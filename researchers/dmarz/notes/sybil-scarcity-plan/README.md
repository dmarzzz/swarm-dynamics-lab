## TLDR

The original scale study recovered almost all specialist facts even while excluding many honest specialists. Each fact had many truthful carriers, so repetition is a plausible explanation to test. The newcomer study made truth scarce but also changed the population, topology, admission rule and timing. This proposed experiment directly connects them: keep the original 972-identity environment and change only how many existing honest specialist slots still report each rare fact—1, 3, 9, 27 or 81. Compare random and coverage audits at 4, 64 or 108 checks, with strong or weak simulated checking. Measure final specialist accuracy, which truthful facts survived admission, and harmful influence. Scripted invariants and clean API qualification must precede any comparison. The current instruction is **plan and publish only; no execution**.

## Question and prediction

At fixed population, graph, attacker reports, verification draws and admission rule, how much of the earlier high accuracy depends on repeating each specialist fact across many honest identities?

The single proposed primary contrast is **one minus eighty-one truthful carriers per rare fact**, using random auditing, 108 checks and attacker check-pass probability 0.1, in final specialist accuracy. The directional prediction is a decrease. A 10-percentage-point decrease is the proposed practical marker: an approximately 99% starting point would then fall below the prior 90% engineering target. This is not a safety guarantee or a power calculation. A small, uncertain or positive contrast is a valid outcome and must not trigger tuning or a favorable rerun.

The closest anchors are [the scale results](../sybil-scale-api/RESULTS.md) and [the completed newcomer results](../sybil-newcomer-api/RESULTS.md). At 972 identities, 108 checks and strong checking, the scale study reported 98.6% specialist accuracy for both random and coverage auditing. In the newcomer main cell, random achieved 26.4%, renewal 20.8% and reputation 12.5%; renewal's proposed advantage was not established. These were different environments, so their gap is not itself a controlled scarcity effect. This plan changes redundancy inside the original environment. The completed [budget/reliability follow-up](../sybil-budget-api/RESULTS.md) adds 24 fresh paired roots and 2,880 valid outcomes. At N972 with strong checks, random/108 reached 100% specialist accuracy with 3.4% attacker seats and 52.4% honest specialist retention; coverage/108 reached 97.2%, 2.9% and 37.4%, respectively. The primary coverage 108-minus-4 replication was +56.9 percentage points (descriptive 95% interval +43.1 to +70.8). Random first met the joint mean target at 64 checks, while coverage first met it at 108; these are tested-grid markers, not guarantees. This reinforces the value of measuring rare-fact survival directly. The successor primary remains random/108 as proposed before this completed anchor, and no new scarcity outcome has been observed.

This is an exploratory local follow-up, not a novelty claim or accepted hypothesis. Formal survey/hypothesis gates and the successor's review status remain unresolved. The previous owner waiver does not constitute a new independent review.

## Metrics

| Measure | Definition and purpose |
|---|---|
| **Primary specialist accuracy** | Exactly correct outputs for skills 3,4,5 divided by three, at each fixed audit checkpoint. Null and wrong values count as incorrect. Primary estimand is c=1 minus c=81 at random/108/0.1. |
| Truth available after admission | Fraction of the three rare facts with at least one truthful carrier admitted. Evaluator-only; not a strict bound on lucky guessing. |
| Carrier survival | Admitted truthful rare reports divided by 3c; also per-fact carrier count and the proportion of roots where all three facts survive. |
| Original outside retention | Admitted original honest outside identities /243, kept separate from carrier survival. It must be unchanged across c within each matched selection cell. |
| Harmful/attacker influence | False admitted reports /486 and attacker-owned admitted reports /486. With unchanged attack reports and selection, these must be invariant across c; violation is an instrument defect. |
| Wrong answers and abstention | Non-null wrong specialist outputs /3 and null specialist outputs /3, alongside complete six-fact accuracy. |
| Truth/lie balance | Actual truthful and false reports per rare fact in the admitted packet. This changes intentionally with redundancy; do not claim the intervention isolates scarcity independently of consensus composition. |
| Selection/process checks | Check targets/outcomes/order, passed/failed sets, admitted IDs, packet hashes, identity/report counts, model schema validity, missing/duplicate rows and exact source match. |
| Resource use | Calls, input/output tokens, known dollars, outstanding/unpriced reservations, latency and stage time. Report actual cost separately from allocation and conservative ceilings. |

No oracle rescue or extra model arm is proposed. A same-packet scripted plurality baseline and the evaluator-only truth-availability calculation are offline diagnostics, not hidden replacements for model decisions. No conditional-on-survival ratio should substitute for the all-assigned primary endpoint; if reported, give its numerator/denominator separately and label the conditioning.
