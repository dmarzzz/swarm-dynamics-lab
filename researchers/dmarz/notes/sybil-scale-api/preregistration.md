# Frozen exploratory scaling protocol v1

2026-10-04. Follow-up requested by dmarz; no formal S2 or novelty claim. README and design.yaml define the full matrix and graph scaling. This protocol is committed before API collection.

1. Primary descriptive contrast: coverage rare accuracy, proportional minus fixed checking at N=972, pass=.10, badges visible. N=36 budgets are identical and reused as a zero-difference anchor. A 10-point difference is practically useful; security cost is always reported jointly. Other sizes, arms, badges, bad-seat shares and model/plurality differences are secondary descriptive estimates, with no selection of favorable conditions.
2. Independent units: 24 sampled world clusters 6000–6023, paired across all sizes and policies. Each size's underlying graph follows a common deterministic construction; ownership, rotation, node IDs, truth and verifier outcomes are seeded. Same-world conditions share all potential outcomes; same budget's badge variants have identical packet order. World-cluster bootstrap 10,000 draws, fixed seed. Population interpretation is conditional on this graph generator; repeated identities/skills are not replication.
3. Fixed checks=4; proportional checks=N/9. No-verification has zero checks and is a diagnostic. Deduplicate identical budgets at N=36 and every no-verification budget. Expected S1=24*(16+28+28+28)=2400 independent API invocations but only 24 world clusters. A budget label never causes an extra model draw on the identical N=36 packet.
4. Graph generalization is validated against original N=36 worlds, including public graph, hidden ownership, check outcomes and final admission. At all sizes test connectivity, population counts, degrees, bridge count, symmetric outside profiles and blind policy interfaces. Only outcomes/data in the public packet reach the model. Numerical PageRank optimization must agree with the original (including ties) before use; otherwise retain original.
5. S0 clean worlds5000–5003 plus engineering4900–4901. Q0 same clean fixtures are fresh model observations: each N has16 cases (full/common-only × badges ×4 worlds). Require per size 100% structural validity, >=95% field correctness, >=90% exact packets, and100% missing-evidence abstention. Full packet has N reports, more than S1's N/2; no truncation. Model amendments require new disjoint Q0 worlds and a recorded attempt; no reusing qualification to claim untuned generalization. Holdout10000–19999 never opened.
6. API actor: claude-haiku-4-5-20251001, temperature0, exact original prompt/schema, no tools/thinking/cache, max500 output tokens. Four inflight calls at most; shuffled dispatch; 120s per request;4h per stage. Durable per-call reserve before POST, call-ID duplicate refusal, usage and billed-cost reconciliation. Known/unknown failures are preserved. Stop new dispatch on any failure, let already dispatched calls finish, then record remaining not started. No retries, no imputation, no restarting an attempt. Authorized bounded repairs use new IDs and qualification if runtime changes.
7. Both all-assigned and complete-valid estimates are reported. Any incomplete scientific stage is diagnostic until reconciled; missing outcomes are never silently discarded. For assigned-denominator accuracy failures have zero credit, with invalid counts visible; policy graphs metrics of unstarted outcomes may only be shown as scripted planned data, clearly labeled. No scientific conclusion from a failed qualification.
8. Visuals follow mapping v1: log-spaced population axes, policy colors, fixed/proportional line styles, accuracy/attacker-seat-share panels by check reliability. Both badge modes retained in separate images. Replay time is completed calls, not simulated agent conversation. Raw completion records and graphs are durable artifacts. UI marks pending/failed cells, preserves chronological prefixes, and exposes no secret or evaluator truth to actors.
9. No changes after viewing S1 except repairs of verified defects, documented with preserved outputs. Valid adverse or null results complete the study. Report transport/model failures and cost, release the host only after artifact checks and worker exit.
