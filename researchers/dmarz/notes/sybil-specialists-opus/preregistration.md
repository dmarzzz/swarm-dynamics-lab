## Amendment A1, 2026-10-04 07:45 UTC: Sonnet 4.6 replaced by Opus 5.5 before any paid call

dmarz instructed on 2026-10-04: "use opus for everything going forward please". The relay came through dmarz/fleet-monitor. The Sonnet 4.6 version ([sybil-specialists-sonnet](../sybil-specialists-sonnet)) ran only its scripted S0 and made no model calls. Its paid stages will not run. This study is registered under its own name and hub id, so no Sonnet record is relabelled.

Changes from the Sonnet version:

- **Model and request:** `claude-opus-5-5`, confirmed through the Models API on 2026-10-04. Opus 5.5 rejects sampling parameters, so `temperature` is removed. Thinking cannot be disabled on this model; it runs adaptive thinking at `output_config.effort: low`, the shallowest setting, because the task is extraction. Thinking blocks in the response are ignored, and the answer is the single text block. A `refusal` stop reason is a recorded failure. Item 6's "no thinking" and "temperature zero" therefore do not hold for this model, and this is a model property, not a choice.
- **Output cap:** raised from 500 to 3,000 tokens, because thinking counts against `max_tokens`.
- **Prices:** USD 4 / 20 per million input/output tokens, from the official pricing page (platform.claude.com/docs/en/about-claude/pricing, read 2026-10-04).
- **Ledger cap:** USD 40 on conservative reservations (worst case about USD 27 for Q0 plus S1), with the 300-call ceiling unchanged.
- **Fresh qualification cases:** Q0 and S0 qualification worlds move from 3000–3005 to 3100–3105. These worlds have not been used by any sybil study, so Opus is qualified on cases no model has seen. Q0 has 24 rows (hash `48769920…`).
- **S1 unchanged:** worlds 4000–4011, 192 rows. The ordered (id, packet hash) list is identical to the Haiku pilot (`7eaff47f…`, recomputed in-process), so Opus-minus-Haiku contrasts pair by world.
- **Expected spend:** about USD 1.6–5.7 for Q0 and S1. Input is about 1,600 tokens per call, from the Haiku pilot's measured 1,233 scaled by about 1.3 for the newer tokenizer. Output is 40–1,000 tokens per call, depending on thinking length at low effort, which is not yet measured. Q0 measures it, and the S1 estimate is restated from Q0's actual usage before S1 launches.
