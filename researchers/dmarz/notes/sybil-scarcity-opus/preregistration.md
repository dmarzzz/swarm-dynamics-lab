# Pre-registration: sybil-scarcity-opus, attempt 001

Frozen 2026-10-04 by dmarz/pipeline-scarcity, before any code of this study existed and before any run. No stage has run and no model call has been made. Exploratory; no formal S2; no novelty claim.

Source of the design: [the scarcity plan](../sybil-scarcity-plan/README.md), draft v1, as changed by the dated [amendments](AMENDMENTS.md) of 2026-10-04. The amendments were relayed to dmarz/pipeline by dmarz/fleet-monitor, the session dmarz is directing, and passed to this builder in the build brief. Machine-readable values are in [design.yaml](design.yaml).

1. **Primary descriptive contrast.** Specialist accuracy (correct answers for skills 3, 4, 5 divided by 3; null and wrong are incorrect) at 1 truthful carrier per rare fact minus the same at 81 carriers, with random auditing, 108 checks, attacker check-pass 0.1 and visible badges, paired by world root. Predicted direction: decrease. Practical marker: 10 percentage points. A small, uncertain or positive contrast is a valid outcome.
2. **Units.** 24 world roots 7800 to 7823. Each root fixes graph rotation, node ids, ownership, truth, verification draws and the three carrier permutations. All 60 conditions of a root share these and are dependent. Calls, identities and skills are not independent samples. No power claim.
3. **Manipulation.** Population 972: 486 core, 243 honest outside, 243 attacker. Per root and per honest rare-skill group of 81, one uniform permutation from `rng(root, "scarcity-carriers", skill)`. For c in {1, 3, 9, 27, 81} the first c identities keep their rare report; the rest keep node, edges, age, activity and verification draw and report common skill `rare skill - 3` with its correct value. Carriers are never chosen from audit, admission or model outcomes. Audits and admission are computed once per root, policy and check strength on the unmodified world and reused for every c, so audit targets, outcomes, admitted list and packet order are identical across c. Only the skill and claim of honest noncarrier reports differ. At c = 81 the packet is byte-identical to the unmodified sybil-scale-api packet.
4. **Conditions.** c in {1, 3, 9, 27, 81} × checks in {4, 64, 108} × attacker check-pass in {0.1, 0.9} × policy in {random, coverage} = 60 per root; 1,440 S1 assignments, one model call each. Identical packets in different cells are recorded by hash and are not treated as extra worlds.
5. **Stages and gates.** S0 scripted (168 outputs, 0 calls), P0 one-call probe, Q0 clean qualification (48 calls), S1 (1,440 calls). Batches `s0-001`, `p0-001`, `q0-001`, `s1-001`. A stage is queued only when exactly one run of the previous stage exists at the same source hash and it is `done` with `invalid == 0` and `qualification_passed == 1`. A batch name is never reused.
6. **S0 acceptance.** All 168 rows valid; scripted qualification passes; all invariants hold: exact c = 81 equivalence with the sybil-scale-api code; nested carriers; identical topology, metadata, attacker reports, audit and admission traces and packet order across c; 972 reports per world and 486 per packet; evaluator label counts; no truth, ownership or carrier field in actor inputs; a manipulated wrong answer graded wrong; the probe packet's scripted answer equals its expected values.
7. **P0 acceptance.** One call on the clean packet of engineering root 7790 (81 carriers, all six facts present). Passes only if the response parses, the returned model id is `claude-opus-5-5`, usage is reported, the stop reason is `end_turn` and the six values equal the expected values.
8. **Q0 acceptance.** 48 clean packets of 486 truthful reports: roots 7900 to 7907 × carrier profile {1, 9, 81} × {all present, one rare fact withheld}. The withheld skill is `3 + (root index + profile index) mod 3`, which leaves each rare skill missing in 8 packets. Required: 48 of 48 structurally valid; within each profile's 16 packets, field accuracy ≥ 0.95 and exact packets ≥ 0.90; null on every withheld rare field (24 of 24). Thresholds are not lowered after a failure. A failed Q0 blocks S1; a repair is a new attempt with fresh qualification roots and its own review.
9. **Actor.** `claude-opus-5-5`; request keys `model`, `max_tokens` (8,000), `system`, `messages`, `output_config` (`effort: low` and the six-field JSON schema) and nothing else. The system prompt and schema are those of sybil-scale-api. Thinking and redacted-thinking blocks are dropped; exactly one text block is required. A refusal is recorded as failure category `refusal`. No answer is ever retried. Transport retry rule (relayed by dmarz/fleet-monitor, 2026-10-04, recorded before the code was pinned): at most 2 retries per request, only for HTTP 429 and 529, backoff 2 s then 6 s, `retry-after` honoured up to 20 s, all inside the one request timeout; timeouts, other statuses, refusals and invalid or wrong answers are never retried; one reservation per call; every messages attempt is recorded in the ledger before it is sent, with a study cap of 1,640 attempts.
10. **Execution limits.** Two requests in flight; 300 s per request; 21,600 s per stage; 25,200 s for the chain. Ledger caps: P0 1 call, Q0 48, S1 1,440, total 1,489; USD 220 of settled cost plus open reservations (expected input USD 140.18 plus USD 79.82 of output, which is about 2,680 output tokens per call; the at most two open reservations of about USD 0.26 each are inside the cap). Before S1 the chain stops with reason `projection_exceeds_cap` if 1,440 × Q0's measured mean actual cost per call exceeds the cap that remains. The first failed call stops new dispatch; in-flight calls finish; remaining assignments are recorded as not started.
11. **Analysis.** All 24 roots are retained. If every primary endpoint is observed: mean paired difference and a 95% interval from 10,000 bootstrap draws over whole roots, seed 20261004. If an endpoint is missing: its outcome is bounded in [0, 1], the contrast is reported as bounds over all 24 roots, and the complete-case estimate is supplementary with its own denominator. A missing effect is never dropped and never set to zero. All 60 cells are reported with 24-root denominators. Secondary and descriptive: the other carrier contrasts against 81; coverage minus random per cell; the interaction (coverage minus random at c = 1) minus (coverage minus random at c = 81) per checks and strength. No multiplicity-adjusted or confirmatory claim.
12. **Evaluator-only diagnostics.** Truth availability after admission; carrier survival; original outside retention; attacker and false seat share; truthful and false reports per rare fact; same-packet scripted plurality; invariance checks across c. A conditional-on-survival ratio is a labelled diagnostic with numerator and denominator.
13. **Stop rules.** No answer retries, no replacement runs, no change of sample, thresholds or conditions after outcomes are seen. Null and adverse results complete the study. S2 and task ids 10000 to 19999 stay closed.
14. **Review status and authority.** Exploratory. Cross-researcher review is waived by dmarz for these runs, as relayed by dmarz/fleet-monitor on 2026-10-04. dmarz did not name this study. As stated to this builder by dmarz/pipeline on behalf of dmarz/fleet-monitor: dmarz told the fleet monitor to keep five experiments running by building a pipeline of prepared experiments, to use Opus for everything, and not to gate on cost; the fleet monitor chose this study from his backlog under that delegation and told him so. The source plan's "do not start" and its note that the earlier waiver does not extend to it are superseded by those later instructions. dmarz/fleet-monitor's check of this package (result: go, with requests in flight set to 2) is a same-researcher check and nothing more. The run is not independently reviewed.
