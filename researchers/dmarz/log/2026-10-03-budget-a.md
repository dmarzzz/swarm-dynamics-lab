What surprised me: the evidence on showing an agent its budget points both ways. BATS measures gains from a per-tool-call budget tracker (BrowseComp 12.6 to 14.6 on Gemini-2.5-Pro; same accuracy at budget 10 as ReAct at 100 for 31.3% less cost), while Cognition reports Sonnet 4.5's injected context countdown caused premature wrap-up, fixed by advertising 1M tokens and capping at 200k. BAGEN finds frontier agents over-optimistic about remaining budget; Cognition finds Sonnet 4.5 underestimates it. Anthropic's docs show the countdown was dropped on newer models in favour of an opt-in, advisory task budget.

What next: a matched experiment on visible versus hidden budgets for agents using the task_budget API (one model, one task set, budget shown / hidden / misstated), and extending it to several agents sharing one budget, which none of these sources test.
