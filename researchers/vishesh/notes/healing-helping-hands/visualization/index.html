    Design, denominator and limits

    Scouts make one model-backed extraction before communication. Subsequent sharing, deduplication and aggregation are programmed. This is not 200 language agents reasoning each round. Atlas accuracy uses 20 claim consensuses; local accuracy uses 200 curators. The baseline is the consensus of valid synthetic reports, not scientific truth.

    Three corpus seeds are paired fixtures. Rounds, documents and agents are not independent experiment replicates. A Laya attachment has the same number of call slots as a Qwen attachment, not the same FLOPs or tokens. Agreement does not prove independent errors.

    Measured steps only, no interpolated states. Round 0 follows the first neighbor exchange; the event occurs before round 10's exchange. Playback is accelerated logical time, not inference wall time. Swarm Lab
