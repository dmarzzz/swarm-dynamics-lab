## How to read it

| Label | Meaning |
|---|---|
| Accept | Useful proposed work; remains open until its acceptance evidence exists |
| Adapt | Keep the objective, change the prescription or inference |
| Superseded / in part | Newer evidence resolves some or all of the old recommendation; remaining work is explicit |
| Defer | Plausible future experiment; not a required new run or automatic priority |
| Disagree in part / Not adopted | Reason stated; preserve the recommendation for traceability |

**Green** means a scoped repair or valid closeout has evidence. **Amber** means a proposal or limited diagnostic, not admission to a main study. **Red** means a claim or current rule fails its intended test. These colors describe evidence, not project worth. No study gets a confidence upgrade because its documentation improved.

## The 13 recurring problems, made actionable

| Review pattern | Operational interpretation |
|---|---|
| Ceiling/floor | Check whether the chosen endpoint can distinguish the intended mechanism. Do not discard observed hard/easy cells after evaluation or design solely to get a positive model advantage. |
| Structurally zero contrast | Audit information access, reachable actions, deterministic aggregation and trigger rates. Distinguish architectural identity from a model-dependent null. |
| Inflated n | Use the root/receipt/episode population actually sampled; calls, fields, actor slots and replay rows are work counts. |
| Interface effects | Freeze effective context, model route, schema, response normalization and parser version; measure errors at each boundary. |
| Weak comparator | Use a same-input strong baseline and report its cost/access. A useful study may measure failures relative to an exact solver; it need not force that solver off ceiling. |
| Scripted versus native | State which agents act natively, which transitions are programmed and which outputs are deterministic. Do not imply 200 identities are 200 independent learners. |
| Configuration dependence | Distinguish controlled initial state from deterministic hosted outputs. Record memory/reset and context budgets per actor; repeat only to resolve a useful uncertainty. |
| Visual overstatement | Show units, missingness, qualification and scientific status separately. Archive figures through existing provenance rules, without deploying shared UI from another account. |
| Weak positioning | Closest work is often already catalogued. Read the methods needed for the claim, then label replication, engineering evidence or unconfirmed novelty honestly. |
| Theme/realism gap | Real incident transfer is valuable when the question requires it; it is not mandatory decoration on every synthetic mechanism test. |
| Budget mismatch | Distinguish expected cost, enforceable reservation, known actual spend and unknown liabilities. Local model inference is not automatically zero resource cost. |
| Transport failures | Use a prospective bounded execution contract, informative safe error categories and complete closeout. Do not loosen stops or introduce automatic retries after seeing failures. |
| Buried negative evidence | Lead with the most decision-relevant observed result and its limits. Small adverse estimates do not establish broad inferiority or equivalence. |

## Corrections to the review itself

- **Healing:** C5 produced 23 disagreements in 432 main cases, so the review’s guaranteed-zero enum-order assertion is contradicted by newer evidence. The actual problem is 234 wrong accepted agreements and a failed safety criterion.
- **Information versus salience:** a receipt computable from existing evidence adds no information, but can still change a bounded model’s behavior. Name the question correctly; do not call the behavioral effect mathematically impossible.
- **Statistics:** 24 roots is not a universal floor; five roots do not make a bootstrap confirmatory. Independent-vote rare-event formulas and Kish effective-N require assumptions. Zero variance or tiny denominators may make a correlation/interval uninformative or undefined.
- **Theseus:** an 8-case batching effect cannot be treated as the measured noise band for a 4-case v1 interface. Three turnover levels crossed with two change levels create six cells, not the review’s four-arm budget sketch.
- **Antsy:** positive rare STOP rates are not literally unreachable. Also, 46.25 minus 8.45 seconds is below 45 seconds; this arithmetic does not replace a measured warm-service qualification.
- **Historical scoring:** add answerability, corrected-estimator and counterfactual analyses alongside original outcomes. Do not silently replace registered gold, exclude inconvenient assigned cases or relabel retrospective work as preregistered.
- **Permissions:** independent researcher review remains optional. The source’s suggestions to contact others, bypass browser restrictions or run expensive local/hosted follow-ups are recommendations, not authorization.
