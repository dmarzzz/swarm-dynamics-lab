02 / Definition, context and lifecycle

An agent is a controlled system, not a name

Do we currently spin up the same agent reliably? Partially, and inconsistently across projects. Several scripts reproduce controller initialization well. There is no single enforced contract spanning effective model configuration, actual delivered context, memory state and permissions. A declared model name, fixed seed or repeated persona does not close that gap.

An agent definition is the versioned policy and operating rules. An instance is that definition plus its mutable state inside an episode. Identical definitions may intentionally receive different private evidence. Role differences require declared role-specific definitions or versioned role parameters. A stateless model request may still participate in a persistent agent through controller-managed memory.

Reproducibility has three levels: reconstructing setup, replaying recorded actions, and reproducing behavior in fresh model executions. The first two can be exact under a defined boundary; the third needs measured variation unless the inference stack guarantees it. Same weights do not imply same state; same state does not automatically imply identical hosted output.

06 / Prioritized work

A lean route to stronger research

First, fix execution truth. Require the verified condition-specific plan receipt at the lowest common execution boundary; resolve the actual qualified model configuration once; validate whole outputs before state mutation; reserve budgets before dispatch; write a terminal record for every assigned unit; separate publication errors from numerical outcomes. Refuse to overwrite completed historical run IDs.

Then, fix experimental identity. Implement only the lifecycle fields used by the chosen study. Freeze actual prompt/context rendering and source bytes before launch. Record memory initialization, reset, ownership and truncation. Use named random streams so treatment-dependent message counts cannot silently change unrelated decisions. Browser sessions, vector databases or distributed checkpoint stores are unnecessary when the study does not use them.

Then, qualify a measurable mechanism. Use exact/scripted controls to establish that damage causes loss, that a clean task is solvable, and that the primary endpoint is attainable. Distinguish broad task competence from repeated wording templates. A qualification failure should stop model efficacy comparisons, while retaining all failed evidence.

Finally, run one paired held-out study. Freeze one primary contrast, experimental unit, useful effect size, cost ceiling, failure handling and analysis. Choose sample size from pilot variation and desired precision. Randomize or counterbalance role positions and order. Preserve paired worlds in analysis and treat repeated seeds, forks and downstream agents at their proper dependency level.
