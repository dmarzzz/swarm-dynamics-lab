# Biological frontiers for heterogeneous agent swarms

2026-10-04 UTC · vishesh/codex-heterogeneous · exploratory research, no experiments

The owner's follow-up asks for more conceptually interesting, biologically grounded questions and direct research into X discussions. This revision focuses on dependencies, inheritance, niches and compatibility between lineages. The first HX shortlist remains useful implementation background; it is no longer the recommended conceptual focus.

Eight new questions, HX-31–HX-38, extend the existing bank to 38. The five priorities within this biological-frontier subset are:

| Rank | Question | Score | Decisive intervention |
|---|---|---:|---|
| 1 | **HX-31: Can less capable individuals make a smarter collective?** | 93 | Allow costly capability loss, then remove and restore the helpers. |
| 2 | **HX-32: When does an agent symbiosis become an evolutionary trap?** | 92 | Swap co-adapted partners and normalize their interface after a task shift. |
| 3 | **HX-33: Does the inherited habitat decide which agents are intelligent?** | 92 | Transplant identical newcomers into habitats built by different model families. |
| 4 | **HX-35: Can compatible swarms evolve incompatible ways of thinking?** | 91 | Recombine independently developed procedures after translating their vocabulary. |
| 5 | **HX-37: Can one agent live on another agent's failed work?** | 90 | Remove and restore the failed-artifact stream that sustains a cheap specialist. |

These use the existing rubric, with assistant-assessed scores, not human or independent reviewer votes. The biological-frontier filter follows the owner's new preference; it is not an undisclosed change to rubric weights. Close scores are fragile. See [scores and sensitivity](SCORES.md).

The scan read eight substantive X roots/discussions associated with six projects, followed primary papers, and checked relevant biological and digital-evolution precedents. Multiple authors discussing one paper are not independent evidence. The most consequential finding is how much is already occupied: shared memory, emerging roles, language invention, transmission to weaker models, agent contagion, adversarial evolution, and digital symbiotic dependence all have predecessors. The opportunities above require narrower causal results. None is certified as a first.
