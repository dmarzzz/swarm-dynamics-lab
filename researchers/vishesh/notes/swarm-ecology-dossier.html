The NCA connection: inspiration with precise boundaries

The paper's announcement thread contains Andrew Davison’s prediction about a possible successor to transformers. It quotes Mayalen Etcheverry’s announcement of Reasoning with Neural Cellular Automata. The paper studies local recurrent cells and asynchronous updates on visual reasoning tasks, including mazes and Sudoku. Davison’s architectural prediction goes beyond those demonstrated results. Davison post · Paper.

Etcheverry’s thread describes local interactions producing evolving spatial solutions, and discusses scaling through space, rollout duration and parallel trials. The most useful hackathon connection is the experimental style: vary local connectivity, update dynamics and damage, then measure collective function. Author thread.

NCA cells, bacterial cells, bird models and language agents operate at different levels. Reusing a hypothesis does not establish a shared mechanism. In particular, a communication network of transformer-based agents is not a reproduction of an NCA architecture.

Case studies worth building around

Claims mutate through retelling

A Village report follows an NGO rejection as agents transform it into unsupported endorsement claims. Use it to develop a claim-lineage method, then evaluate on another episode. What Do We Tell the Humans?.

Consensus can outrun evidence

The persuasion report describes a theory built around missing history data and its correction through a mundane temporal explanation. It supplies a candidate episode, not proof of a universal contagion mechanism. Persuasion in the AI Village.

Persistent state can preserve mistaken interpretations

The compounding-misalignment study traces a long trajectory and memory states. Separate observed persistence from the claim that compaction caused later behavior. Compounding misalignment: Gemini case study.

Correction deserves a longitudinal endpoint

The Gemini intervention offers an example of peer assistance and memory correction. A useful follow-up asks what survives and whether later behavior changes. Saving Gemini.

False accusations are an essential negative control

The sabotage game includes a unanimous accusation against an innocent agent and unequal exposure to saboteur roles. Use the former as a caution against consensus-based ground truth. Can Agents Fool Each Other?.

Reporting does not guarantee response

The DeepMind research-swarm paper describes both exploit adoption and spontaneous reporting. It argues that the counter-response lacked effective institutional tools; this motivates a test of reporting-to-resolution mechanisms. Emergent cheating and whistleblowing in research swarms.

A fair test

  1. Define a single question. Choose an outcome that could disconfirm your preferred story.
  2. Use known truth where possible. For observational work, use evidence-backed manual labels and preserve unknowns.
  3. Match resources. Network topology should not silently determine total tokens, observations or messages.
  4. Repeat the experiment. Report independent runs and uncertainty. Messages from the same run are not independent experimental replicates.
  5. Include a simple baseline. Majority vote, no communication, ordinary search or a manually reviewed record can be appropriate.
  6. Keep all outcomes. Show a representative replay alongside aggregate results; do not select only the most dramatic run.
  7. Separate analogy from evidence. A growth curve is not automatically logistic population growth, and a transition is not automatically a phase transition.
  8. Make limitations visible. A small, honest result is more useful than an elaborate unsupported claim.

Build and presentation plan

Before kickoff · Request data; choose the question, task and fallback; run a tiny pilot.

Saturday morning · Establish ground truth, logging and a working baseline.

Saturday afternoon · Implement one comparison; validate that treatments differ only as intended.

Saturday evening · Complete an end-to-end run. If the result cannot be interpreted, cut scope.

Sunday morning · Repeat trials or annotate held-out episodes; inspect errors and negative controls.

Sunday afternoon · Freeze analysis, finish evidence links, README and recorded demo.

Two-minute story: 15 seconds for the question; 45 for one visible mechanism; 35 for aggregate evidence; 25 for limitations and the next useful application.

How to read the tags

Lift and difficulty

Low lift: one small runner or viewer. Medium: a task harness, logging and analysis. High: recovery infrastructure, dataset work or a model reproduction.

Moderate difficulty: familiar implementation with a clear score. Hard: causal inference, confounds, uncertain data or research infrastructure. These describe the proposed research project, not the browser illustration.

Novelty and fit

Focused extension: a specific test of an established idea. Useful tooling: value comes from investigation workflow or usability. Established concept: the basic demonstration already exists; a new measurement is essential.

Strong fit: directly addresses agent-swarm behavior or investigation. Exploratory: adjacent to the event’s language-agent focus. These are editorial judgments, not organizer scores.

Hours are rough estimates for one experienced builder with data and tools ready. API delays, access requests and unfamiliar infrastructure add time. No empirical performance or likelihood of winning is implied.

Study 01 / Ecology

Collective Sensing

Local signals. Shared mistakes.

At matched evidence and communication budgets, how does network structure change accuracy, error spread and correction?

Lift MediumDifficulty ModerateNovelty Focused extensionEvent fit Strong

12–20 h estimated MVP · tools + data ready ↳ Fish schools → evidence networks

The interactive model runs in the HTML edition. Its outputs are illustrations, not experimental findings.

Background

Collective sensing asks whether a group can recover a signal unavailable to any individual. In fish, movement and local interaction can produce an effective response to environmental gradients. For language agents, the corresponding question is about evidence: who sees which observations, and how does communication change the estimate?

Event fit. Connects collective sensing to Village’s consensus cases and Grove’s interest in agent ecology.

Prior art

Emergent sensing in mobile animal groups · Berdahl et al., 2013

The researchers connect fish-school behavior to environmental sensing. Borrow the separation between an individual’s local input and the group’s measured performance.

Multiagent Debate · Du et al., 2023

Multiple language-model instances exchange answers and reasoning. This is a direct baseline for communication, though it does not establish that local spatial networks are best.

Application

A research team splits a document collection among agents. Can they combine partial evidence without repeatedly counting the same source? The same design could help distributed sensor interpretation.

Contribution

Compare local, global and silent networks while holding observations and communication budget fixed. The interesting contribution is a map of when communication helps, including correlated-error conditions.

Experiment

  1. Give 12–20 agents partial observations of a synthetic world with a known correct classification. Use explicit rules rather than biological trivia.
  2. Compare a local ring or lattice, the same structure with a few long-range links, and a shared chat. Keep each agent’s total incoming message allowance comparable.
  3. Introduce one misleading observation, then a correction at a fixed round. Record every observation, message and answer.
Measures and controls

Measure

  • Final accuracy and disagreement
  • Rounds until a correct stable decision
  • Incorrect adoption fraction and correction latency
  • Tokens and delivered messages per correct decision

Controls

  • Same base model, prompts and initial evidence in the first experiment
  • Paired task seeds and repeated independent runs
  • Non-communicating agents plus majority-vote baseline
  • Separate clean, misleading-evidence and corrected conditions
Scope + presentation

MVP

One task generator, three communication treatments, structured messages, a replay and a table of repeated-run outcomes. Pilot a small batch before scaling.

If time remains

Add model diversity or asynchronous updates only after the topology result is interpretable.

Two-minute presentation

Run the same evidence through two networks. Introduce an error. Show how far it travels, then reveal accuracy and recovery across all trials.

Main risk

A flocking animation alone is well explored. Measure estimation error; distinguish independent observations from copied messages.

Study 02 / Ecology

The Commons

Who pays for shared knowledge?

Does verification before sharing protect useful collective output when some shared results are unreliable?

Lift MediumDifficulty ModerateNovelty Focused extensionEvent fit Strong

12–20 h estimated MVP · tools + data ready ↳ Fish schools → evidence networks

The interactive model runs in the HTML edition. Its outputs are illustrations, not experimental findings.

Background

A public good costs its producer something while benefiting others. Bacterial siderophores make the cost-and-benefit structure concrete. In agent systems, verified shared notes can play a similar role: producing them takes budget, while everyone can reuse them.

Event fit. Grove’s institutions and the DeepMind research collective both make shared-resource governance relevant.

Prior art

Cooperation and competition in pathogenic bacteria · Griffin et al., 2004

Experiments connect bacterial cooperation to relatedness and the scale of competition. The lesson is to vary incentives and interaction structure explicitly.

Melting Pot · DeepMind

An existing suite tests cooperation, competition and other social interactions. Commons-style environments already have substantial benchmark history.

LLM agents in Melting Pot · 2024

Adapts Melting Pot scenarios for language agents and evaluates cooperation in Commons Harvest. This is close prior art, not merely a biological analogy.

Application

Shared research caches, collective annotation and communal compute budgets. Useful output would identify a cheap rule that sustains verified contributions.

Contribution

Use shared artifacts with an objective quality check. Test whether attribution or contribution credit changes both useful output and free-riding.

Experiment

  1. Agents spend a fixed budget testing small, objectively checkable hypotheses. Findings enter a shared library.
  2. Compare immediate publication with evidence-required publication. Introduce a controlled fraction of unreliable contributions.
  3. Track whether agents reuse, verify, dispute or ignore findings; keep the true validity of each finding available to the evaluator.
Measures and controls

Measure

  • Verified useful findings per total budget
  • Downstream work wasted on false findings
  • Time until a bad artifact is challenged
  • Honest work delayed by verification

Controls

  • Equal initial knowledge, test cost and total budget
  • Separate non-contributors from false contributors
  • Clean-library baseline
  • If roles are programmed, report introduced rather than emergent cheating
Scope + presentation

MVP

One hypothesis-testing task, two sharing policies, one contamination level and a clean condition; artifact lineage replay.

If time remains

Local versus global libraries, spatial assortment, or access earned through verified contributions.

Two-minute presentation

Show one unreliable finding being reused. Switch to the evidence gate and reveal the benefit and cost over repeated runs.

Main risk

A generic harvest game adds little. The contribution should come from verified knowledge, a new incentive comparison, or a well-measured failure.

Study 03 / Ecology

Regrowth

Lose workers. Preserve function.

Which coordination structure recovers task performance after loss of agents, memories or links?

Lift HighDifficulty HardNovelty Focused extensionEvent fit Strong

18–28 h estimated MVP · tools + data ready ↳ Regeneration → replicated memory

The interactive model runs in the HTML edition. Its outputs are illustrations, not experimental findings.

Background

Resilience concerns retained or recovered function after disturbance. A group may reconnect visually while permanently losing unique information. Treat network repair, memory recovery and task recovery as separate outcomes.

Event fit. Connects the NCA inspiration to persistent agent systems and a practical resilience question.

Prior art

Growing Neural Cellular Automata · 2020

Learned local rules grow patterns; training with damage improves regeneration. This offers a perturbation protocol, not evidence that language agents regenerate the same way.

Kilobot self-assembly · Harvard, 2014

A thousand-robot system assembles shapes from local interactions. It is a physical precedent for distributed organization under imperfect conditions.

Application

Long-running research or coding teams need to survive worker loss, context resets and missing shared artifacts. A recovery benchmark could expose which memories actually need replication.

Contribution

Remove a worker with unique evidence, then compare replication, checkpoints and role reassignment. Score recovered answers as well as restored connectivity.

Experiment

  1. Use a distributed map or constraint-solving task with a known correct output. Give agents distinct partial information.
  2. After a fixed work interval, remove randomly chosen agents or disconnect a bridge. Compare centralized and local coordination.
  3. Measure completion and accuracy after damage; account explicitly for replacement agents and information that was permanently lost.
Measures and controls

Measure

  • Performance before damage and after recovery
  • Recovery time and additional token cost
  • Fraction of runs recovering by a fixed horizon
  • Sensitivity to random versus targeted disruption

Controls

  • No-damage baseline and matched initial task difficulty
  • Equal surviving resources or explicit normalization
  • Separate deletion of a copy from permanent destruction of unique information
  • Fixed perturbation timing to avoid favorable case selection
Scope + presentation

MVP

One task, two architectures and one damage type. Produce a replay with an actual scored output.

If time remains

Test whether distributed copies also restore corrected false beliefs: resilience can preserve harmful state.

Two-minute presentation

Erase part of a functioning network, then show its answer recovering—or failing—against a measured no-damage baseline.

Main risk

Restarting an agent is easy; reproducing the right state is the hard part. Keep failures and restart costs in the score.

Study 04 / Ecology

Quorum

Agreement is not independence.

How does adoption change with repeated messages, distinct messengers and genuinely independent evidence?

Lift LowDifficulty ModerateNovelty Focused extensionEvent fit Strong

6–12 h estimated MVP · tools + data ready ↳ Quorum sensing → evidence thresholds

The interactive model runs in the HTML edition. Its outputs are illustrations, not experimental findings.

Background

Quorum rules turn accumulated signals into a group commitment. Bacterial signaling and ant nest choice show different versions of threshold coordination. Counting agreeing agents is much simpler than checking whether their evidence is independent.

Event fit. Offers a narrow, testable version of the Village’s persuasion problem with little data-ingestion overhead.

Prior art

Cooperation and conflict in quorum-sensing bacteria · 2007

Signaling and response can be exploited by noncooperators. A threshold is a mechanism with incentives, not an automatic guarantee of reliable action.

Speed versus accuracy in decision-making ants · 2009

Nest-choice experiments examine speed–accuracy trade-offs. This supplies a useful two-axis evaluation: how fast the group commits and how often it is right.

Application

Agent approvals, incident escalation and automated fact-checking. An evidence-aware quorum could prevent five copies of one rumor from looking like five confirmations.

Contribution

Compare votes with unique verified evidence identifiers. Sweep the commitment threshold and plot false commits against delay.

Experiment

  1. Provide an agent an initial evidence packet and a choice with known ground truth.
  2. Compare one source repeated five times, five agents repeating one source, and five independent observations.
  3. Vary exposure count and evidence reliability. Record decisions before and after receiving messages.
Measures and controls

Measure

  • Correct and incorrect adoption probability
  • Sensitivity to independent versus repeated evidence
  • Confidence calibration where elicited
  • Reversal after a credible correction

Controls

  • Match total text length and message order distributions
  • Declare which observations share a source
  • Use both true and false target claims
  • Compare with an evidence-counting baseline
Scope + presentation

MVP

Three message conditions, a small set of generated problems, repeated trials and adoption curves.

If time remains

Place tested agents in a network to examine whether individual thresholds predict group cascades.

Two-minute presentation

Present three visually identical crowds. Reveal that only one contains independent evidence, then compare decisions.

Main risk

Unique identifiers are not enough if several documents share the same upstream source. Include that case in the test.

Study 05 / Ecology

Diversity & Resilience

Different types. Different failures.

Does heterogeneity improve error detection and recovery under comparable resource budgets?

Lift MediumDifficulty HardNovelty Focused extensionEvent fit Strong

14–24 h estimated MVP · tools + data ready ↳ Biodiversity → error correlation

The interactive model runs in the HTML edition. Its outputs are illustrations, not experimental findings.

Background

Diversity is useful when it changes failure correlation or task coverage. Different role names do not guarantee different errors. Measure disagreement before discussion and determine whether it survives communication.

Event fit. The Village explicitly raises whether diverse systems are more robust to cheating. This gives the project a clear organizer-facing question.

Prior art

Demystifying Multi-Agent Debate · 2026

Studies confidence and diversity in debate and notes that ordinary debate can underperform voting. It gives a reason to test independent aggregation first.

Persona Inconstancy · 2024

Examines conformity, confabulation and impersonation in persona-based collaboration. Prompted identities should not be treated as stable biological species.

Application

Choose a mixture of models, prompts or retrieval sources that remains useful when one component has a systematic blind spot.

Contribution

Cross an explicit shared blind spot with measured pre-discussion error correlation. Match total spend and include a homogeneous ensemble with independent samples.

Experiment

  1. Choose one objectively scored collaborative task and a reproducible misleading artifact.
  2. Compare homogeneous groups with groups mixing models or reasoning roles.
  3. Measure both clean-task performance and resilience to the same introduced error.
Measures and controls

Measure

  • Group accuracy and time to correction
  • Pairwise error correlation
  • Cost per correct solution
  • Dissent that changes the final answer

Controls

  • Include best-single-model and homogeneous strong-model baselines
  • Report both equal-token and approximate equal-cost comparisons if possible
  • Rotate roles and initial evidence
  • Use repeated task seeds
Scope + presentation

MVP

Two population compositions and one perturbation. Separate capability gains from resilience gains.

If time remains

Explore whether strategic diversity within one model gives similar benefits at lower cost.

Two-minute presentation

Show the same error passing unchallenged in one community and being challenged in another; then show aggregate outcomes.

Main risk

Model diversity changes capability and price too. A result cannot be attributed to diversity if those differences explain it.

Study 06 / Investigation

Telephone

Follow the claim, not the confidence.

Where does uncertainty disappear as a claim moves through a group, and does correction reach later behavior?

Lift MediumDifficulty ModerateNovelty Useful toolingEvent fit Strong

10–18 h estimated MVP · tools + data ready ↳ Transmission → source lineage

The interactive model runs in the HTML edition. Its outputs are illustrations, not experimental findings.

Background

A claim can change when it is summarized, copied into memory, then cited by another agent. A useful viewer preserves the source, the exact retelling and what changed: certainty, quantity, attribution or meaning.

Event fit. Directly addresses the hackathon’s information-flow track and several Village case studies.

Prior art

LLM-Culture · Perez et al., 2024

Open software passes stories across agent networks and generations, with metrics and a web interface. Transmission experiments and visualizations already exist.

What Do We Tell the Humans? · AI Village
