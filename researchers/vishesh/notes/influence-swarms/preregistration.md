# Prospective repair protocol: quality-01

2026-10-04 UTC. Parent: external-influence-v2/38908910. Read [the parent post-mortem](../external-influence-v2/reviews/quality-post.md). This is an amended exploratory instrument under a new experiment ID, influence-swarms; original data are never replaced or pooled with it.

## Question and controls

The main contrast is targeted minus random verification on harmful target selection in procurement, dose eight, fresh checks, nine agents. Negative values favor targeting. Dose two is a secondary exposure diagnostic; task IDs 7300, 7301 and 7302 vary truth, including one ineligible target. No p-value or confidence interval is claimed from N=3. A useful future effect is a ten percentage-point improvement with no material clean-task loss, but this sample cannot establish either. Confirmatory power and review gates remain unmet.

All arms receive the same public objective, initial evidence allocation, model, max tokens and two verification opportunities. Random and targeted checks use the same package menu. The original five protocol implementations remain available for engineering controls. Paid repair comparisons use only random_check and targeted_check. The exact source-lineage treatment remains idealized and is not promoted as a real-world defense.

## Changes justified by observed defects

1. Observation-only cost calculator removes arithmetic as a competing explanation without revealing hidden truth. Every arm gets it.
2. Project each checker response onto its declared package before use. Irrelevant default fields cannot override unrelated facts.
3. Materialize a verified ledger, calculate eligibility and utility once, then enforce that final rule identically for every arm. The model chair receives the scorecard and proposes a choice; proposal errors/disagreement remain visible. This changes decision authority and is a new architecture, not a claim that prompts alone were repaired.
4. Qualify clean/superior controls in all three domains on fresh task 7200, not the previously tuned task 7100.
5. Use lower exposure and eligible/ineligible task variation in the procurement diagnostic. Travel/dependency are competence probes, not independent demonstrations of transfer.
6. Retain all raw events, add call indices/request hashes/timestamps/environment versions, and distinguish live progress from final figures and post-hoc counterfactuals.

## Assignment and stages

S0: three domains × task 7200 × clean/superior × random/targeted × seed 23 = 12 outcomes, 180 nominal calls. Gate: all valid and committed-correct under the enforced architecture. Separately report whether the model chair itself followed the rule. These checks qualify the instrument, not attack resistance.

S1: procurement tasks 7300–7302 × misleading worlds × doses 2/8 × random/targeted × seed 23 = 12 outcomes, 180 nominal calls. Analyze each exposure separately and aggregate differences by truth task only. Holdouts 9000–9999 remain unopened. Do not select favorable worlds or repeat adverse scientific results.

Engineering: 1,200 scripted outcomes across three domains, eight truths, clean/misleading/syndication/superior controls, doses 2/4/8 and five arms. Scripted outcomes are tests of the instrument, not LLM evidence. A separate positive control at full contamination must flip the unverified baseline and be repairable by scoped fresh checks; stale/unavailable controls must remain distinguishable.

## Measurement and authority

Keep original truth-based correctness, harmful choice, constraint violations, coverage and regret. Add chair_proposal_correct and chair_rule_disagreement. Brier loss scores the proposal's confidence against proposal correctness, not enforced correctness. Retain source support and propagation diagnostics; missing replies never count as clean evidence or correct decisions. A normalized ledger can still choose incorrectly if its observed or verified facts are wrong; rule enforcement is not truth enforcement.

## Failure handling and budget

One transient HTTP retry, with another conservative reservation, only for status 429/502/503/504. Maximum 720 possible request attempts for 360 logical calls, but an USD 8 non-overlapping subquota is the hard stop; nominal maximum is USD 6.34752, all-retry maximum would be USD 12.69504 and therefore cannot be authorized under that quota. Report budget-truncated assignments as failures, never drop them. No hidden auth/parse/outcome retries. Durable raw artifacts survive reporting problems; upload repair must not repeat model calls.

The USD 8 is not allocated yet. It must be atomically reserved from the existing common USD 45 authority before a dedicated host uses it, with the lease bound to that host. No new API budget or server purchase is authorized by this file. Machine allocation, public plan validation and pre-run assessment must be complete before paid queueing.

## Interpretation and gates

Valid null/adverse outcomes finish a sound diagnostic. Execution defects require evidence-preserving repairs and new attempt IDs. No model call may be made only for visualization. A successful deterministic replay is not live qualification. No broad robustness, real web search, realistic supplier reliability, domain-general transfer, or increased-agent-count benefit is established by this design.
