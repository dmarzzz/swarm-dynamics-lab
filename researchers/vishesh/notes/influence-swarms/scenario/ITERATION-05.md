The latter removes reports and retrieved-check interpretations; all primary documents and arithmetic worksheets remain identical. Label the intervention a context package, not a pure vote ablation.

Each workflow uses one fresh reviewer and one unchanged standard chair: four workflows ×six cases ×two calls =48 nominal calls, at most96 transport attempts,24 terminal decisions. Rotate the four-workflow order by case index. All use the same pinned Haiku snapshot, input/output limits, primary evidence, buyer policy and fresh stateless calls. No previous chair answers, evaluation truth or model outputs from another workflow reach an actor. Retain choice/confidence and a recorded-only verification request in both reviewer contracts. Typed format, evidence checking and computational receipts are a bundled intervention; no claim isolates JSON format alone.

Typed extraction records regions, SSO/export, seat/outcome/setup prices, simple/complex pilot counts and three sequential rollout stages, grouped by primary document. Each group supplies one document ID and an exact supporting excerpt. Values may be null; unknown confirmation remains unknown. Bounded notes name limitations or future verification, and do not change policy. The program checks candidate/document association, exact excerpt membership and extracted-value alignment with the labelled fields in that excerpt. A mismatch is retained and becomes unknown evidence, not substituted with the correct source value. This validator is specific to the synthetic document grammar; it is not a general semantic verifier. Its expressiveness limits must be reported.

One versioned buyer-policy object supplies the comparison operators, thresholds and cost definition. Decimal arithmetic derives weighted automation, annual software-only cost, rollout days and total annual operating cost. Every requirement receipt contains policy clause, observed/required values, source IDs, status and reason. UNKNOWN and FAIL both block purchase, but identify different missing facts versus demonstrated failures. No mitigation prose or future plan can clear a failed/unknown check. All candidates are evaluated before deferral; limitations about drift do not create an extra service threshold.

The chair sees the original records plus that workflow's reviewer/check receipts. Its raw action is retained. Separately, a purchase-authority function authorizes only a candidate with all mandatory checks PASS and a supported cost within the policy's tolerance among eligible candidates. DEFER stays DEFER; the gate does not silently choose another supplier. Record eligible and cost-acceptable alternatives when a raw DEFER is unnecessary. Matrix authorization remains dependent on model classifications; typed authorization depends on the limited excerpt validator. Neither substitutes evaluator truth.
