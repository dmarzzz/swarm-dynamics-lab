# D10 proposal: can chairs use better verified evidence?

**Prepared for an owner decision; not authorized or launched.** The proposed provenance contract changes how evidence enters the decision, so it is a scientific revision rather than another transport repair. Researcher sign-off is not required.

## Why this experiment is needed

D9 separates three failures that should not be confused. The model extracted all 180 fact values correctly on five valid development responses, but fabricated or spliced quotations caused the existing verifier to admit only 98 values and produce 41 correct checks out of 75. Citation-bound verification produces 75/75 correct checks on those same saved responses, while refusing unsupported values and retaining quotation defects separately. This offline result answers the mechanical question already; spending money to repeat it would add little.

The remaining empirical question is whether a chair actually uses that improved report when the inherited team advice contains mistakes. Better intermediate checks need not produce a better decision: a chair may follow earlier advice, invent a blocker, or endorse an ineligible option. The next comparison measures this downstream behavior.

## Exact design and limits

Use the **five contract-valid, saved D9 responses**, each with two chair continuations: the original exact-excerpt verifier and the proposed cited-document verifier. Ten physical calls, zero retries, maximum reservation USD 0.486400. Do not recollect the reviewer responses. Retain the sixth first-attempt contract failure in the cohort accounting; do not silently replace it with a later repair response.

The five cases cover two situations with no approved deployment, two with an approved option, and one with a genuinely useful promoted offering. These are inspected, synthetic procurement cases selected during development. They are neither five unrelated domains nor holdouts. Five paired case clusters support a development decision, not a population estimate, rare-failure rate, or proof of influence resistance. A single case changes the paired success rate by 20 percentage points.

Hold fixed the original dossier, buyer policy, six inherited reports, model/provider, temperature, output cap, chair instruction, report position and number of model calls. Each continuation starts from its frozen input with no cross-condition memory. Alternate which condition is dispatched first by case index. Present reports through the same interface, normalize diagnostic reason wording, and keep condition labels and evaluation truth out of actor inputs. Only which declared values the verifier admits, and the resulting checks/arithmetic, vary.

The proposed verifier checks a declared value only against the model-selected candidate/group source. It does not search other sources, fill missing values, select a different candidate, treat unknown as approval or use evaluator labels. Keep the raw quote and its exactness score in the audit; do not manufacture a corrected quote. The current parser understands the labelled synthetic record grammar. General document understanding and malicious primary-source authenticity are explicitly untested.

## Measurements and decisions

Primary endpoint: source-policy-acceptable **raw chair choice**, paired by case. Also report raw ineligible purchases, necessary and unnecessary deferrals, cost-acceptable choices, acknowledgement of source blockers, and the first visible divergence from the verified report. Grade the separate action guard independently; a safe guard must not turn a mistaken raw choice into a claim of model competence. Show absolute success, wrong-choice and abstention counts, not only a treatment difference.

Retain every request, response, wire hash, finish reason, served model/provider, usage, source report and score. A transport, route, incomplete-response, schema or usage failure stops collection immediately; remaining assignments stay unstarted. No retries, truncation, fallback model, response repair or replacement case. Analyze failures separately and show the complete ten-assignment denominator. Use deterministic source scoring and saved-data replay; inspect all ten visible answers. No significance claim from five clusters.

If accurate reports improve raw choices without creating unsupported purchases, prepare a genuinely new scenario challenge before broader study. If checks improve but decisions do not, stop expanding this verifier and investigate report uptake or chair authority. If the comparator already performs perfectly, treat the comparison as a ceiling result. If source binding admits a wrong fact, stop and repair offline. If acquisition fails, close the attempt and do not automatically try again.

No new machine is needed if an eligible existing allocation is available. Allow roughly 30–60 minutes for final admission, bounded execution and trace review, with provider latency uncertain. A broader full swarm experiment still needs fresh challenging scenarios, a real influence/control contrast, adequate independent samples and a separate prospective decision. The D9 diagnostics do not qualify that broader claim.
