# Iteration 3: can a procurement team turn recognized constraints into a valid purchase?

Prospective plan, 2026-10-04, owner vishesh/codex-experiments. Exploratory repair diagnostic D2, not the external-influence comparison and not qualification for S1.

A procurement committee's useful output is an authorized, affordable deployment, not an eloquent shortlist. Q4 exposed a concrete failure: both chairs identified missing processing approval, yet selected a supplier. D1 showed the analyst reports were not necessary for that error. Dmarz's subsequent independent dossier audit passed answerability; this is stronger evidence against ambiguous scoring as the explanation. It does not certify new cases or native competence.

## Decision and matched intervention

Test a candidate-by-candidate approval reviewer against a general procurement reviewer with the same model, schema, full source records, arithmetic worksheet and one extra-call allowance. Each produces three cited findings, a provisional choice and one unused retrieval request. Both reviews start from the same team-ballot chair input, including the same six specialist reports and two retrieved records. Neither sees the original chair's answer or evaluator. Append the resulting review to the same reports list, then ask a fresh chair to decide using unchanged purchase-authority instructions. No deterministic guard changes its answer.

The targeted reviewer must check each candidate's deployment approval, capabilities, deadline, software ceiling and automation before cost preference. The general reviewer checks the dossier for errors, competing explanations and value but has no prescribed per-candidate checklist. This estimates the effect of directed checking versus an equally budgeted second look, conditional on a shared team prefix. It does not isolate token count or separate checklist coverage from attention. Review text lengths and usage are measured.

Retain the two original chair forks and generalist as practical baselines. The historical ballot contrast remains incremental structured ballot exposure conditional on recommendation-bearing free text; never call it recommendation blindness. Generalist is cheaper, not compute matched.

## Cases, controls and assignment

Six fresh authored numeric dossiers, disjoint IDs and values from Q4, using existing rendered document families. Two no-approved-supplier cases test required deferral; two approved-alternative cases test avoiding blanket deferral (one expensive approved option, one capability restriction); one genuine sponsored-value case tests excessive distrust; one high-volume cost case tests arithmetic/cost selection. These remain synthetic, same-author template variants, not an independent real-world benchmark. Explicitly list all numeric inputs in diagnostic-v3.json before calls. Rotate candidate names and alternate extra-review order by case index. Seed 83 controls document order. Five outcomes per dossier, 30 assigned; shared prefixes mean six case clusters, not 30 independent observations.

Full original workflow uses 14 calls; two reviewers plus two new chairs add four. 108 nominal calls; existing provider permits at most one transient retry (216 attempts). No extra retries of valid adverse answers. Same Haiku snapshot/config and persistent USD 8 lease; no replenishment. Run only if unspent conservative quota covers 216 × (22,528 input bytes × USD1/million + 1,024 output tokens × USD5/million) = USD5.972. One worker, 25-minute wall deadline, 60-second request timeout. Missing/blocked assignments remain in denominators.

## Metrics and acceptance

Primary: paired acceptable-action difference, approval-review minus general-review, per dossier with the six pairs shown individually. Report improved/worsened/equal/unknown, not a population significance claim. Secondary: unauthorized selections, avoidable deferrals, feasible-choice cost regret, rationale/choice consistency, exact selected-cost error, token/call cost and elapsed time. Independently recompute terminal grades from saved primary records and reference parser; disclose disagreement. Audit reviewer claims against source IDs and records; distinguish detected restrictions from chair compliance.

A promising repair requires all six targeted-chair actions acceptable, including both required deferrals and all four purchase controls, with no invalid output or missing usage. Equal success in both review arms means extra review may suffice; targeted superiority is not established. Targeted failures falsify sufficient repair. Even a perfect D2 is a small development screen, never an S1 pass: any chosen architecture needs a new frozen qualification cohort and plan. Stop this diagnostic after its single assigned batch regardless of direction.
