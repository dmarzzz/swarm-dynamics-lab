# Scale qualification: model roles before team size

Prospective implementation refinement of PLAN.md after D10, before new-model calls.

## TLDR

Can GPT-6 Sol and GPT-6 Luna produce usable procurement advice, extract source-backed facts and honor buyer-specific purchase conditions? Each receives three roles on three inspected cases: nine independent calls per model, no retries. Compare roles and models descriptively. Require complete acquisition, 108/108 source-aligned correct auditor facts, 45/45 correct candidate checks, no wrong accepted facts and correct final authorization on all three chairs. Ordinary advice is provisional; score it without mistaking it for purchase. These are development checks, not holdouts or a model leaderboard.

## Question

D10 yielded valid transport but only 2/5 correct raw choices per interface. Correct reports alone did not fix missing-approval or cost-category errors. New model qualification must separate response validity, factual grounding and decision competence.

## Setup

Frozen development cases: regional-no-approval, renewal-approved-option, sponsored-service-value. Use primary buyer records from the original D5 packet, without inherited peer advice. Ordinary opinion sees the complete primary dossier in this isolated role test; the subsequent team instrument must qualify its partial-dossier/revision behavior offline and retain that limitation. Chair sees the same primary records, visible arithmetic in a compact report of the previously collected valid D9 facts under the source-bound verifier. This is saved native evidence, not a new model auditor response or hidden evaluator truth. Auditor receives original complete typed contract with shared definitions and a concise limitations instruction. No replacement of errors by expected answers.

Exact standard OpenRouter routes: openai/gpt-6-sol and openai/gpt-6-luna, provider only openai, no fallback, maximum prices respectively 2/10 and0.1/0.5 USD per million input/output tokens. Reasoning effort none; no temperature parameter; strict JSON schema; no tools or streaming. Preserve the served provider/model and raw output. Catalog access does not count as successful qualification.

## Protocol

Freeze nine wires per model, case-major opinion/auditor/chair order. Run Luna first as the lower-cost interface discriminator, then Sol. Each stage is separately published/registered and admitted. Stop at first acquisition, contract or usage failure; preserve unstarted requests. A scientific error may complete the fixed cohort but fails that model's scale admission. Do not reroll a failed cohort; any necessary repair diagnostic states its changed mechanism prospectively.

No extra researcher approval. Current account, exclusive allocation, immutable public plan/readback, source/runtime, original budget and exact packet gates remain. Existing diagnostic authorization covers necessary interface repairs within the remaining budget, not an increase or favorable-result search.

## Metrics

Each auditor:36 raw facts,36 source-aligned facts,15 source-truth checks, wrong accepted count. Each opinion: preferred choice and cited claims, provisional only. Each chair: raw acceptability, violated constraints, unnecessary deferral, source-bound guard result and rationale. Record cost, latency, physical attempts, missingness and provider. Three development roots per model; roles are dependent observations, not nine independent samples.
