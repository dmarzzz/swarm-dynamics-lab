## Three failure points and intended decision

D2 reviewers omitted alternative candidates, made false cost/requirement claims, and sometimes acknowledged a blocker while authorizing purchase. These require separate measurements. A complete JSON object is not proof of a correct assessment; a correct assessment is not proof that the chair obeys it. Test whether schema-required coverage and a separate consistency instruction repair these two transitions without replacing the model's choice with the evaluator's answer.

D3 reuses all six frozen D2 team-ballot chair observations as development diagnostics. Parent cases and requests are hashed. Do not rerun analysts or reveal old chair answers. These are deliberately previously inspected cases, not fresh evidence of generalization. Collect two fresh isolated reviewer responses from the same observation:

1. **Narrative → standard chair:** targeted candidate-check instructions with the existing findings schema, then unchanged chair instructions.
2. **Matrix → standard chair:** require one keyed entry for each candidate, with deployment scope, capabilities, rollout deadline, software-only budget and service coverage classified PASS / FAIL / UNKNOWN; supplied document citations and a short note. Retain provisional choice/confidence so removing a preference is not an unacknowledged extra treatment. Append this report to the same chair observation.
3. **Same matrix → consistency chair:** fork the exact same matrix and chair observation, adding only instructions to select among candidates supported on every requirement, check that the final action agrees with those assessments, and consider other eligible candidates before deferring. Primary sources can correct a mistaken assessment; any override must be explained. No postprocessor alters the action.

Review format necessarily changes schema and formatting instructions; report length/attention remain bundled. Both reviewers use identical model, evidence, maximum input/output allowance and one call. Matrix chairs share the identical reviewer response; their only intervention is the consistency instruction. Alternate narrative/matrix generation order and chair fork order by case index. Each case uses five calls and three final decisions: 30 nominal calls, at most 60 transport attempts, 18 outcomes. No valid-answer rerolls.

## Measurements and acceptance

- Coverage: all 3 candidates × 5 requirement fields present, with supplied citations. Schema validity is operational, not semantic accuracy.
- Check accuracy: compare all 90 matrix statuses with a separate source-derived assessment; UNKNOWN is distinct from FAIL. Verify citations identify supplied records and show notes for inspection; identifier validity does not establish entailment.
- Action: source-scored acceptable purchase/deferral, named constraint violations, avoidable deferral, cost regret and cost-claim error. Record raw contradiction with the model matrix separately from source-scored error.
- Practical use: reported tokens/calls/spend, response latency, and a shadow execution gate that refuses purchase when any selected-candidate status is not PASS or the checklist is malformed. Gate uses model-reported checks only, has no gold access, does not substitute an alternative, and can wrongly defer or miss falsely reported PASS. Keep raw and guarded actions separate; never call mechanical enforcement improved reasoning.

Primary comparisons are paired matrix-standard minus narrative-standard, then consistency-chair minus matrix-standard. Show every pair. Six reused clusters provide diagnostic evidence, not a population estimate. Preserve invalid/missing outcomes and all parent failures.

A candidate repair must have 18/18 valid decisions, no missing usage, all 90 matrix statuses correct, and all 6 consistency-chair actions acceptable before advancing to D4. If this strict development criterion fails, report which stage fails; no broad influence sweep or repeat-until-pass. D4 is conditional only: freeze six new authored numeric configurations before D3, reuse the same templates with new IDs, rotated names and changed numbers.
