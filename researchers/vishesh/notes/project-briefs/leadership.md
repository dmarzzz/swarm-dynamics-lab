## Background

Talkativeness, centrality and influence are different. A coordinator may send many messages without changing the outcome; a quiet agent may supply the one decisive observation.

## Closest prior work

- **Embodied LLM Agents Learn to Cooperate in Organized Teams · 2024** — https://arxiv.org/abs/2403.12482  
  Tests organization structures and designated leadership in embodied tasks. It provides an intervention-based precedent for comparing teams.
- **Anthropic’s multi-agent research system · 2025** — https://www.anthropic.com/engineering/multi-agent-research-system  
  Describes an orchestrator-worker production design. Task decomposition and delegation are concrete mechanisms to inspect.

## Where it applies

Identify bottlenecks, replace fragile coordinators and understand whose evidence actually changes a shared decision.

## The angle

Compare a communication graph with matched runs in which one message is withheld. Use interventions on synthetic tasks before interpreting real trace centrality.

## What to watch

Withholding a message changes downstream histories. Use repeated matched runs and describe the intervention precisely.
