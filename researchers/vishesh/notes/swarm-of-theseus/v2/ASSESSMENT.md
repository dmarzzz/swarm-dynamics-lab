# Iteration assessment against the plan

2026-10-04 UTC. No v2 model experiment attempted. No new API spending. This is an implementation/design assessment, not a post-hoc experiment plan or an empirical post-mortem.

## Judgment

The concern about overhyping the original result was justified: correct supplied rules plus shared memory make a weak test of useful cultural survival. The improved study now tests selective correction across descendant generations and a feedback interruption. It is more discriminating and practically interpretable, but its novelty and usefulness remain unproven. No claim that these are the globally best three scenarios is warranted.

The user-requested X review in [SOCIAL-GROUNDING.md](https://github.com/dmarzzz/swarm-lab/blob/addecbcd43ee6f07993db2f3f4578ef2aab356e1/researchers/vishesh/notes/swarm-of-theseus/redesign/SOCIAL-GROUNDING.md) informed the changes: weak verification and stale handoffs motivate release checks; unreliable or accumulating memory motivates curation; file portability without behavioral evidence motivates the console intervention. The incident-specific selective-hazard construction is our extrapolation, not a result from those threads. Hughes's research thread already establishes generational transmission as prior art. Vendor/practitioner anecdotes are motivation, not benchmark evidence.

## Remaining gaps

1. Actual model competence and adapter/schema behavior are untested for these new prompts. S0 must pass before S1.
2. A budget-matched single controller is absent. No special swarm advantage can be claimed.
3. Model-family/runtime changes are deferred. Interface renaming is a narrower diagnostic.
4. Finite rule patterns, synthetic costs and four primary paired worlds limit generalization and precision. A null or ceiling is a valid result.
5. Evidence tagging also changes writing instructions and attention. Equal calls/length ceilings do not isolate a pure provenance mechanism.
6. The common feedback interruption is deliberate. A result may depend on it; uninterrupted-feedback sensitivity remains future work.
7. Full prior-art gate and independent researcher review remain incomplete; this stays an exploratory hunch in notes.
8. Live worker support is measured hub progress; final PNG/replay generation is implemented. Automated final artifact upload and deployment verification remain operator steps, to be checked before paid launch.
