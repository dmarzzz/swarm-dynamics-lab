## TLDR

Can a learned, useful consultation practice survive complete founder replacement in a connected 50-member institution? Compare direct interactive predecessor teaching with equally bounded static handover, broken inheritance and retained founders. Score unseen joint decisions, native consultation edges, evidence provenance, harmful approvals and useful service before, midway through and after turnover. A deterministic single controller using learned founder notes and an exact reference establish strong practical baselines. One paired institution is a scale/feasibility pilot, not50 independent samples or evidence of general cultural survival. Model: exactly GPT-6 Sol, no fallback.

## Question and prediction

Prediction: qualified founders' acquired local consultation routes and evidence-checking practice can be transmitted to fresh successors; inherited institutions retain more correct useful service than broken inheritance. Interactive teaching may help compared with static notes; no directional advantage is required over retained founders or the controller. Support justifies independent-world replication, a null says explicit teaching may add no value, adverse results favor a simpler controller, and qualification failure stops collection for post-mortem. Existing isolated chains cannot establish collective interaction; increasing their length alone is insufficient.

## Setup

Fifty active logical seats form a randomly relabeled connected directed ring. Each seat requires current signed attestations from its two adjacent specialists before authorizing its local operation. Edges overlap across the whole institution: every member serves as both decision owner and witness for two peers. The institution's practice is learned from labelled private founding episodes. Generic instructions specify legal messages and named-field semantics but do not give its hidden routing map. A public current roster maps stable seat labels to current identities; it contains no consultation edges or learned policy. Stable seats are organizational positions, not persistent agent memory.

Each native context is isolated. Actors have only their own bounded note, their current observations and addressed messages. They cannot see the operator, full world, gold labels, future episodes or evaluation archive. A retiring member teaches only its immediate successor, then its context is inaccessible. At50 replacements all founders are retired. Fifty active members implies100 identities over a turnover per replacement arm, not50 simultaneous API requests. Scheduling is deterministic with bounded concurrency; parallelism is not the intervention.

The task spans three prespecified checkpoint strata inside this single world: clean allow/one-peer veto; stale/missing/conflicting reports; and a prospectively specified responsibility change supported by fresh labelled local evidence. Reassigned roles receive sufficient new evidence; preservation of unchanged routes and correct revision of changed routes are separate endpoints. Synthetic operational analogues are not real-world organizational field evidence.

## Protocol

1. Validate typed observation fields, semantic teacher declarations, copied-evidence provenance, private contexts, lifecycle and all baseline truth tables offline. Earlier Q0 cases are development material, never fresh holdouts.
2. A bounded qualification uses one disjoint five-member world and explicit clean/adverse cases to test acquisition, native two-peer request/response/decision coordination, and one complete handover. Require every clean qualification unit to return the correct route, supported note and all actions, with valid contracts and no accounting error. Fail closed; no retries or threshold relaxation.
3. Conditional on qualification, acquire all50 founders. Each must pass its declared route/evidence/action gate. A founder failure stops expansion; do not replace failed seeds or select a successful roster.
4. Fork the exact founding checkpoint into interactive apprenticeship, matched static handover, broken inheritance and retained-member controls. Replacement order is paired across replacement arms. Each replacement has at most3 calls: teaching continuation, learner inspection/question and final commitment. Interactive teacher sees the learner question; static teacher does not. Both receive the same note/message capacity and call allowance. Broken inheritance receives no predecessor note or reply but retains the same allowance for current-evidence re-evaluation; unused calls are recorded, not spent as dummy work.
5. At0,25,50 replacements, run a connected consultation round: each of50 owners selects two witnesses; each of50 witnesses answers its incoming addressed requests from private current observations; each owner makes its final decision from returned receipts. Three calls per active member per checkpoint are a maximum, not three separate agents. Score native actions without software correcting them. Keep repeated stages nested in the one world.
6. The retained group uses the same current episodes, private memory capacity and compute allowance. The simple deterministic controller receives the aggregate learned founder notes, makes the same authorized witness lookups and updates only from the same fresh demonstrations. It has no hidden routing oracle and no model calls. This tests whether straightforward structured institutional memory already suffices. A native GPT controller comparison is deferred; no native-swarm-versus-native-controller superiority claim is supported. The exact reference demonstrates the attainable truth-table ceiling and a memory-free refusal baseline exposes refusal-only success. Neither is claimed as emergent culture.
7. Stop at the first provider/accounting ambiguity, failed admission, deadline or cumulative bound. No automatic retries, substituted model or successor. Reconcile and post-mortem all assignments, including unstarted dependencies.

## Frozen communication and leakage controls

Each witness can attend to at most two owner requests per checkpoint, each bundling six cases. Requests are admitted in the same deterministic owner order across arms; overflow is logged as unavailable communication, never silently serviced for one arm. Correct learned ring routing exactly fills every witness capacity. Incorrect routing can produce congestion; report overflow and lost service separately. This is a declared capacity consequence of routing, not a hidden input truncation.

Successor commitment receives no answer-bearing test panel: only its inherited messages (none in broken inheritance), current roster and empty private successor context. Behavior is evaluated later through actual consultations. Teacher declarations are scored for correctness; in the main pilot a bad lesson is transmitted and counted as a failure, not repaired or silently dropped. Qualification stops on a bad lesson. Public generic rules define evidence validity; what is learned and transmitted is local routing and application, not the invention of those rules.
