## TLDR

Can a learner recover a hidden class-to-source policy from eight labeled examples and use the frozen R1 F executor on held-out cases? Compare learned-policy F with true-policy F on six fixed acquisition worlds, two task families, eight test cases each. Measure exact policy recovery, content-valid evidence citations, held-out actions, harmful activations and useful releases. Up to204 native calls. This tests a prerequisite for culture, not a swarm or a novel learning algorithm.

Predict exact recovery on these deliberately identifiable finite tasks, without treating that prediction as observed. Existing D2/R1 records supply the answer to actors and cannot answer this question. An enumerating solver is the exact learning baseline and tests identifiability offline; native collection is useful only to qualify the intended model acquisition component.

If acquisition and clean execution pass, freeze the checkpoint architecture for a separately planned selective-inheritance comparison. If learning fails with a passing ceiling, classify extraction, citation and execution errors and stop this attempt. If both are perfect, report a prerequisite ceiling, not swarm benefit. Missingness or inadequate controls yields inconclusive qualification. No automatic expansion or rerun to improve results.

## Setup

Six fixed world roots7300–7305 cover all six ordered distinct source mappings for classes A/B; all are fresh relative to D1/D2/R1. Development seeds8300–8305 are separate. Two families per root: release requires governing signal AND freshness; incident activation requires governing signal alone. Sources are probe, ledger, canary. Eight training cases and eight test cases per root (four per class), shared across task families. Source evidence covers each Boolean signal/freshness combination exactly once per class in each split.

Construction is fixed before sampling: independently permute four Boolean pairs for each source, rejecting draws unless each source's release-positive row is distinct and each source's incident-signal vector is distinct. Reject test sets sharing a full class/evidence pattern with training. Opaque IDs, summary and queue are randomized nuisance variables; they cannot encode the mapping. This is a coverage-designed finite panel, not six random draws from real organizations. Holdouts are fresh combinations within a known rule family, not a new domain. Selection uses no native answers.

The learner sees the known rule family and all eight historical observations with binary outcomes. Incident history says activated/quiet and never names the source actually used; source-valued outcomes would leak the mapping. The true mapping and test cases remain evaluator-only. Learner returns mapping A/B plus a list of historical IDs supporting each choice. Evidence support is checked semantically: cited same-class rows must uniquely distinguish the chosen source from the two alternatives. Correct IDs alone are insufficient.

One learning call per root/family (12 total). Its policy is frozen before held-out calls. Learned-policy F receives only that mapping, the current single case and existing F instructions/schema; it gets no history, feedback, truth or operator context. True-policy F differs only in mapping. Their eight cases are paired. Both are fresh stateless calls. No notebook, communication, replacement, voting, retry, provider fallback or native repeats. Pinned model claude-haiku-4-5-20251001, temperature0, max output1200, original F interface otherwise unchanged.
