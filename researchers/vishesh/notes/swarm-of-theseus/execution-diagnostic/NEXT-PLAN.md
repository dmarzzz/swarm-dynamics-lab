## Next experimental design improvement

Separate **learning a policy** from **executing it**. The repaired executor has only been tested with the correct mapping supplied. Using that ceiling as proof of acquired culture would be a design error.

The next concrete proposal is an acquisition screen before any turnover experiment: six fresh worlds with all six source mappings, both task families, eight labeled historical cases and eight held-out cases per family. A learner receives historical observations/outcomes and the known rule family, but no true class mapping. It returns a structured class/source policy with supporting historical IDs. Freeze that policy before held-out decisions; do not correct it using evaluation feedback. Feed its policy to the frozen F executor, and compare with an explicit-correct-policy F ceiling. Keep these actor roles and context boundaries separate.

A lean first allocation would use 12 policy-learning calls, 96 learned-policy executor calls and 96 explicit-policy ceiling calls: 204 calls total, six paired worlds and 96 distinct evaluation case/family pairs. These counts are a proposal, not admitted assignments or a promise of adequate population precision. Before implementation, freeze new training/evaluation seeds, show that histories distinguish all candidate mappings, specify full rule/action gates and missingness, and calculate a conservative reserve inside the remaining cumulative authority. If history cannot identify the mapping, repair the generator before exposing a model. No existing D2/R1 failures become held-out evaluation cases.

## Return to the cultural question

If acquisition qualifies, test **selective inheritance**, not generic access to memory. Start with one changing-rule scenario before scaling three stories:

- One class's learned rule becomes obsolete while another stays useful; successors must change the first and preserve the second.
- Compare editable inherited notes with frozen founding notes, no inheritance and a single controller matched for information, calls and token limits.
- Include full private-context replacement versus no replacement. Incumbents must actually possess private observations unavailable to successors, so replacement is a real intervention rather than a renamed stateless request.
- Fork all arms from the same acquired checkpoint. Descendants do not receive founder training packets or the true current mapping. Score transfer before feedback and adaptation after equal feedback; a common feedback interruption can test whether corrections survive the next full replacement wave.
- Keep wrong inherited advice and console migration as later mechanism-specific extensions. Neither should be bundled into the initial inheritance contrast or advertised as a novel domain merely because labels change.

The primary cultural endpoint should require both correct retention and correct updating. A static archive win over no memory is a useful baseline, not the main contribution. A matched controller tying the swarm is a valid result. Do not infer swarm-specific benefit from a majority-vote scaffold.
