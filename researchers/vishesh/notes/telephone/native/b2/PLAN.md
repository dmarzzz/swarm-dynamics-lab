## Practical question and claim

For twelve explicitly authored operational decision scenarios, how does three-step lossy handoff compare with giving each successor the original source alongside the prior handoff, using one model and identical task/output limits? Does the direction and practical size of the difference reproduce in a second fresh execution block?

The decision is whether to retain source access for operational handovers or accept summaries alone. This is a practical information-policy comparison: source access deliberately supplies more information and may cost more input tokens. It is not an equal-information coordination effect, a model effect, a causal effect of fifty agents or a population-general claim. Lossless copy is a strong zero-model preservation baseline; if it is sufficient operationally, recommend it. LLM handoff superiority over copying is neither assumed nor required.

## Arms, contexts and native assignments

## Endpoints, precision and fresh replication

Primary endpoint: terminal decision correctness on each root, paired R minus P, reported separately for both fresh blocks and as the mean of each root's two paired differences. Distinguish false GO, false HOLD, UNKNOWN, invalid and missing. Secondary: all-hop source-target retention, unsupported critical additions, first loss, actual input/output cost and latency. Score every target and factual assertion using frozen report-content and strict status-integrated sensitivity rules, with two documented same-operator passes. Counterfactual rule gold determines decisions; human semantics and scoring ambiguities remain visible.

Independent scenario units: twelve intentionally constructed roots, not 144 calls or twenty-four repeat trajectories. They share an author and selection procedure; no random-population independence is asserted. Report all per-root cells, block-to-block differences, agreement/disagreement, range and dispersion across roots. Twelve cases give 8.33 percentage-point resolution per block; two blocks are a minimal reproducibility check, not a precise variance estimate. Any root-resampling interval is explicitly exploratory and conditional on these selected cases, never a population guarantee. Do not call the effect stable merely because two noisy point estimates have the same sign.

A credible baseline requires complete case acceptance, competent simple/direct-source comparators, trustworthy collection/scoring, and a practically interpretable repeated pattern (including stable null or harm). Evaluate the full pattern and limitations after both blocks; no guaranteed BASELINE MET label from a completed run. If disagreement is large, report instability and propose any further repetition separately. Missing outputs receive null semantic scores and explicit denominators; bracket assigned decision contrasts with worst/best missing outcomes. A transport/accounting/schema failure halts the packet with descendants marked unstarted; no paid retries in this proposal.
