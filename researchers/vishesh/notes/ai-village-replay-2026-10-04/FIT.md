## Best fit among ideas we have not run

**Telephone is the strongest existing unrun brief.** It directly asks where claims change across retellings; this corpus contains chat, memory and action traces that can potentially connect those stages. The brief remains a hunch; this assessment does not assert all required links exist. [Concrete development plan](TELEPHONE.md), [original brief](../project-briefs/telephone.md).

| Unrun brief | Fit judgment | Useful bounded question / why not first |
|---|---|---|
| Telephone | Best | Can explicit trace links reveal loss of qualification, attribution or scope? Measure verified link precision before causal language. |
| Memory | Very strong | Does a correction survive the next consolidation and relevant retrieval? Overlaps the Theseus handoff pilot; share corpus work rather than create a duplicate run. |
| Casefile | Strong, cheap | Can a source-linked incident packet improve reconstruction accuracy and investigator time? Needs actual blinded human task evaluation to claim usability. |
| Leadership | Strong observational use | Separate suggestions followed by observable action from mere narration. Centrality alone does not identify causal leadership. |
| Whistleblowing | Conditional | Evidence-backed escalation and false-alarm cases are plausible; establish actual exposure and adjudicable incidents. |
| Institutions / commons | Conditional | Trace contested contributions and verification practices. Rules/incentives need an explicit intervention or authored sandbox. |
| Coordination | Conditional | Audit duplication, conflicting work and wait states. Message volume cannot stand in for effort or reliable cost. |
| Culture / regrowth | Conditional | Natural onboarding/memory informs scenarios; arbitrary convention and turnover effects require controlled histories. Theseus already covers much of this. |
| Collective sensing / diversity / quorum / dissent | Reuse existing lines | Good evidence stimuli; topology, source independence and matched resource allocation remain controlled-design work. |
| Discovery | Weak | One known AI population lacks representative human/ordinary-automation controls. Do not infer real-world agent detection performance. |
| NCA observatory | Poor | No useful cellular-state trajectories or relevant perturbation ground truth. |

This is a review of the sixteen local briefs and study registry, not proof that no related work exists elsewhere. No completed prior-art survey or accepted new hypothesis is claimed.

## Strong new direction: acknowledgment is not correction

Measure the difference between **verbal closure** and **evidence-backed closure**: after a correction, did each affected agent's next memory and next relevant action actually change? The new decision is whether an action-backed closure rule prevents prematurely marking a multi-agent incident resolved. This adds a system-level closure criterion to the existing single-agent memory question. [Prospective hunch and feasibility design](ACKNOWLEDGMENT.md).

The distinctive opportunity is linked long-running chat → memory → observable action. A chat-only benchmark cannot check that distinction. This does not establish uniqueness among all datasets, guarantee complete chains here, or constitute a novelty claim. If complete chains are rare, merge this as a Telephone/Memory annotation dimension and park the standalone proposal.

## Actual preparation evidence

[Inventory](development-inventory.json): four file-order prefixes, 2,000 rows each, pinned revision. [Structural audit](inventory-audit.json): only **7/896** referenced chat messages and **7/283** consolidation-linked sessions occur in the corresponding loaded prefixes. File order moves backward in time roughly half the time. These are incomplete convenience prefixes, not missing-source estimates or representative prevalence measurements.

All 8,000 rows have update timestamps later than creation; the schema notes updates are often only microseconds later. This is a timestamp fact, not evidence every row was substantively edited. The builder conservatively excludes rows updated at or beyond the cutoff. Six thousand projected text records were normalized privately with visibility, redaction and availability explicitly unreviewed; **zero admitted or gold-labeled episodes**. No computer-turn or screenshot table was acquired in this phase. No source text was printed to the operator transcript, sent to a hosted model or committed.

The next acquisition should index and select a complete bounded task window by IDs, not read another arbitrary prefix and call it a cohort. Inspect all associated joins and record each absent/not-loaded/redacted component separately. Current raw prefixes remain development material permanently; later tasks sharing their artifacts/claims cannot quietly become holdout data.
