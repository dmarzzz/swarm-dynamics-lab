# Telephone: the best existing unrun fit

Prospective exploratory preparation, 2026-10-04. Extends the [unrun brief](../project-briefs/telephone.md), not a formal hypothesis or launched experiment. Source: [[data-ai-village-2026]]. No source-text excerpts are published.

## TLDR

Build a source-linked account of where meaning changes as agents retell claims in chat and memory. Compare reviewed explicit provenance with literal matching and lexical retrieval. Score edge precision, claim fidelity and unresolved coverage; similarity-only edges never become causal propagation. Start with eight development task components, conditional on complete records. This is corpus construction, not evidence that an intervention helps.

## Question and prediction

Can we recover useful, verifiable claim-transmission chains without conflating text resemblance with shared origin? The practical decision is whether a lineage-aware annotation tool adds enough correct links to justify use beyond search. Existing LLM-Culture already studies text transmission in agent networks; this proposal adds situated evidence/receipt and memory-action verification, not the invention of transmission studies.

## Setup

Select eight connected task components before looking for dramatic failures: include at least two ordinary accurate-retelling components, two uncertainty or qualification cases, two correction cases and two unresolved-source cases if available. These quotas are desired annotation coverage, not observed classes. Freeze selection rules before deeper reading; disclose if the inventory cannot satisfy them. Select based on observable trace availability, never arm performance. Keep whole linked tasks/artifacts in development. Do not count 30 links in one task as 30 independent tasks.

For each atomic claim annotate entity, proposition, quantity/unit, valid time, modality/uncertainty and attribution. Classify a proposed edge as explicit reference, evidenced access, similarity only or unknown. Explicit references themselves are untrusted claims until the referenced record is verified. Correct source identity and faithful representation are separate labels. A first observed mention is not necessarily the origin. Record missing screenshots/tool results as unavailable; narration alone cannot prove action success.

## Protocol

Use the shared private normalizer and visibility-reviewed record schema. Keep a private table of source/target IDs, cutoff, available evidence, edge category and claim-field differences; retain two separate annotation passes and disagreement notes. No reviewer approval gate is added. A single owner can do both passes but must label them same-owner adjudication, not independent review.

Recent-history and BM25 retrieve candidate evidence from the same permitted archive. Exact references and authenticated graph traversal remain strong provenance controls. An initial lexical match supplies a candidate only. Do not pay a model merely to solve supplied graph lookup. Claim-fidelity labels remain separate from automatic source matching. The newly implemented generic categorical scorer can evaluate supported/refuted/unknown judgments once gold exists; it does not yet perform multi-field lineage annotation or provide a viewer.

After development, freeze the annotation rubric and selector. A possible next qualification/evaluation uses 8 and 24 new connected components as in PLAN.md, but only after actual inventory counts and annotation feasibility support it. No such holdout has been selected or inspected in this work.

## Metrics

Verified edges / all proposed edges; resolved / all annotated targets; fidelity errors by field; unknown-source and unavailable-evidence rates; annotation/reconstruction time. Report per-component results and matched baseline differences. Retrieval recall needs an independently established eligible source set; do not invent it from the retriever's own candidates. Eight development components give coverage, not a population prevalence estimate. A 24-component follow-up remains a coarse pilot with wide uncertainty.

Acceptance for proposing paid extraction: unambiguous cutoff/visibility, complete critical joins, reproducible labels, leakage checks passing, ordinary and uncertainty controls, and an actual semantic gap not already solved by lookup. Otherwise deliver an annotated casefile and stop. No retries, model sweep, cloud allocation or dollar allowance is requested here.
