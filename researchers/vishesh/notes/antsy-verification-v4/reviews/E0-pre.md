This is exploratory S0/S1 engineering, not a gate-approved hypothesis. The template worker's deterministic/paired/blind/total contract is adapted to a single bounded worker; no S2.

Run Tesseract automatic(PSM3), block(PSM6), sparse(PSM11), each ind+eng, on identical original images. Record actual version, file hashes, TSV outputs and CPU latency. One thread/one worker,300 OCR calls maximum,30s per call,45min overall, no paid APIs. Every failure retained; no outcome retries. Exclusive sim-test-01, claim vishesh-antsy-verification-v4, two-hour allocation; verify immediately before launch. No unrelated process is stopped.

Primary corpus score: multiset normalized annotated-token recall, spatially matched to the closest eligible annotation line (word centroid within bounding box plus4px). Report exact annotated total-price text recovery separately. This is not field extraction, full-text precision, financial correctness or vendor API performance. Reference labels and OCR quality stay in the evaluator; actors receive only OCR confidence/count signals and purchased QA responses. QA is a simulated human-reference check, with ideal label accuracy explicitly assumed.
