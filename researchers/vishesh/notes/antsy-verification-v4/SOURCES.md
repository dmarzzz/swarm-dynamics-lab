# Scenario grounding

Opened2026-10-04 UTC; this is a focused design check, not a completed prior-art survey.

- [CORD primary repository](https://github.com/clovaai/cord), README and dataset specification read. Authors provide receipt images, OCR annotations and parsing labels; the released sample has1,000 Indonesian receipts. CC-BY-4.0. [Official v2 dataset](https://huggingface.co/datasets/naver-clova-ix/cord-v2) and API revision/license inspected. Use only validation100; test stays unopened. Dataset attribution: CORD: A Consolidated Receipt Dataset for Post-OCR Parsing, released by the CORD authors/NAVER CLOVA. The data are external to this experiment; configurations' winners are measured, not authored by us.
- [Tesseract command-line documentation](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html), language selection, TSV and segmentation sections read. [Quality documentation](https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html), segmentation/input-quality discussion read. These motivate comparing segmentation configurations on unchanged receipts. No claim that these modes represent different commercial APIs or independent OCR model families.
- [AWS Textract quotas](https://docs.aws.amazon.com/textract/latest/dg/limits-document.html) and [asynchronous processing](https://docs.aws.amazon.com/textract/latest/dg/async.html) opened for scenario framing: input format, size and operation mode are real routing constraints. We do not call AWS or transfer its limits/performance to our local configurations. We narrow this experiment to measured extraction quality and QA budget rather than inventing provider privacy policies.

The biological connection remains active information gathering before commitment. We do not claim receipt QA implements an ant colony's recruitment mechanism. The scientific need is empirical: determine whether imperfect, inexpensive quality signals plus a few targeted reference checks can approach an expensive per-receipt oracle, and whether a multi-agent coordinator improves that allocation over a single agent or rule.
