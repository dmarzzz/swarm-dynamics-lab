# Connection to the original sixteen directions

| Original brief | What Antsy v4 implements | What it does not establish |
|---|---|---|
| [04 · Quorum](../project-briefs/quorum.md) | A measured choice between further assessment and commitment, with fixed versus adaptive stopping on the same ballot history. | No evidence-independence estimator, provenance protection, or urgency manipulation. Counting five same-checkpoint votes is not five independent observations. |
| [01 · Collective sensing](../project-briefs/collective-sensing.md) | Complementary confidence views for three roles, shared QA, and a centralized agent with the full observation union. | No emergent sensing, spatial network comparison, or advantage caused by secretly giving the group more evidence. Two roles already see the full summaries. |
| [13 · Coordination](../project-briefs/coordination.md) | Quality, paid checks, logical calls, physical calls, latency and repair overhead are recorded separately. Simple rules can reject the need for a committee. | A high call count alone does not prove waste; it must be compared with measured gains. Hosted and local timings are not controlled hardware benchmarks. |

The later [decision-models direction](../project-briefs/decision-models.md) supplies the typed-action comparison between Laya and Jev. It is additional to the original sixteen. Each model is a separate homogeneous committee condition; this is not a heterogeneous-ensemble experiment.

The useful contribution is a reusable evaluation pattern: external tasks, executed alternatives, evaluator-only counterfactual scores, explicit purchases of information, matched cheap controls, immutable plans, and failure-preserving replay. It can transfer to API-output selection or research-resource curation only when those tasks have defensible external ground truth and a realistic verification service. Receipt results alone do not validate that transfer.
