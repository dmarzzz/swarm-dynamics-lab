## Diagnosis and decision

Haiku Q0 produced 40 identical wrong normalizations on one receipt despite varied roles. The 16-call locale diagnostic did not repair this; all visible quotes located the right token. The bottleneck is interpretation between printed evidence and amount, not lack of votes. Saved consistency checking detects the mismatch but cannot verify a new literal-token contract or image-checking capability. Test whether separating these functions reduces wrong acceptances without losing useful service.

## Matched-call comparison

For each receipt, collect four fresh-context Haiku responses. Direct readers A and B each extract a normalized payable amount using the prior prompt. Their two-call baseline accepts only if both valid responses accept the same amount; otherwise refer. The treatment uses a literal extractor (printed amount token and its label, with no normalized amount) and a separate checker that sees the original delivered image plus that token and label. The checker must confirm both exact visible token and final-payable-total label; a negative check forces referral. Deterministic code normalizes only a supported literal grammar, then accepts only after the checker confirms. Baseline and treatment each cost two calls; this is a functional decomposition test, not an independent-model or emergent-swarm claim.

The normalizer supports unsigned integers, period/comma thousands grouping, two-digit decimal fractions and consistent grouped-plus-fraction forms. In this Indonesian receipt-corpus contract a lone final three-digit group is grouping, not a fractional currency amount. Unsupported forms, signs, competing tokens and uncertain extraction refer. Record this assumption; do not generalize it to arbitrary currencies. No gold values or reference labels enter agent input or normalization. The checker is fallible same-model corroboration, not a pixel-proof oracle. Model evidence is not hidden reasoning.

Fixed per-case order alternates which arm goes first across cases. All agents receive identical image pixels, pinned Haiku4.5 through Anthropic-only OpenRouter, fresh context, temperature0.4,512-token output limit and strict schema. No peer information crosses arms. The checker receives only its treatment predecessor's explicit token/label; direct readers cannot see each other. No hidden operator context, memory, tools, provider fallback or retries.
