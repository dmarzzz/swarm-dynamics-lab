# Immune Response: peer correction qualification

**Prepared offline; no native attempt yet.** The [prospective plan](PLAN.md) describes two incident families: an external runbook recommending a repair, and a report claiming an earlier repair succeeded. Each assertion is paired with worlds where it is true and false. The common current probe makes the disagreement resolvable from evidence rather than a hidden evaluator label.

The experiment compares private reconsideration, ordinary discussion and structured evidence-linked peer notes. Initial responses are generated once per world/repeat and forked identically into all three branches. This pairs the starting mistakes without selecting only cases where contamination succeeded. Architecture-supplied probes, model-proposed inspections and actual voluntary inspection have distinct fields. The primary revision timepoint is both members' immediate post-note proposal before enforcement; later terminal actor decisions are separate.

## Offline evidence

Twelve tests pass, with zero model calls:

- Public-information comparator feasibility across 20 varied seeds/four worlds (80 scripted cases), plus full collection paths for one and two repeats.
- Actual shared initial-response hashes across all three arms; exact184/368 main-call schedules and48-call solo qualification.
- Identical source wording and catalogs within truth crossovers; identical initial observations in the failed/successful recovery pair.
- Negative controls for inaction, repeated restarts and omitted repair verification fail qualification. Blanket source trust and blanket rejection choose the wrong immediate action in their respective truth counterparts after the common probe.
- Wrong peer notes are routed unchanged, and architecture probes cannot become voluntary/model-proposed inspections.
- Missing/failed attempts retain all assigned cases. Scientific qualification binds to the source/world/model contract and refuses scripted, incomplete or mismatched receipts.
- Bounded note and prior-response payloads fit the8,000-byte contract; largest tested request7,020bytes. Future histories are still checked before dispatch.

A module-name collision in the first offline test was resolved by unique `peer_*` module names. Review also caught contradictory initial-probe attribution; the fix preserves the raw proposal while marking execution as architecture-forced, with a regression where the model did not propose inspection. Neither defect reached a native run.

The fixture truth differences are observable and consequential, but these remain **two authored roots**, not production incidents or a precision estimate. Two fresh repeats describe instability only. The treatment bundles note structure and message routing; it does not isolate provenance alone. A failure to mislead any initial agent is a valid failed manipulation, not permission to reroll stimuli. Earlier sealed cohorts are untouched and are not claimed as independent-root validation for this new design.
