## Qualification versus scientific replication

1. **Contract competence gate:** use the9 explicitly reused Q1 development cases for the repaired singleton. Require9/9 joint correct and zero unsafe attempts under the unchanged criterion. This is useful qualification, not independent scientific evidence. Stop before the scientific cohort if it fails. A team cannot rescue an incapable singleton. Existing paired-Q2 proposal remains unfunded; do not run both overlapping qualification proposals by default.
2. **Freeze12 new roots:** these must be untouched by native prompt/model tuning. Author access for label/reference validation is disclosed; “protected from model-response tuning” is narrower than independent authoring or a field holdout. Hold out entire mechanisms/source fixtures from prompt tuning. No tuned selection of easy roots after observing native answers.
3. **Fresh replication:**12 matched roots ×2 arms ×3 fresh execution blocks =72 native episodes. Each block resets worlds, agent contexts, memory, counters and output paths and resamples hosted responses. Do not reuse saved answers. Randomize arm order within each root/block with a frozen schedule, distribute blocks over at least two collection sessions, and record provider timings/versions and queueing. Equal temperature does not establish determinism. Three repeats estimate limited within-root variability; they do not triple independent n.
4. **Comparator competence:** run the deterministic public-evidence reference on every root with exact same tool semantics. Include each root’s clean and missing-evidence counterpart once per arm:48 additional native control episodes, with fresh contexts, no tuning between controls and fault repeats. Each arm must pass all24 clean/missing controls with zero unsafe attempts before interpreting the fault comparison. If either arm fails, preserve the full control cohort, diagnose, and do not dispatch the72 fault episodes under that instrument. Control variants share their root and do not add independent n. Passing them establishes only necessary restraint/evidence competence; fault diagnosis/repair remain separately measured in the scientific cohort.

The complete proposed scientific roster is120 episodes:72 fault replications plus48 native controls, preceded by the9-case reused development gate. Stop at failed gates; no replacement or retuning within the frozen cohort. The gate makes unstarted later episodes explicit rather than promising that every planned cell will necessarily run.
