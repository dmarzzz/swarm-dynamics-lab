## TLDR

First test whether native Jev can read complete synthetic land/water observations and produce a full map. If that competence check passes, compare counterbalanced early report histories under private/social decisions and reset/retained state, with pooled and deterministic baselines. Measure whole-map error bounds, label-specific competence and paired history disagreement; preserve every missing response and unstarted assignment. The native interface uses 36 named typed questions, not a free-form generated map. This is exploratory qualification and a six-world pilot; it does not test adaptive exploration, establish internal model changes or satisfy the formal research gate.

Can the deployed provider/model satisfy the clean evidence contract before we interpret history effects? ## Protocol

Q0-A1 uses fresh world seeds 200-205, three private clean reset observers per world: 18 map requests, 648 cell choices. No earlier history, peer maps or false reports enter these competence requests. Freeze the assignment hash before dispatch. Required pass: all 18 assignments terminal, at least 95% valid map responses (thus 18/18 at this small size), whole-map upper error <=10%, and upper error <=20% on each of LAND and WATER. Report raw counts (216 land and 432 water opportunities). Failure stops advancement and requires a post-mortem and new bounded diagnostic plan; no automatic rerun or tuned reuse of qualification seeds.

S0-A1, only after a passing Q0-A1, uses fresh seeds 206-211: six independent paired worlds, each with PC-1's 72 swarm, 12 pooled and 3 clean map requests. Total 522 map requests; both stages together at most 540. This reduces the original twelve-world history cohort to six to insert a separate capability gate. It is not a powered effect study. Confirmation seeds 1000-1099 remain unopened.

Use one dedicated worker, no retries, maximum 60 minutes per stage, stop after five consecutive transport/schema failures. Budget exhaustion stops before the next paid request and retains all remaining assignments as not-started. Strict round barriers keep social inputs limited to the preceding completed round. Do not deduplicate byte-identical reset requests: independent calls are necessary to measure service variability. Persist request and response hashes, sanitized responses and assignment state before/after each dispatch. On restart, never automatically retry a started/uncertain call. Calls that fail or return unknown cost retain their maximum reservation.

## Metrics
