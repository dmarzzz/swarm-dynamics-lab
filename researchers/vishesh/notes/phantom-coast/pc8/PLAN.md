## Question and prediction
The new empirical unknown is whether TypeSafe can supply useful semantic normalization of prose histories, not whether it can minimize supplied numbers. Predict lower prose extraction error than a frozen rule parser and preservation of valid reliable evidence. The representation contrast asks whether errors appear when the same facts move from explicit fields to prose. Downstream expected regret measures whether extraction differences change a verification choice; it is not assumed that every field error matters.

Decisions: if parser is perfect in qualification, retain structured capture/parser and stop. If native qualification fails or discards protected valid evidence, stop this configuration and inspect all misses. If qualified and it improves prose extraction over parser, run only the prespecified pilot. After the pilot, favor the model only for a narrowly supported prose-normalization role if extraction and downstream metrics improve without reliable-evidence harm; otherwise retain parser/structured capture. Inconclusive results do not trigger enlargement. No same-cycle repair/retry/model switch. A gain over this parser is not a claim that no better deterministic parser exists.

## Setup
Each root has six uniquely named report records and three independent calibration events from one source. A correct retained calibration says whether the source matched a noiseless reference. Distractors are exact/shared-origin copies, superseded assessments, events before the declared validity window, or unverified challenges. The acceptance rule is explicit: retain one current verified record per independent event; a later verified correction replaces an earlier assessment; receipt time does not renew an old observation; a challenge without a new verified measurement cannot invalidate the original. Actor-visible record IDs, event/origin relationships, dates and report text carry the evidence. Hidden answer labels never enter native context.

Classify every record MATCH, MISMATCH, EXCLUDE or UNKNOWN. MATCH/MISMATCH means keep as independent current calibration with that outcome. EXCLUDE rejects an ineligible copy/stale/superseded/unverified record. UNKNOWN is an explicit unresolved decision, excluded from the downstream calibration but counted wrong when a determinate gold label exists. Native packets contain all six records and the policy, but no posterior, answer table, hidden labels, owner conversation or tool access. One fresh native request per root/representation; no shared memory. Criteria/order and record order are paired within root; seeded condition order controls sequential provider drift imperfectly.

Treatment: semantically equivalent prose. Comparator: structured fields encoding the same event/origin/date/verification/correction facts, not extra truth. Strong references: frozen normalization/regex/provenance parser with synonym and negation handling; structured-field rule solver; oracle gold extraction; always-check/trust downstream. Parser is authored on development language and frozen before qualification. Reserved phrasing families are not used to tune it after responses. Its finite coverage is disclosed; no deliberately incorrect baseline, unbounded parser repair or claim of optimal parsing.

Four families: duplicate provenance, verified correction, stale observation and reliable-evidence preservation under an unsupported challenge. Each root is a separate generated report history; semantic families and phrase templates repeat. Qualification has2 roots/family; pilot6 roots/family. Both representations share the exact history. Event correctness patterns, IDs/order and cutoff dates vary under fixed generators. This is synthetic evidence normalization, not measured human reports or a collective-agent process.

The downstream controller receives all extracted MATCH/MISMATCH records as independent calibration observations, so erroneous duplication can affect its posterior. It uses the same fixed prior P(good)=.5, source accuracies .9/.3, calibration noise .1, shift probability0, and two-report horizon for every extractor. Verification cost alternates .1/.4 by root. Gold posterior evaluates the expected loss of each extractor's first action followed by an optimal second action under true gold evidence; compare to the exact gold first-action optimum. This deliberately isolates first-action regret from later policy errors. Wrong/missing extraction is not silently replaced by gold; no model policy decisions occur. Realized random truth luck is not the primary endpoint.

## Pre-run design clarification, before native data

Development showed ordinary synonyms are covered by the parser. Reserved prose therefore includes attributed preliminary unverified impressions alongside the final verified comparison. Structured records expose the same preliminary fact in a separate field, preserving information parity. The parser keeps its conservative ambiguous-polarity UNKNOWN behavior rather than arbitrarily choosing an outcome when a sentence mentions both. This deliberately tests discourse/authority resolution beyond lexical normalization; it does not establish superiority over a discourse-aware parser. No reserved outcomes have been collected or used to retune the baseline. The favorable interpretation is limited to this frozen parser and authored language family.
