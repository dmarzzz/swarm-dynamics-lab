## The working scientific position

The most useful near-term question is not whether swarms are generally better. It is **which coordination or state-management intervention improves a defined task under a defined information and resource constraint**. A single solver, ordinary voting, an indexed lookup or a conventional transaction check may be the best answer. That would be useful engineering knowledge, not an unsuccessful research session.

Voting is a serious baseline, model family is not an independence certificate, and exchanging facts does not ensure they are correctly integrated. These are bounded lessons from E1–E3, not universal rankings of multi-agent architectures. Therefore separate four observable stages: acquiring a fact, delivering it, retaining it and using it correctly. A team may fail at any one without needing a new theory of collective intelligence.

Memory repair and lineage enforcement already have direct computational predecessors (E4, E7, E8). The remaining candidate value lies in a **specific boundary**: incomplete or wrong ancestry, fresh retries of stale content, cross-task context, negative premises, delayed return, or recovery cost. First ask whether existing code already contains that comparison. Replication and implementation hardening remain legitimate contributions.

“Immune response” is a useful organizational metaphor for detection, containment, repair and re-entry. It does not establish a single mechanism. Distinguish corrupt information, an affected honest agent, an attacker-controlled instance and a contaminated shared store. Resetting a context cannot establish trust in a controller whose objective remains adversarial. Recovery means useful authorized work with bounded cumulative harm, not just quieter logs or renewed agreement.

Biological precedents suggest contrasts, not transported constants, emotions or guarantees. Read direct computational prior work before distant analogies. A compelling animation can reveal the experiment's mechanism, but visual resemblance between networks is not evidence that their state variables or dynamics coincide. For cellular work, distinguish learned local rules, training distribution and lesion regime from physical biological regeneration (E9).

## Distinctions that should survive every summary

| Do not collapse | Why the distinction matters |
| --- | --- |
| Agreement / correctness / authorized action | Agents can agree on a wrong fact or correctly infer an action they are not authorized to take. |
| Model diversity / evidence diversity / error independence | Different labels or documents can encode the same failure source. |
| Ancestry / semantic similarity / source authority | Copying, factual reliability and permission have different meanings. |
| Suspected anomaly / invalid contribution / malicious intent | Observable behavior may not identify motive. |
| Containment / deletion / functional recovery | Blocking access may stop harm while destroying needed knowledge. |
| No observation / negative observation / justified absence | A timeout or incomplete search does not establish absence. |
| New record / new comparison / scientific novelty | The dashboard's New badge only means recent publication. |
| Engineering fixture / live model pilot / confirmation | Scripted correctness does not demonstrate a model effect or generalization. |
| More runs / independent task worlds / new task families | Seeds and paraphrases do not automatically broaden inference. |
| Test passing / theorem antecedents / deployed guarantees | A test only exercises its cases; a conditional proof only covers its assumptions. |

## What remains uncertain

We have not established that our source-grouped quorum, selective repair or critic role beats simple alternatives on held-out live-model workflows. Current notes contain comparisons and hunches; this pass is not a completed survey or accepted hypothesis. Existing catalogue counts measure records, not independent corroboration. Published source metadata does not establish correctness, reproducibility or novelty.

Our most defensible first tasks have explicit truth and observable actions: constrained provider choice, versioned plan repair, conflicting edits, trace completeness and artifact verification. Their precise scoring is a strength, while their narrowness is a transfer limit. A second task rule should challenge the mechanism; three wrappers around one inequality do not provide three independent domains.

## How to update this context

Record the source or run revision, the observed result, its denominator, and the statement it changes. Keep measured results separate from interpretations. A later result can resolve a critique; do not keep repeating the old objection after checking the revised design. Refresh the affected critique fingerprint and explain the resolution. Do not silently upgrade an abstract check to a full reading or an author's validation record to our independent replication.
