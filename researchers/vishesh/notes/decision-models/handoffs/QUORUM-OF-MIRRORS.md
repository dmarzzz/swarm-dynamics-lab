# Quorum of Mirrors handoff

Owner preference: a primary project. Working headline: **One Witness, a Hundred Votes**. Canonical ID DM-02, area decision-models. “A hundred” is a communication hook, not an approved size or budget. Current exploratory context is in ../REIMAGINING.md.

## Research question

When does an apparently large consensus contain little independent evidence, and which intervention restores the value of a quorum? Separate source count, agent count and communication rounds. Do not rediscover that perfectly copied votes are dependent and call that new science.

## Strongest design

Use equal-sized groups with controlled observation ancestry. Compare duplicated reports, distinct observations and meaning-preserving restatements; source identity should come from recorded ancestry, not self-reported citations. Include explicit versus partial lineage. A source-aware method that gets hidden truth is an oracle ceiling, not an implementable defense.

Compare majority voting, source deduplication, calibrated evidence accumulation, pooled-evidence single Jev and no discussion. Return distributions support diagnostics; confidence is not calibrated correctness by assumption. Add **The Next Observation** as a budget ablation: another observation versus another judgment. Keep it separate from the existing general optimal-swarm-size project.

The decisive stress test is **The Right Dissenter**: new contradictory evidence arrives after consensus. Pair correct and incorrect new evidence. Dissent's RD-1 protocol supplies bounded checks and withdrawal; this project owns the evidence-dependence comparison rather than duplicating the entire dissent suite.

## Outcomes and visual narrative

Show endorsements resolving into their true observation ancestors. Record wrong unanimous commitments, probability change without new sources, accuracy per independent observation, and response to correct/incorrect fresh evidence. Stratify error dependence by task difficulty. Do not present an effective-sample-size approximation as a literal count of independent minds without assumptions.

## Closest prior and honest failure

Repeated evidence is established in [[hamdi-2013-removal]]; correlated Jev judge errors in [[rao-2026-jev]]. The opening is an intervention and its useful resource tradeoff under typed decisions. If deterministic deduplication solves the task, report that. Generalization beyond Jev needs a matched comparator. No native qualification or scientific outcome has been recorded for this project.
