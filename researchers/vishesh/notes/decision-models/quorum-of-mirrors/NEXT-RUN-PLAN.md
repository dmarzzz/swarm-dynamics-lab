## Setup

Pin historical route `typesafe/jev-1.13`, served `typesafe/jev-1.13-20260917`, provider TypeSafe, fallback disabled. Current route and pricing must be verified immediately before admission. Each report consists only of a neutral ID, binary value, q and visible-root label or null. No root index, expected answer, bit triple, fixture name, lineage count or evaluator metadata enters the request. Report order and neutral root aliases are deterministic, mixed and independent of expected answer. The prompt states equal truth priors, conditionally independent distinct acquisitions, and that copied reports/previous decisions are not new observations. Partial requests do not reveal the root count or copy-shape support.

The fixture evaluator holds three true roots, accuracy q∈{.65,.80}, root bits (1,0,0) or (0,1,1), and multiplicity (7,1,1). Both conflict directions occur at each q in each context/lineage cell. Full lineage exposes arbitrary root aliases. Partial lineage conceals the two singleton roots; repeated root identity remains visible. This mask deliberately exercises opaque singleton handling and is qualification-specific; C1 uses its independently randomized mask. No qualification case is a fresh scientific world.

Peer context contains five fixed slots: the focal slot has the correct prior choice, three slots have the opposite choice, and one is unavailable. Self-review context contains just the focal slot with an incorrect prior choice. The previous choices and their scores are **constructed qualification inputs**, not prior native calls; the run report must say so. All available slots use the same finite choice-score pattern (.80 chosen/.15 other/.05 DEFER), to avoid certainty and source-specific score cues. No rationale or future branch output is available.
