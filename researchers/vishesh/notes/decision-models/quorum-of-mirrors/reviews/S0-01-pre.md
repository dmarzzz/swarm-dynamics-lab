## Protocol

Sixteen predefined clean evidence cases: Cartesian product of bit triples in {0,1}^3 and q in {0.65,0.80}. Root IDs r0,r1,r2; report IDs p0..p8; multiplicities (7,1,1). They are development/competence cases, not the reserved world seeds or holdout. Build actor packets using an allowlist. The model is told a prior of 1/2, conditional root independence, each root's q, and that copies of an observation add no evidence. Ask for the more likely state. With three equal-q roots there is no tie. DEFER remains an available typed option for inability; clean cases require ZERO or ONE.

Each case is submitted twice with identical state/question bytes and distinct invocation IDs. Ordering: first pass lexicographic case order, then second pass in the same order. No peer messages, no quorum and no model reasoning trace in S0. Each invocation has a permanent planned record before dispatch and an atomic durable reservation. No automatic retries; ambiguous failures consume their reservation. Failures stop new calls, preserving remaining assignments as unstarted. No favorable-result reruns. New diagnostics require a new attempt and pre-run note.

The exact MAP answer is determined by the three root bits; it is evaluator-only. It is not a sampled world truth: qualification evaluates interpretation of evidence, not chance agreement with a hidden diagnosis. This distinction must be carried into every plot/summary.

Native Jev probabilities represent the distribution over typed choices ZERO/ONE/DEFER. Preserve these exactly, with the established two-decimal sum tolerance; do not normalize or reinterpret P(ONE) as a calibrated binary-world posterior. S0 reports no Brier score against a sampled world truth. The main QM-2 probability contract needs this distinction before a native factorial study; probability shifts are decision-score diagnostics only until independently validated.
