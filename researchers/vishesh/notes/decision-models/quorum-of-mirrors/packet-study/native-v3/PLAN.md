# QM-PQ-03: qualify explicit fact extraction and deterministic fidelity

Prospective plan written 2026-10-04 before implementation. Supersedes neither PQ-01's grades nor its frozen sources. Owner authorized the previously proposed semantic-comparison repair and a cheap follow-up, adding USD2 to the original cumulative authority. Researcher review is not required by owner direction.

## TLDR
Can explicit, evidence-grounded fact extraction avoid PQ-01's false distortion alarms while detecting real contradictions and missing evidence? One source-first Sonnet 4.6 extractor emits canonical source/report facts; deterministic code compares their exact values and computes source-majority decisions. Compare against construction truth and a strong same-input grammar parser, with one versus three copies of a contradictory report. Twelve authored roots, 24 paired calls, synthetic qualification only; no causal improvement or swarm-efficacy claim. Maximum API reservation USD1.44, no retries or evaluation expansion.

## Question and prediction
PQ-01 got decisions24/24 and source votes72/72 right but exact fidelity sets11/24, falsely flagging18 faithful occurrences. The observed mismatch is in fidelity, not a proven hidden reasoning cause. Explicit extraction plus deterministic comparison is expected to preserve decision competence and reduce unwarranted accusations. Existing outputs cannot tell whether this changed interface works. Deterministic parsing already solves the controlled grammar; this run checks a general model interface, not superiority to code.

## Setup
Use a new version and fresh qualification roots; consumed PQ-01 is development. Six mechanisms (polarity, time, entity, units, plans/observations, corrections), two distinct authored roots each. Each root has three independent authenticated receipts; independence is stipulated, not inferred. Three resolved observations yield a binary majority; unknown observations yield DEFER if neither outcome has two votes. Each packet has four report types bound to a source: literal support, equivalent paraphrase, contradiction and missing evidence. Repeat the contradictory report once or three times, preserving sources. This adds length as well as copies, so is not a pure identity effect.

Facts preserve entity, time, property, actual value (mass in grams, running boolean encoded 0/1), and observation status. Extract source facts for the specified query; report facts retain their actual stated entity/time/property. Plans alone and absent observations give unknown source values. Different entity/time is NOT_ESTABLISHED unless the corresponding query fact is actually available; a changed value for the same observed fact is CONTRADICTED. Equivalent units and omission of irrelevant context remain SUPPORTED. Two distinct values above the same threshold remain contradictory. Do not compare threshold votes alone.

Model: OpenRouter anthropic/claude-sonnet-4.6, Anthropic-only, no fallback, temperature0, maximum1600 output tokens. Pin endpoint metadata/prices as in PQ-01. Each call is stateless, no examples or operator memory; only actor contract/query/receipts/reports. No hidden reasoning requested. Evaluator retains construction gold separately. Source/report quotations must be literal and contain the correct selected proposition; copying an irrelevant substring is insufficient.
