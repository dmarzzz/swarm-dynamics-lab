## What the reading changed

Simple adversarial flips are already studied [[hu-2026-jevadvbench]]. Semantic option-name effects are also prior work [[sun-2026-type]]. A fresh contribution must identify a collective consequence or an intervention that changes useful outcomes. The shortlist makes no claim that these gaps are proven empty.

The inspected Jev specification accepts text, not images [[typesafe-2026-models]]. Coordinate-based map demos probe textual spatial knowledge; cat/dog and screen examples require a separately evaluated perception layer. The official OpenRouter guide documents a Decisions API route [[openrouter-2026-jev]]; this task has not tested authentication or inference.

Current confidence documentation now publishes its formulas [[typesafe-2026-confidence]], unlike an earlier paper’s description of those formulas as undocumented. Freeze documentation date and model version rather than treating either claim as timeless. Schema validity guarantees neither correct classification nor resilience to untrusted evidence.
