# Plan coverage and claim boundaries

This record evaluates the frozen implementation against the RD-4 plan. It does not change its assignments or scoring.

| Requirement | Implemented evidence | Interpretation boundary |
| --- | --- | --- |
| Alias multiplicity/order cannot buy checks | RD-R1 regression and exact/alias epochs in every applicable trajectory | Changing report content is new information; copies do not become independent sources |
| Preserve supported and withdrawn resolution | Persistent closure with request time, verification time, scope/version and TTL; repeat epochs | Incorrect native resolution can also persist; memory correctness is not factual correctness |
| Stop and resume in both directions | Twelve favorable and twelve adverse final changes per policy | Not a sample of real incident recurrence times |
| Source can recover after being wrong | Withdrawn regime followed by new observation from the same source | No learned source reputation or malicious-intent inference |
| Semantic interpretation beyond literal old grammar | Three wording forms; numeric load/range thresholds; required versus optional tests | Same author and finite templates; no independently authored corpus |
| Scope/version and freshness | Wrong-object cohort; version-change/expiry/future-time regression tests | Native S4 does not contain version-change, same-source conflict, missing-verifier or late-verifier strata; those robustness claims remain untested here |
| No-dissenter controls | Initially absent challenge and unanimous votes | Votes are scripted; no spontaneous minority formation |
| Matched admission comparison | Only criterion wording differs between original/symmetric request builders | Their later states can diverge because their earlier actions differ; do not call later information identical across diverged trajectories |
| Strong simple comparators | Always-check, pooled and exact finite-text reference retained | The main matrix emphasizes legitimate reopening, not a broad learned-triage cost frontier; superiority here would not establish efficiency across noisy operational workloads |
| Qualification separation | Default tests remap old constructors to development seeds; RD4 native qualification needs explicit preparation | Historical reserved-path exposure stays documented; fresh IDs are not fresh semantic families |
| Public plan and allocation | Immutable plan, server-side public preflight, browser-readable GitHub plan, exclusive Dmarz claim | Local dashboard DNS prevented claiming browser rendering of that dashboard; actual public registration was verified remotely |
| Failure retention and cost | Shared response/failure cache, original cumulative ledger, per-policy logical requests and counterfactual settled cost | Shared failures create dependence; actual spend is not the sum of counterfactual arm costs |

The construction can be useful even if the learned gate adds no value: a scoped, expiring evidence closure is an implementation guarantee, while the model's admission and resolution remain empirical questions. Broader semantic validation, independent replication and formal research promotion remain separate gates.
