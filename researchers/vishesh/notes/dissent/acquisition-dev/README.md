# Acquisition development: six cases, three shared rule structures

**Built and checked offline; no native calls, spend or reserve access.** Right Dissenter remains first alternate and scientifically incomplete. The proposed24-family evaluation corpus does not exist. These six public development episodes share three conservative core-rule structures: a single required predicate, conjunctive requirements, and authority ordering. State variants and domain names do not create independent families.

The hand-authored action table agrees with the deterministic resolver on **18/18legal choices**. The routine comparator reaches the best attainable action in **5/6episodes** and the stronger neutral coverage controller in **6/6**, using five synthetic checks each. The routine miss is acquisition failure: its DEFER is justified given what it fetched, but a better source could have exposed the failed migration. Calling that a parser/interpreter failure would misdiagnose the bottleneck.

These are **scripted controller results**, not native neutral/dissenter scores. The inexpensive coverage controller uses only actor-visible requirements, catalog coverage, authority and priorities; it does not inspect the future response or evaluator labels. Native neutral/challenge request drafts differ only in selection instruction. All policies share the one-check/one-credit limit, sources, per-source latency, deadline, eligibility gate and final resolver contract. The simulator rejects second checks, source spoofing and undeclared coverage. NONE is legal, preventing needless checking from being rewarded as dissent.

Twenty offline tests pass, covering counterfactual labels, parity and leakage, hidden-response noninterference, source provenance, TTL/authority/conflict controls, negative costs, deadlines, replay, catalog order/ID invariance, optional-evidence harm and policy faults. Every source has an explicit public counterfactual response. The sixth case would permit PROCEED only with an illegal second check; the instrument detects that budget violation rather than crediting apparent recovery.

## Scientific assessment

The corpus exercises six coverage regimes, but most information is structured and task rules are explicit. It is useful for validating acquisition traces, labels, missingness, conditional versus attainable correctness and budget parity. It is not a realistic high-diversity benchmark or a completed scientific baseline. Labels are same-author and checked by two representations, not independently annotated. Automated structure grouping is a conservative inventory, not proof of independent sampling.

The stronger simple comparator already solves every attainable target, so these fixtures expose **no residual capability requiring dissent**. Do not remove its coverage metadata, hide sources or disable its checks to manufacture an advantage. The proposed native packet can distinguish role-framing help/harm and repeat variability relative to this competent reference; it cannot demonstrate superiority over the reference or broad collective benefit. Broader construction must first document genuinely different operational dependency structures and a useful empirical unknown.

Native API integration, response validation/usage envelopes, fresh execution stability, disjoint acquisition qualification/evaluation corpora and a funded PI packet remain outstanding. The270-call candidate is disabled, unregistered and unfunded. The older162-call expiry-repeat proposal is not an automatic prerequisite or added allowance. Existing RD7/RD6 evidence, sealed reserve, original budget ledger and stage fences remain unchanged.
