## Question and prediction

Does challenge framing alter the selected evidence or the final justified decision relative to neutral verification, after controlling for the incumbent action? The simple coverage controller solves all six attainable goals. Thus a favorable native contrast would establish an interface effect relative to the neutral model prompt, not a need for dissent over the strong simple baseline. A null/adverse effect is useful too. Saved scripted results cannot measure native prompt sensitivity or fresh hosted variability.

Cross each episode with incumbent PROCEED, HOLD and DEFER, while retaining identical evidence, task and source responses. This removes the development corpus's incidental tendency for its original incumbent to be wrong. The scripted incumbent is context, never truth. Neutral/challenge selection requests have byte-identical states and choices; only the selection instruction differs. Both use the same final resolver request after their chosen acquisition. No native swarm or learned consensus is involved.

## Measurement and interpretation

Primary finite contrast: paired challenge-minus-neutral attainable-action success at fixed episode/incumbent/repeat. Separately report conditional interpreter correctness: a correctly interpreted but poorly chosen source must not be mislabeled as a reasoning/parser error. Report all source selections, legitimate service, wrong commitments, DEFER, unnecessary checks, agreement/disagreement across fresh executions and sensitivity to the incumbent. Routine and coverage references remain explicit comparators.

Three core-rule clusters and six authored episodes are the structural scope. Incumbent variants and fresh executions are repeated conditions. Report the full table and repeat ranges; do not infer a field rate, population confidence interval, independent replication or statistically precise small effect. Missing pairs remain unknown with conservative bounds, never silently DEFER or dropped denominators. A result confined to one shared rule structure remains such.

If neutral and challenge both match the simple reference, report stable equivalence of observed actions on this finite corpus without a general equivalence claim. If challenge repairs native neutral misses, inspect whether it closes only a model interface gap already solved by the controller. If it hurts valid incumbents, report false-challenge harm. Large fresh-repeat disagreement blocks a stable role-effect interpretation. Native failures or a universal ceiling do not justify weakening the comparator or automatically expanding this corpus.

This packet is not fresh acquisition qualification and does not unlock the broader48-episode study. A useful next main study still requires distinct challenging families, disjoint competence/evaluation inputs and an explicit residual question beyond cheap coverage-directed checking.
