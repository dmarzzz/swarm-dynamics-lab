# Freshness diagnostic case assessment

The 48-cell authored development matrix is ready for the scoped diagnostic. It cannot estimate a field error rate or qualify a broader dissent system. [Offline evidence](offline/validation.json) and [61 check results](offline/unit-tests.txt) support the following acceptance findings.

| Requirement | Evidence and boundary |
| --- | --- |
| Relevance and answerability | The three domains retain the observed failure's explicit requirements, metadata and choice contract. Both favorable and adverse evidence have a correct fresh action and become DEFER when expired. |
| Labels and strong comparator | Literal actor-visible reference and eligibility-gate-plus-reference each agree with 48/48 declared labels. No gold field enters a request. |
| Isolated contrast | Removing only the eligibility receipt reconstructs the raw request byte-for-byte; removing history/ballots reconstructs source-only. Text, timestamps and within-case action order are held fixed. |
| Challenge and negative controls | All-PROCEED, all-HOLD, all-DEFER and ignore-age faults fail controls. Metadata checks include negative age and exact TTL boundary. |
| Evidence integrity | The gate filters observations and evidence cards consistently; mismatched card/source metadata rejects rather than laundering freshness. Rejected sources remain in a separate audit. |
| Precision and independence | Six shared semantic roots, 12 task/age cases and 48 dependent requests. No repeated native sample or statistical significance claim. |
| Reserved qualification | 54 separate generated cases were sealed after source freeze; automated labels/baselines pass, individual contents uninspected by the operator. Same grammar is disclosed; no real-world holdout claim. |
| Execution and accounting | Synthetic original-ledger checks preserve historical uncertainty, enforce 48/554 call limits, reject duplicate attempts and retain all assigned missing outcomes. No native calls in this evidence. |

The diagnostic retains earlier source wording, including “current” within an expired observation, in every matched arm. This controls that wording instead of silently fixing it. Explicit age plus eligibility is a composite aid; this experiment cannot attribute a change solely to arithmetic, salience or wording. No filtering-controller result will be presented as learned native freshness competence.
