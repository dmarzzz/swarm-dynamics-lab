# R1: real-record reporting repair through trace bundles

Status: prospective engineering implementation plan, 2026-10-04. Saved-data replay only. The defects are already known from the public review; this is post-hoc repair validation, not a preregistered scientific discovery or a blinded holdout.

## TLDR

Turn saved capture-memory-mix records into swarm-trace/0.2.0 envelopes, let the current searcher agent (shadow/sol-rsi2) propose constrained reporting policies, replay each against a frozen accounting contract, and record attribution for an accepted repair and a rejected alternative. Additional model calls: zero. The saved searcher proposals are agent-authored artifacts, not a pretend fresh model execution every time the demo runs.

## Question and prediction

Can a bounded report-only bundle restore complete attempt accounting without changing scientific outcomes? A lineage-preserving policy should pass the accounting contract; hiding failed attempts or clamping a broken rate should fail. This expectation follows an existing review, not a novel prediction. The evaluator is same-author software, not an independent reviewer. No scientific policy promotion or payment is authorized.

## Setup

- Pin the current public MP3 five cell files, all rows including failed and repeated attempts. Replay units are cell/arm reporting groups, not independent scientific samples.
- Import first 16 public MP2 policy-call rows in each of its five files, with full-file counts and digests. This bounded illustration is not a random or representative call sample. Missing native IDs/usage/cost remain unknown.
- Import a bounded public dmarz trace file if its schema is usable. It is provenance context only, never a target for modification or credit for a scientific finding.
- Pool metadata: at most three records whose structured user request contains the full approved capture-memory research task. Local-only receipts establish scope. Do not join them to game-policy calls without an exact native correlation ID. Transport success never becomes scientific acceptance.
- Raw pool prompts, responses, private identities/paths, unsalted private content hashes and nonces stay outside git. Public replay needs only approved numeric projections and existing public files.

## Protocol

1. Freeze public source paths, bytes and SHA-256 digests before constructing replay artifacts. Check the input hashes every replay; drift fails closed. Explicit record identity combines cell, task, seed and arm. Row position is physical-record provenance, not provider retry ancestry.
2. Project every MP3 record to typed numeric/categorical metadata. Preserve validity and capture missingness. Commit attempt lineage and source row references. Public envelopes use imported identities and a publication hash chain, not invented historical causality.
3. Searcher agent supplies at least two content-addressed declarative policies: lineage-preserving reporting and a plausible but invalid shortcut. No executable candidate code, shell, network, arbitrary files or hidden source access. The baseline reproduces selected-record-only reporting with undisclosed attempt history; it is not represented as an exact re-execution of every historical UI bug.
4. Builder evaluates each policy on every frozen cell/arm group. Reference accounting is separately implemented in the same package (same author). Required contract: all physical records counted; invalid and superseded records disclosed; logical groups reconciled; retained-record selection declared; captured numerator and valid denominator from the same selected population; zero denominator stays unknown; failed-first attempts remain visible; scientific outcomes unchanged.
5. Acceptance: all accounting checks on all groups, positive improvement over baseline, and no source or outcome mutation. Negative comparator retains no right to credit merely because it claims a gain. Report all candidates and group-level results.
6. Credit ledger: 1000 non-transferable demo attribution units per accepted reporting service, split 20/60/10/10 among evidence originator/searcher/builder/evaluator. Zero dollars and zero payable claims. Mark same-principal maintenance, independent review absent and no transferable reputation. Bind each entry to source root, bundle hash, rubric hash and evaluation hash; duplicate settlement IDs fail closed. Rejected proposal receives an explicit zero-credit receipt.

## Metrics

Primary: accounting contract assertions satisfied / assertions assigned, per candidate and all groups. Secondary: raw, invalid, logical, selected-valid and superseded record counts; selected captured numerator / selected valid denominator; first-attempt-valid and eventual-valid logical counts. Do not infer causal scientific improvement, confidence intervals or independent sample sizes from reporting checks. Call samples, pool records and episode rows are distinct observational units and are not summed into a model-call total.
