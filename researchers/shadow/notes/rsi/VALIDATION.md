- **14 unit tests passed:** schema/hash-chain checks; salted and domain-separated commitments; canonicalization; duplicate-key/nonfinite JSON rejection; envelope tamper/extra-content rejection; quarantining an invalid bundle while retaining a valid batch candidate; content-free adapter projection; Anthropic cache-token accounting; unsigned/historical live-admission refusal; review over self-reported gain; sealed-result ordering; budget/rubric protection; epoch/builder restrictions; principal quota/reviewer conflict; dependency/rebate/payment-conservation checks.

- **Six content openings verified locally:** prompt and stored-response commitments for all three records match their original stored bytes and private nonces. No opening nonce or plain source-content hash appears in any release file.
- Public pool events, public omission projections and both worked-example bundles validate against the closed JSON Schema and applicable semantic/hash checks.
- The offline example selects the contract-preserving candidate, rejects the overclaim, reproduces a conserving hypothetical allocation and reports **zero actual settlement**.
- Release files were scanned for credential prefixes/assignments, private-key blocks, JWT/access-key shapes, private-context identifiers, local private paths and forbidden em dashes. Relative document links were checked. No matches remained. A substring false positive on the ordinary word "conventions" was corrected by matching the private-name sentinel as a whole word, not by exempting any exported content.

## What these checks do not establish

The scope match does not recover native run/span/call identity. Imported IDs are new; source timestamps do not establish priority. HTTP success is not scientific acceptance. Collected response text does not establish complete tool/SSE capture. Costs and served-model revision are unknown.

The bundle evaluation is a synthetic developer-owned contract fixture, not an independent reviewer or research holdout. Its $1 split is hypothetical and its OFA bid is zero. No live signature verification, trusted key registry, auction relay, escrow, worker isolation, scientific effect or actual payment has been demonstrated.

The protocol schema is not a privacy classifier. Public examples are safe by content-free projection and explicit scope selection, with regex checks as defense in depth. Raw selected lines, full task text, source paths/digests, nonce receipts and private byte hashes remain local and uncommitted.

## Reproduction

```sh
python3 researchers/shadow/notes/rsi/test_protocol.py
python3 researchers/shadow/notes/rsi/demo.py
```

These commands require no raw source access. An authorized local operator can additionally verify original-byte provenance using the private receipts. Public readers cannot independently recover that provenance from the sealed examples alone, by design.
