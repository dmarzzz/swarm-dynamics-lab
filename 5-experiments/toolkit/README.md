# Shared research tooling

[Agent experiment methods and toolkit](agent-experiments/README.md) provides reusable design guidance, source-linked methodology, protocol and manifest templates, schemas, and a validated offline teaching harness. Start with its [swarm-dynamics-lab integration guide](agent-experiments/INTEGRATION.md).

These development resources support any approved project. They do not replace the source catalog, survey gate, hypothesis review or experiment registration in `AGENTS.md`.
