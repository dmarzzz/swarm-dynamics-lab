## What the existing evidence establishes

Independent arithmetic reproduces 29/32 native choices matching root MAP, versus 24/32 count-all and 32/32 root-majority references. The critical split is **5/8 correct on copy/root-conflict calls, 24/24 elsewhere**. There are only four conflict configurations, each repeated twice; neither 32 calls nor five judges is an independent sample of 32 or five worlds. The references are retrospective deterministic computations, not randomized provider comparisons. Root MAP is optimal under the generating assumptions, not guaranteed sampled-world truth.

Thus S0 establishes limited, fallible use of explicit provenance under an instruction to deduplicate. It supplies no evidence that discussion helps, that IDs can be inferred when unavailable, or that a swarm is worth its cost. The revised RESULTS largely states these limits honestly. Fixed quorum, retained failures, no replenishment of easy worlds, constituent effects beside the interaction, and the ban on treating native choice scores as calibrated probabilities are all appropriate.

## Required revisions

**Q1 — Narrow the information-boundary claim or change the support before registration.** In the proposed S1 distribution, report multiplicity alone recovers root majority without visible root IDs. For balanced copies, ONE counts are 0/3/6/9. For skewed copies they are 0/1/2/7/8/9. Across BOTH shapes, predict root-MAP ONE exactly when the number of ONE reports is in `{2,6,8,9}`; otherwise ZERO. This works for every bit triple, favored root and both proposed q values. Our exhaustive 48-case algebra check uses no reserved worlds and obtains 48/48 MAP agreement. The shape label is unnecessary.

Withholding the generator description from a model does not remove this observable shortcut. It tests a reasoner's use of withheld metadata under a narrow distribution, not inherent inability to recover the decision. The historical example using alternative hidden root counts establishes ambiguity over a broader graph class, not this S1 support. Either explicitly restrict the claim and add this distribution-aware count rule as an evaluator/reference comparator, or broaden the generating support so the SAME actor-visible evidence can have different root-MAP answers within that support. If choosing the latter, document paired indistinguishable manual examples and the target posterior/decision before opening seeds 41000–41005. Do not manufacture seed outcomes to create ambiguity. Also require neutral report IDs and an actor-packet audit of metadata leakage.

**Q2 — Match the instruction for a judge-count recommendation, or remove that recommendation.** The primary source-aware-versus-standard committee contrast is identified as a prompt-package effect. But comparing a source-aware committee to a standard-only pooled solver changes both architecture and instruction. Add source-aware pooled self-review in each repetition × lineage cell if making the practical claim that extra judges earn their cost. Alternatively retain the existing pilot and explicitly defer that conclusion; a favorable committee interaction alone cannot justify more judges. Adding the matched pooled cells would mean 48 extra calls: 592 new, 624 cumulative, approximately $0.838656 reserved at the assumed tariff. This arithmetic is not an amendment, funding approval or validation that longer prompts fit the cap.

**Q3 — Freeze a conflict-sensitive context screen and an operational next-step rule.** The 16-request screen is sensibly distinct from S0, but 7/8 full-lineage MAP can again be dominated by easy cases unless coverage is explicit. Prespecify both directions of report/root conflict, both q values, misleading peer endorsements and unavailable peer slots in the eight full-lineage fixtures; document which cases exercise each condition. The partial half should retain its interface-only gate. No hidden-world correctness requirement is warranted there. Keep original failures and bounded disjoint repairs.

Specify the next decision without pretending six worlds establish equivalence: absent usable contrasts, report uninformative and do not replenish; absent an instruction benefit, retain the simplest provenance rule/pooled option for this task and stop this version or motivate a new question; a positive interaction with worse underlying correctness is not advancement. A favorable scoped pilot may justify designing a powered successor only after cost/quality and matched-comparator assessment. This is an engineering decision, not a significance threshold.
