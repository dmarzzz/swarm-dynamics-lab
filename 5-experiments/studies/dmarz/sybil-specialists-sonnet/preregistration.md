1. Primary development contrast: coverage minus degree in rare-skill accuracy with attacker pass .10, visible badges, one bridge swap, four checks, 18 admitted seats. Secondary: visible minus masked badges under coverage at attacker pass .90. Both may be negative. Report every arm and cell.
2. Twelve independent world clusters 4000–4011; four arms × two pass rates × two metadata modes = 192 calls. Potential verifier outcomes, packet identities and order are paired across arms/modes. Model calls have no seed parameter and are separate stochastic draws. All 192 assignments are globally shuffled deterministically by study/stage before dispatch. No causal claims about independent calls or graph families.
3. Q0 uses six disjoint clean worlds 3000–3005, full versus common-only reports and both metadata modes: 24 calls. Full reports agree on all six facts; common-only reports require three nulls. Require 100% structurally valid, >=95% per-field accuracy, >=90% exact packets and 100% missing-fact abstention. No pilot until qualification passes. Future prompt repair requires disjoint new qualification worlds and a recorded amendment.
4. Scripted plurality on the identical packet is retained for every call as a zero-cost reference. It ignores badges. Check outcomes and graph admission remain algorithmic; only report synthesis uses an API. This does not test autonomous Sybil creation or credential verification by an LLM.
5. Integer facts, no external knowledge. Evaluator owns truth and common ownership. Prompt sees only admitted synthetic reports, skill index and optional operational verification status. It sees no group, truth, principal, graph position, policy name or attacker pass parameter. Badge visibility changes only the verification field. Stable shuffled report order avoids ranking leakage. Missing facts require null, conflicting claims may abstain. Do not reveal the attack offset to the actor.
