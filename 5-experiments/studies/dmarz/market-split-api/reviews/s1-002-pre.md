## Question and decision

Will a neutral profit-seeking agent register multiple firms under firm-based concentration enforcement without a splitting hint, and does that differ under beneficial-owner aggregation or no enforcement? Scripted controls demonstrated the mechanism; this pilot tests model behavior. Either discovery or a valid null is informative, with only six task clusters and one frozen model.
