# Reproduction and operating interface

Use Python3.12 with `pip install -r requirements.txt`, from this directory. `python3 src/selftest.py` runs offline regressions. `python3 src/worker.py --stage S0 --attempt <fresh-name>` produces a finite local scripted stage under `results/`; no API access is used. Every attempt directory is exclusive and cannot overwrite a previous run.

The private launcher sets `SWARM_SOURCE`, `SWARM_MODEL_API_KEY`, `SWARM_MODEL_WORKSPACE_ID`, `SYBIL_API_BUDGET_LEDGER`, `SYBIL_FOLLOWUPS_LEDGER` and hub credentials by alias. Never copy values into this repository. Root operator supplies the exclusively claimed fleet allocation, study ledger and shared-cap enforcement. `src/coordinator.py:enqueue(sr,stage)` registers and enqueues exactly one S0, Q0 or S1 batch. `study.params(stage)` stamps runtime hash and source commit; no S2 exists. Exact-runtime successful S0 gates Q0 and Q0 gates S1. `python3 src/worker.py --hub` claims one batch and exits after completion. Automatic hub retries fail closed when attempt is not1.

Nominal paid assignments: Q0 16 +S1 2880 =2896. Two concurrent calls; no retries. Exact preflight reservation totals are in `reservation-plan.json`, distinct from actual billable use. Root must check the shared $500 owner budget including other experiments before either paid batch. `provider.Ledger.transact()` keeps the existing reserve/response and accounting interfaces; planned reservations are nonrefundable for cap enforcement.

Each successful stage writes all assignment/world/episode histories, `summary.json`, `analysis.json`, `initial_frame.png`, `final_frame.png`, `retention.png` and `replay.gif`; live hub runs also upload bounded progress images. The final report is generated only from saved observations. Run `python3 reporting/verify_results.py <results-directory>` to check IDs, hashes, evaluator grades, check counts, exact cell counts and analysis reproducibility. Use matching pinned Python/dependencies for exact floating arithmetic. A nonzero failure or reporting-error count requires an own post-mortem and bounded repair before closure.

The per-study nonrefundable reservation cap remains $140; nominal exact reservation is $130.754844. Known request usage releases only the unused request reservation in the separate actual-plus-unsettled guard; unknown billing retains the full request reservation. This guard is part of the owner's $500 aggregate allowance and does not replace accounting for other experiments.
