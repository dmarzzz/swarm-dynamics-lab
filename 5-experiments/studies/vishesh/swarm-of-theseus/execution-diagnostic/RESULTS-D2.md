## Failure structure and PI interpretation

D's 40 failed presentations cover 20 distinct case/family combinations. It scores 183/192 in early positions and 161/192 late. Reversing the same cases changes 32/192 matched actions, versus 4/192 disagreements between native repetitions of the same ordered request. This supports order sensitivity within these batches; order and other context effects are not isolated cognitive mechanisms.

E's eleven failures cover only three case/family combinations. Two incident cases have a false governing probe signal, but the actor selects probe in all four presentations of each. One has both irrelevant signals true; the other has every signal false. Thus irrelevant-source conflict is not a necessary explanation. The actor chooses the mapped source but fails the conditional none branch. This is an observed rule-application failure, not demonstrated reasoning about hazards.

The remaining three E failures copy the same release case ID incorrectly, omitting characters. Their action is hold, the correct semantic action for the supplied case; strict scoring must still fail the unmatched ID. These are identity-contract failures, not absent provider responses. Original records and strict scores remain unchanged.

Atomic order labels contain identical actor inputs. Its one order-pair and one repeat-pair disagreement concern the ID-copy failure and cannot support a position effect. Fresh cases exposed failures hidden by D1's small perfect result.
