## Fixed P1 interpretation and P2 recommendation

Before native input freeze, retain these direction-independent rules:

1. No P1 after a Q3 semantic, schema, evidence or accounting failure. No seed replacement or retry. Native failures remain failures.
2. A transport/contract defect or incomplete all-founder acquisition prevents a turnover inference. Resolve it offline and report the missingness; do not label it cultural loss or select a successful replacement world.
3. Evaluate all four terminal arms and the shared baseline in both executions of each of the three P1 worlds. A valid wrong broken-arm result is the intended manipulation; it is not a competence failure requiring a reroll.
4. Report all paired differences and per-world repeat disagreements. A proposed practically noticeable difference is two correct terminal decisions out of36 (5.56percentage points), with no increase in harmful approvals; this is a disclosed operational margin, not a significance threshold. Report smaller effects rather than censoring them.
5. If both primary arms and the simple controller are perfect in every terminal cell and repeat, close the **current case suite** as ceiling-limited. More of the same sampling has little discriminatory value; this is not evidence of general equivalence or a broad completed culture baseline.
6. Otherwise, if the instrument and controls are valid, P2 can address repeat variability or new-world uncertainty regardless of whether the contrast is positive, null or adverse. A consistent non-ceiling null remains eligible. Recommend the same fixed three new worlds/two repeats; never choose family/seed allocations based on which favored the treatment.
