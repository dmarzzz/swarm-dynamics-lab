All four irrelevant-change variants preserve their base answer. Reordered/duplicated documents and opaque case IDs preserve decisions. Public inputs exclude labels and evaluation fields; each packet is below 4,500 bytes. Strict Boolean typing rejects integer substitutes. Unknown policy wording produces abstention: this is a parser limitation, not evidence for a model advantage.

Question clarity, answerability, matched perturbations, missingness, label isolation and a competent fixed control have concrete software checks. Construct realism, independent annotation, unseen semantic generalization, distribution of economic opportunities, topology measurement, native reliability and statistical precision remain unvalidated. Both labels and implementation have one author. These checks do not constitute a scientific-quality score or independent audit.

Crucially, deterministic code solves every known case. A collective experiment using only these fixtures would not yet demonstrate useful adaptation. Before a comparative run, construct unseen evidence/rule combinations and demand/version changes where all arms retain the same information and competent exact solvers. Charge fixed compilation and adaptive discovery alike. Reject a design whose claimed benefit depends on deliberately withholding a successful static rule.
