## What this can and cannot establish

This is a finite authored benchmark of six causal mechanisms, not six sampled independent production incidents. Conditions, repeated calls and actors do not increase root n. All cases are developer-visible and A/B-used; C tests fresh-run stability on that declared support, not untouched transfer. Root-paired completion means, all three replicate outcomes, first-error categories, safety, absolute service, actual model cost and elapsed-time distributions are the primary report. With only two roots per structure, avoid stratum population claims and bootstrap precision theater. No universal optimalN,5-point equivalence margin or field reliability conclusion.

Case realism is still limited: three structured evidence records per root, idealized reversible settings, no actual service containers, noisy free-text logs, delayed probes or exogenous updates. The repair mechanism is substantive and executable, but full production diagnosis is not simulated. Native A can establish whether the current model can use this contract; it cannot prove challenge or external usefulness. If all strong policies reach a reliable ceiling, report the null on this support and assess whether the benchmark answers a useful decision before collecting more. Do not manufacture a swarm advantage by weakening the singleton.

Before funding/dispatch: finish native typed batch schema, exact request builder and bounded relay/ledger/receipt adaptation; test failure capture, owner/context isolation and serialization on worst permitted histories; freeze case/assignment/source hashes and arm order; refresh project/study budget, public immutable plan/TLDR, runtime, approved-account/exclusive allocation and qualification checks.
