# Antsy diversity measurement protocol

The reusable protocol now lives in [Worker diversity and shared errors](../../../toolkit/agent-experiments/WORKER-DIVERSITY.md). Antsy's frozen definitions, contrasts and thresholds remain in [PLAN.md](PLAN.md); its concrete profiles are in [spec/worker-profiles.json](spec/worker-profiles.json).

The shared guide covers declared configuration differences, evidence lineage, behavioral agreement, correlated wrong answers, complementarity, and decision value. A different name or engine is never counted as proof of independence. Future LLM studies must add model/prompt/context manifests and repeated judgments; this OCR run does not establish LLM-agent diversity.
