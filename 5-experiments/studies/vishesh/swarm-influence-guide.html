01 / Outside control

Change a reported fact.

The outsider publishes a fabricated delay on a bulletin page. It does not send a command to the swarm or install a malicious teammate. The experiment must establish that the page is actually retrieved and treated as credible.

02 / Belief update

A different optimum appears.

Normal travel estimates are A 12, B 18, C 24 minutes. If a false 15-minute delay on A is accepted, the estimated times become A 27, B 18, C 24. Choosing B follows the unchanged objective under a false premise.

03 / Shared provenance

Five votes can share one error.

The agents exchange summaries of the same bulletin. Agreement is correlated evidence, not five independent observations. The failure is accepting and propagating an unverified claim; shared weights or shared hidden values need not be assumed.

What profiling one agent could actually tell us

Suppose a permitted public interface lets the researcher observe one agent’s recommendations on separate synthetic tasks. Those observations might suggest that it gives recent traffic bulletins substantial weight. They do not reveal its actual value function, prove which sources other agents trust, or grant access to the group.

For this example, profiling proposes a hypothesis about evidence handling. Whether tailored external content outperforms a generic false report must be tested. The depicted cascade alone would demonstrate neither preference recovery nor a benefit from profiling.

How to test the external influence claim

Use a synthetic retrieval corpus and a simulator that retains hidden ground-truth travel times. Pair clean and contaminated versions of each task. Keep agents, objective, normal route estimates, retrieval tooling, and vote rule fixed. Only one external document changes.

  • Record whether the document was retrieved, which agents saw it, and whether its claim was accepted.
  • Compare a tailored report with a generic report, with equal visibility and similar length.
  • Prevent peer communication in one condition. Deliver the report only through one normal retrieval path in another. This separates repeated direct exposure from peer propagation.
  • Add a condition with an independent live measurement. A trustworthy contrary observation should allow agents to reject the report.
  • Measure target selection when the target is actually worse, true travel-time loss, and uncertainty over held-out tasks.

Report both end-to-end success over all tasks and success conditional on retrieval. A high rate only among exposed agents must not be presented as a high overall success rate.

The 1,000-run totals below are a desired hypothetical pattern, not output from a simulation. Across shuffled tasks, reports would concern the currently faster competing route; a single fixed claim about A does not explain all 1,000 outcomes. Exposure, acceptance, and propagation could each fail in a real study.

Research behind the question

M-Spoiler (Liu et al., 2025) examines manipulating collective decisions with knowledge of one agent. Its optimized adversarial inputs differ from this external false-data scenario.

When collaboration fails (2026) studies persuasive adversarial influence in multi-agent debate. Adversarial Search Engine Optimization (2024) studies preference manipulation through third-party content. These papers motivate the question; none supplies the invented results shown here.
