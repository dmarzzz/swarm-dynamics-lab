# Candidate next question: can fresh evidence reopen a stopped decision?

This question follows the completed RD5 negative result. It is not a preregistered successor or launch authorization.

**When a new observation clearly warrants resuming work, do historical stops, majority ballots or time metadata cause an otherwise competent classifier to keep deferring—and which minimal interface preserves both safe stopping and legitimate resumption?** This is more useful than another sweep of a fixed reserve time because the saved trace already shows where admitted evidence failed to become an action.

The strongest anchor is urgent resume: identical reading, source timestamp, history and ballots produced PROCEED at displayed time/deadline 3 and DEFER at 5. This is an observed difference, not proof of a clock effect. The other late-resume misses make a contextual transfer screen more urgent than a larger policy comparison.

A future proposal should first hold the source and task fixed while separating absolute clock, evidence age, historical action and ballot content. Use matched source-only and full-context conditions, repeated identical requests to expose hosted variability, reciprocal stop/resume cases, stale/conflicting controls, and a deterministic interval evaluator under the same acquired evidence. Qualification must use the complete context that the main comparison will deliver. Build new semantic templates and an independently sourced holdout; changing only IDs is insufficient.

The primary outcome should be correct, evidence-justified reopening by the deadline, with wrong resumptions and unnecessary stops reported separately. The decision is conditional: if metadata/history drives avoidable deferral, test a narrowly separated current-evidence interface; if matched repeats dominate the difference, measure reliability before attributing a mechanism; if the simple controller is sufficient, use it and park the native-model research claim. A negative result should stop the line rather than trigger prompt fishing.

Before any paid successor, specify independent units, sample counts and precision rationale, context construction, stopping, controls and the remaining cumulative resource envelope in a concrete plan. The completed RD5 scope allows no additional calls. Offline analysis can continue without new collection; a materially new plan needs the owner's corresponding decision. No machine is retained or run scheduled by this note.
