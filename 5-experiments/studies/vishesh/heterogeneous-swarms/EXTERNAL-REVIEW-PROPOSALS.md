## Additional gaps and interpretation

Before a diversity study, distinguish model family, competence, evidence allocation, role prompt and memory heterogeneity. These are separate factors. A conditional error-complementarity screen should retain same-model repeats and a strong singleton so model quality is not mistaken for diversity.
