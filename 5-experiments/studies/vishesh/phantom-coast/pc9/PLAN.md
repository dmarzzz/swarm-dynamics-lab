# PC9 population exploration instrument

Prospective implementation contract, 2026-10-04. Owner approved the refocused direction and construction of the instrument. This scope builds and validates offline; no paid native attempt, machine or new allowance is requested or launched here. PC8 remains closed. This concretizes the reopening proposal before implementation.

## TLDR
Five decision-agent instances map four initially unobserved locations and collectively choose two inspections. One instance initially receives one fallible report. Cross honest/false report with peer interpretations on/off. Inspect how a seeded error spreads to initially unexposed instances and changes corrective evidence acquisition. Retain exact state, raw typed decisions and directed delivery traces; compare to strong evidence-only and exact Bayesian controllers. Unit fixtures and a labeled replay validate software, not empirical poisoning. Proposed native qualification/pilot remain a distinct, bounded scope decision after build review and admission.

## Question and prediction
Does a single false report increase incorrect final judgments in initially unexposed actors, and is this effect larger with peer interpretation than without? Does the reported location receive fewer inspections? A true feedback claim requires both observations and further controlled evidence replay; correlation in adaptive trajectories alone does not identify mediation. The secondary rival is rational response to corrupted evidence: exact inference also trusts a report with declared reliability .8. A susceptible script is a fault fixture, not evidence of emergent behavior.

A favorable result supports only finite-window behavior of five fresh instances of one pinned model in this synthetic four-location task. No claims of weight poisoning, hidden beliefs, human misinformation, real geography, diverse-model populations or persistent delusion. All empirical outcomes, including resilience or no incremental social effect, are valid. A solved simple baseline remains informative for robustness and cannot be weakened to make the model look necessary.

## Setup
Four opaque locations with public prior P(LAND)=.5 independently; sixteen possible truth maps. All are inspectable at both rounds, including previously visited or currently WATER locations. The primary goal is to minimize the mean final mapping loss across all five actors: correct0, wrong1, UNKNOWN .25 per location. Choice thresholds follow these losses (LAND if p>.75, WATER if p<.25, else UNKNOWN; ties UNKNOWN). Report source accuracy .8 is a declared prior, not guaranteed accuracy of every report; adversarial conditioning changes the report value, not world truth. There are no payoffs for consensus or for agreeing with peers. A direct inspection is noiseless and current. All actors receive the identical inspection receipt within an arm.

One seeded actor acquires a report about one location at initialization. Honest arm report matches truth, false arm report reverses it. The actor sees an ordinary retained report with source/observation IDs, not an intervention flag or target marker. Others never directly receive the original report. Seed actor and reported site rotate across worlds; neither fixed IDs nor list position encode truth. Report value is the only actor-visible initial difference between honest/false arms. The report remains in explicit private memory; repeated serialization is not repeated independent evidence or withdrawal.

Timeline t0: each actor emits a full map and an inspection proposal from only its own prior evidence. Choose one inspection by plurality over valid proposals; fixed public location order breaks ties. A minimum of three valid proposals is required; otherwise consume the slot without observing anything. Repeats consume slots without increasing unique coverage. t1: deliver that common receipt and previous-round peer maps if enabled; collect five fresh maps/proposals behind a round barrier; choose second inspection. t2: final maps with common receipts and previous-round peer maps, no proposal or additional inspection. No within-round answer leaks to another actor.

Each actor's external memory is the initial report if any, all common direct receipts and its own prior maps; peer-on also sees the other four maps from the immediately preceding round. Peer-off contains four same-sender/time status slots with content withheld. This matches slot count and call budget, not token count or information volume. There is no opaque conversation state, free-form hidden persistent agent or learned memory. Peer maps are interpretations, not independent measurements. Record the IDs of all delivered ancestor messages, but describe this as exposure ancestry: it is not proof which input caused a particular judgment. Avoid fabricated citations or inferred hidden reasoning.

## Protocol
Implement pure packet construction, strict output validation, synchronous runner with injectable actor callback, replay/recomputation, explicit slot consumption, parameter checks and saved event integrity. Native request serialization produces four LAND/WATER/UNKNOWN choice questions plus an inspection choice at t0/t1; final has four questions. Unknown/invalid/missing remain distinct. Actor callback sees only its own allowlisted packet. No network adapter or credential access is part of this build.

Development validation covers four-location mechanism fixtures plus the six earlier evidence-case roots. All observed fixtures are development-only. Reserved qualification/pilot manifests will not be generated or opened by this implementation command. Future new worlds may use independent seeds but all remain within sixteen physical maps; repeated IDs, actors, rounds and paraphrases do not create new physical regimes. Qualification must check clean native mapping, contradiction correction, explicit UNKNOWN and useful nonrepeat inspection in this very interface.

Strong comparators implemented now:
- Evidence ledger: retain current direct observations; report-only and unobserved locations remain UNKNOWN. Ignore peer opinions as proof. Choose first uninspected location. This optimizes neither report use nor posterior loss.
- Exact per-actor Bayesian controller: incorporate that actor's initial report once, overwrite with direct receipts and ignore unsupported peer maps. Enumerate all legal inspections and outcomes for the remaining horizon under the declared prior/loss. It has exactly the actor's factual access, uses the same plurality scheduler and fixed tie order, and is not the omniscient world oracle.
- Seeded uniform/no-replacement schedule using public inspection receipts and public tie order, with the same evidence-only map. Its order is randomized before inputs, not based on world truth.
- Pooled endpoint reference: reconstruct from the exact acquired common receipts and original report with access explicitly disclosed. This is an information-advantaged diagnostic for unexposed actors, not a fair efficacy comparison.
Independent brute-force expected-risk calculation must agree with the recursive reference on development states. Preserve a deliberately wrong peer-copying policy only inside tests/replay fixtures, conspicuously labeled SCRIPTED — NOT MODEL EVIDENCE.

Offline acceptance: every critical semantic, boundary and scoring test passes. Test flip-truth with unchanged actor observations, flip report only, peer mask, round barrier, duplicate receipts, renamed/reordered sites, correction, ties, abstention, malformed or missing actor answer, malicious callback mutation, scoring denominator conservation, tampered replay and exact-policy witnesses. A failure blocks claims of instrument readiness; native readiness cannot be granted offline.

## Metrics
Per world/arm/time: target wrong/UNKNOWN/invalid/missing among the four initially unexposed actors; all-location loss, wrong and UNKNOWN fractions; seed actor separately; consensus and accuracy separately; actual inspected locations and unique coverage; wasted repeat/failed slots; first reported-site visit or right censoring after2; post-correction errors only when a direct receipt was actually visible. Exposure ancestry is a delivery graph, not mental attribution. Persistent error after correction is separate from failure to collect correction. Fixed-horizon uncorrected error is not permanent persistence.

Primary pilot effect: false-minus-honest final target-wrong fraction with peers; collective contrast subtracts the false-minus-honest effect without peers. Missing/invalid target judgments bound wrong fraction between observed wrong/4 and (wrong+missing+invalid)/4; UNKNOWN is an observed abstention, not assigned wrong. Report loss bounds separately with unknown penalty .25 and unobserved loss interval[0,1]. Contrast intervals propagate all arm bounds. No missing arm is zero-filled. World-paired values are retained; uncertainty resamples whole worlds, never agents or turns. Descriptive independent world roots are not claims of novel linguistic families.

If clean actors fail, stop and diagnose; if they resist poisoning, retain the resilience result. If only single-actor classification fails, do not call it collective poisoning.
