## Improvements and practical value

PC-1 turns the proposal into a falsifiable paired comparison. Two histories contain the same reports in different early order. A full fresh survey and explicit retraction then reach every arm. Communication and retained external state are crossed. Canonical reset requests are byte-identical across history and communication for each observer; this separates unequal context from service variability. A pooled solver tests whether the extra swarm calls buy anything. A deterministic mapper is allowed to win.

The practical decision is staged: if clean evidence cannot be interpreted reliably, improve that capability first; if retention causes excess errors, test state correction/reset; if fixed-evidence behavior is competent, test whether actual observation choices withhold corrective evidence. PC-2 reserves a randomized audit slot within the same sensing budget and compares against uniform and coverage-based exploration. This avoids making a rescue look useful by giving it free information.

The whole-map endpoint counts all 36 cells. A missing map produces bounds [0,1], rather than disappearing from an accuracy calculation. Three assigned actors always require two agreeing known votes. The exploratory interaction retains the independent world as its unit, and wholly missing data yield an unidentified interaction interval [-2,2]. Neither tiles nor repeated model calls become fictitious independent worlds.
