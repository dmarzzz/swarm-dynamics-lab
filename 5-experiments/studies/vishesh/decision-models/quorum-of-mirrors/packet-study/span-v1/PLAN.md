# SP-01 repair qualification: select evidence, normalize in code

Prospective plan written before implementation. Owner authorized trace analysis, the next repair and native qualification on 2026-10-04. Researcher review is not required. This is a bounded repair of the existing Quorum extraction interface, not the unrun committee experiment.

## TLDR
Can literal evidence selection plus deterministic normalization eliminate the two R1 failure modes without hiding selection errors? Run 40 fresh qualification calls: five authored families × four source states/directions × one versus three copies of the changed-value report. Compare derived facts, selected spans, modes, classifications and source-majority decisions to typed truth and the strongest same-input parser. Require every call and every paired root exact. Maximum USD1.92 API reservation within the existing USD8 API + USD1 infrastructure authority; no evaluation or automatic retry. Authored grammar only, not field reliability or swarm efficacy.

## Question and prediction
R1-032 quoted an operating source but encoded its value as stopped, while the majority decision remained correct. R1-034 emitted unknown status alongside value0 for a plan-only source, violating the null contract. Saved traces establish these output inconsistencies, not their latent cognitive cause. The prior guard catches both but is a software rejection policy, not demonstrated native improvement.

Change the actor's job to selecting literal clauses: sources return one observed query-matching quotation, or null when no observation exists; reports return the complete asserted, hedged or planned clause. Do not ask the model to emit numeric values, status, entity/time normalization or report mode. A fixed grammar decoder derives those from the selected text, with no gold access and no silent replacement of an incorrect selection by the correct clause. Prediction: the new representation prevents contradictory value/status output and retains accurate evidence selection under copying.

The practical decision is whether this interface qualifies for the declared authored task. Pass: retain the bounded interface result and prepare a naturalistic annotation design offline. Valid misses: identify the selection boundary and avoid claiming robustness. Invalid/transport failure: preserve traces and stop. A direct parser already solves the grammar; no model superiority or causal before/after improvement claim is intended.

## Setup
Five R1 families: conflicting timelines, entity distractors/multiple claims, explicit corrections, decimal units, and plans versus observations. For each family, four fresh roots balance observed-positive, observed-negative, absent-positive-claim and absent-negative-claim. All source truths are query-resolvable or explicitly absent; other two sources disagree. This yields ONE, ZERO and DEFER in every family. Each root has six base reports (assertion, equivalent assertion, changed value, unseen entity, hedge, plan) and a paired variant with two added copies of the changed-value report.

Twenty authored root units, forty calls. The five grammar families are reused; fresh IDs/seeds do not make values, times or semantics disjoint. Qualification is development evidence after inspection, never a population holdout. All earlier R1 cases, including unstarted cases, are released development. Historical 96-case evaluation remains unused. Actor inputs contain only the contract, query, sources and reports, with no gold, family/stage label, operating-session history or earlier responses.
