# PQ-04: distinguish report assertions from source evidence

Prospective plan written before implementation, 2026-10-04. Owner requested analysis, improvements and the next run. This authorizes this bounded continuation within the existing cumulative budget; no budget reset or additional funding. [Previous post-mortem](../../reviews/PQ-03-post.md).

## TLDR
Can the extractor preserve what a report claims even when its source does not establish it? Separate the report-claim schema from the source-evidence schema, then test four paired synthetic scenarios with observed versus plan-only focal sources. Reports remain identical. Compare exact facts, source-majority decisions and supported/contradicted/not-established labels against typed truth and the strongest same-input grammar parser. Eight calls, four authored roots; targeted qualification, not general accuracy, causal repair superiority or swarm efficacy. Maximum new API reservation USD0.48.

## Question and prediction
PQ-03 passed all final decisions/classifications but returned null/unknown for one report that asserted stopped. Its source contained only a plan. The final NOT_ESTABLISHED label was correct regardless of that erroneous report representation. Also, the quote checker recognized the correct quoted sentence but did not require agreement with the extracted fact. These are separate observable gaps, not proven hidden reasoning causes.

The repair gives sources an observed/unknown status and nullable value, but reports have an asserted integer value and no evidence-status field. In this controlled task every report explicitly asserts one observation, so a report's claim does not become unknown merely because support is missing. Code adds the declared claim type internally; it does not supply the claimed value. A stronger gate requires all source and report facts correct, as well as labels, decisions and quotes consistent with those facts.

## Setup
Four authored roots: binary-running claims in both directions and mass claims below/above a5000g threshold. Each has three independent authenticated source groups and four report occurrences bound to focal source0: two equivalent faithful claims (including units/paraphrase), one changed value (same threshold side for mass), and one claim about an unseen entity. Source1 and source2 split ONE/ZERO votes. Conditions: source0 contains an observation or only a plan; query and all reports/IDs/order remain identical within a pair. Thus observed source0 determines ONE or ZERO, while plan-only source0 must yield DEFER. Reports about source0 must change their supported/contradicted classifications to NOT_ESTABLISHED when evidence is absent, while their extracted assertions remain fixed. Unknown-entity report remains NOT_ESTABLISHED in both.

The intended manipulation removes evidence and changes source-text content/length. This is not an isolated wording effect and does not withhold an answer while pretending the answer is known: DEFER is explicitly the correct outcome. Reports are assertions, not authenticated observations. Distinct source-group independence is stipulated; no provenance authentication or real swarm is tested. New entity/time instances after development; known authored templates, no natural-language generalization claim. All earlier published cases are development. Old96-packet evaluation stays sealed and unused.

## Metrics
Primary: exact report assertions stay correct under both evidence conditions, not merely final classifications. Gate:8/8 valid/accounted,24/24 source facts,32/32 report facts,8/8 exact classification vectors and decisions,8/8 literal relevant quotes AND fact-consistent quotation packets. All four pairs must preserve report facts and show the intended source-driven decision transition (ONE/ZERO to DEFER). No false contradictions, missed contradictions or unknown-classification errors. Missing/invalid calls fail the gate and remain in denominators. Preserve PQ-03's historical pass under its original weaker conjunction.

Report individual component correctness, both quotation checks, confusion matrix, pair comparisons, latency and costs. Facts use exact entity/time/property/value/status construction labels; report status is a deterministic declared-claim adapter, never used to infer evidential support. Mass values retain grams, not only threshold votes. Quote consistency additionally requires the extracted fact to equal gold; a correct quote with a wrong fact must fail that component gate. This is same-author typed-oracle/regex-baseline QA, not independent audit.

Four authored paired roots are the units;8 calls and32 report occurrences are dependent. A perfect four-root screen still cannot establish a low population error rate (an IID two-sided95% exact lower bound would be about0.398, and these authored roots do not justify IID generalization). This is a cheap targeted discriminator. Success supports the repaired assertion/evidence interface on these fixtures; a semantic failure retains the deterministic parser recommendation; transport failure is inconclusive. No broad efficacy claims or favorable-result-driven retries.
