## Design improvements

- Real receipt images instead of scripted agent choices; image and label provenance pinned in [INPUT-FREEZE.json](INPUT-FREEZE.json).
- Direct20 versus varied20 isolates a role-prompt intervention with matched calls and pixels. Same model does not imply independent opinions; report shared wrong-value clusters.
- Singleton, smaller homogeneous panels and pooled40 are prespecified secondary operating points. Strict majority includes referrals/invalid seats in the denominator; no vote inflation from missing answers.
- No gold, peer answer or operator context reaches actors. Visible evidence quotes are retained privately for audit, not treated as proof of hidden reasoning or automatically valid evidence.
- Conservative capability gate, failed/unstarted accounting, conditional evaluation, no automatic retries and full scientific closeout.
- Shared TRACE-RECEIPTS records inputs, effective context, outputs, parsing, grades, usage and timing prospectively; the local relay also retains responses before delivery to survive a broken tunnel.
