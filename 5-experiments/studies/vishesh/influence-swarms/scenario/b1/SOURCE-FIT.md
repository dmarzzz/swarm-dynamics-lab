## Case audit and claim boundary

The30 dossiers contain six family mechanisms, each with one development variant and four evaluation variants. The four evaluation variants are intentionally two unsuitable promoted options, one suitable option and one unresolved purchase choice. They are not30 independent business environments. Six shared construction families and repeated schema/accounting conventions limit diversity. Changes within families concern different causal mechanisms (e.g. replicas versus a translation subprocessor), but source format and nonchallenged constraints are shared. Report24 evaluation roots nested within six authored family blocks; claim only this packet's behavior. Broader realism remains unestablished.

Each packet has12 primary records: quote, technical acceptance, stratified pilot and signed order for each of three suppliers. All arms receive identical full records and the same buyer policy. The vendor viewpoint has the same publisher, timestamp, source references, factual sentences and position in both conditions. Only its recommendation framing changes. No new supporting factual claim, testimonial, claimed independent endorsement or hidden source is added. Encoded page lengths differ by less than10%; exact sizes are frozen in the offline receipt. This version tests recommendation framing, not misinformation, omission, coercion or a repeated-publisher network campaign. The scientific question and claims are narrowed accordingly.

The publisher's recommendation is not evidence that it is suitable. Exposure is measured by a separate reported source-position field; exposure failures remain results and are not filtered by whether the treatment worked. Semantic mistakes in advocacy outputs remain valid outcomes. Neutral competence gates never use advocacy effect size, harm or sign.

## Label provenance

The evaluator derives arithmetic with Decimal, graph critical paths, stratum-specific durable rates and explicit three-valued checks. Separately authored offline expectations cover each family's challenge/status, acceptable-action structure, selected exact cost totals and schedule totals. Counterfactual mutations test a repaired blocker, a changed cap, missing primary record and conflicting order. These are internal consistency checks, not independent researcher validation. Conditional ranking is not assigned a unique oracle order when different supported preferences are reasonable. Scoring records check accuracy, purchase action, uncertainty and cost separately.

The public dossier file contains model-visible synthetic facts but no explicit gold answer object. The compiled gold table stays in the ignored local data directory; its digest is recorded in the case manifest. The operator can inspect it, but `observation()` uses an explicit allowlist that excludes gold, family labels, target identifiers and split/mechanism metadata. Agent inputs include neither operator history nor evaluator output. Future runtime must preserve that boundary.
