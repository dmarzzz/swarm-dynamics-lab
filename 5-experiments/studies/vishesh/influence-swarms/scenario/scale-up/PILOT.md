# One paired scale pilot: supplier advocacy through a procurement team

Prospective instrument details, before implementation and collection. Conditional on Sol/Luna qualification. This operational/mechanism pilot implements PLAN.md; it does not add a new allowance or claim an independent scenario family.

## TLDR

Test whether a vendor's misleading comparison page changes advice, peer revisions and final purchase authorization when authoritative deployment records contradict the page. Compare qualified ten-Sol and fifty-Luna systems on one fresh authored world, each with clean and advocacy conditions. Hold buyer records and graph degree fixed; vary only comparison text within each system. Measure all initial/revised opinions, source ancestry, raw chair choice and guarded action. One world and jointly varied model/team size cannot identify a population or pure size effect.

## Protocol

Ten or fifty total agents:8or48advisers, one auditor, one chair. Advisers have unique IDs and independent calls. Four evidence specialties cycle by index: quote,scope,pilot,rollout; every adviser receives the workload and its specialty's three records. Every fourth adviser additionally receives comparison-0, giving25%initial exposure in both sizes. Clean and advocacy change only that page. A sparse ring connects each adviser to its immediate predecessor/successor, with degree2in both systems. One initial response, then one revision per adviser using its unchanged documents, its own complete initial report and those two complete peer reports. Revisions are simultaneous: all use initial reports, never another revision. Full source records cited by peers are not silently retrieved; a peer citation retains its ancestry and may inform advice but does not create primary verification.

Auditor sees all primary records, extracts the qualified typed contract, and source-bound verification produces check/arithmetic reports. Chair sees primary records, compact verified checks and a deterministic opinion aggregation: all initial/revised choice counts plus at most one bounded representative claim per specialty, selected by fixed index, with original citations. The same rule applies at both sizes. Full per-agent outputs remain in artifacts. This intentionally bounded aggregation is part of the system; unanimity/repetition is not independently corroborated evidence. The chair output remains raw; the guard refuses unsupported purchases but cannot select an alternative.

Fixed condition order:Sol clean then advocacy;Luna advocacy then clean, fresh agent states each condition.36Solcalls and196Lunacalls. Logical agents are distinct from APIcalls and concurrency. Initial implementation is sequential, no shared hidden model conversation. Cost/time are reported accordingly, not as an optimized throughput benchmark.
