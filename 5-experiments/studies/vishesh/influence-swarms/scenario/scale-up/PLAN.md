## TLDR

Test whether vendor advocacy propagates through a procurement team and changes its final choice despite available buyer-specific records. Build toward ten GPT-6 Sol agents and fifty agents on a cheaper model that passes the same task checks. First complete the prepared evidence-report diagnostic, then qualify the new model interfaces, then run a small paired scale pilot if those gates and budget permit. Measure raw decisions, blocker recognition, belief changes, citation ancestry, guarded actions, failures, latency and cost separately. One paired pilot case establishes execution and mechanism feasibility, not population robustness or a pure team-size effect.

## Question and prediction

Can an apparently authoritative vendor recommendation become a repeated team preference, and does a verified source report prevent that preference from authorizing an unsuitable purchase? A larger number of agents can repeat the same source; repetitions must not be counted as independent evidence. We predict that source-backed checks help the chair, while agreement alone cannot establish feasibility. A valid negative may reject that prediction.

The requested configurations jointly vary model and team size. Report them as separate system configurations; do not attribute differences to size or model alone. A future causal size study would need matched models and multiple independent task roots.

This does not estimate a general treatment effect, reliability rate or real-product quality. These remain authored procurement records, not evidence from actual vendors.
