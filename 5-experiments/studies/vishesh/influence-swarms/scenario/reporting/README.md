# R43 recorded-report viewer

`r43-main.html` is a standalone saved-data report for native run `influence-swarms/1005-013159-b8c609`. Open it in a browser or serve this directory locally. `r43-main.json` is its numeric/categorical projection; no raw model rationale is published. The source templates are `render_main.py` and `main-template.html`.

The viewer preserves all 108 assigned finals, the separate first-pass dependency projection, reference buyer policy/claims, and visible report-field mismatches. Its four-stage animation is logical report progression, not timing, hidden reasoning or an identified causal transmission mechanism. Shared checker cards show the actual two checker outputs for the chosen root/repetition. Correct action and field accuracy are separate.

To rebuild from the authorized private native evidence bundle, run `python3 render_main.py --results /path/to/native-R43-E0-01 --out r43-main.html`. The renderer replays both outcome analyses and refuses a different assignment count. Run the owning saved-request and semantic audits first; required inputs include their saved audit, semantic differences and authored interpretation notes. Public projection readers can inspect the JSON and embedded HTML data without access to private model prose.
