# PI critique of Healing Helping Hands C3

2026-10-04. Same-author PI-style review, not independent peer review. Evidence: C3 immutable source, plan, raw-response audit, 270-world/8,100-frame replay audit, results and ledger. Latest repository pulled before review.

**Verdict: credible engineering demonstration and valid negative result; weak evidence for a useful heterogeneous agent or autonomous swarm.** Execution was repaired, scientific ambition was not established.

| Dimension | Assessment | Decision |
|---|---|---|
| Question | Two separable questions—model composition and network repair—were bundled. | Focus C4 on one actionable routing decision. |
| Scenarios | Six failure scenarios are useful mechanism probes, but repeated accuracy templates and supplied provenance make the semantic task easy. | Add controlled semantic challenges; still label synthetic limits honestly. |
| Controls | Jev-only and central-verified prevented misleading success claims. Both defeated the intended superiority claim. | Retain Jev, add same-referral-count random control; do not weaken central baseline. |
| Capability | Jev/composite ceiling of 600/600 leaves no headroom for improved accuracy. Qwen errors were repaired by Jev. | Test selective use, not another always-reviewed composite. |
| Measurement | Exact saved-data replay and assigned denominators are strong. Item traffic and logical rounds are not matched compute or real latency. | Separate actual collection charges from derived deployment calls; no efficiency claim from animation. |
| Sample size | 270 worlds are nested in three corpora; 200 agents are not independent n. | Family-stratified reporting with explicit dependence, no inflated CIs. |
| Agent definitions | Stateless, pinned, auditable. Qwen omitted the claim and used fixed accuracy extraction; Jev received claim/report. | Supply the claim to Qwen before introducing distractors, qualify the changed prompt. |
| Data integrity | All 1,800 calls terminated and all 270 worlds replayed; historical failures retained. | Preserve journals, hashes, missing states and original ledger. |
| Resources | C3 succeeded for about 2.5 cents API, but all 2,179 allowed request slots were consumed. | Explicit +492 proposal within remaining dollars; no reset or hidden spending. |
| Reproducibility | Saved tape and deterministic world replay reproducible; hosted model regeneration is not guaranteed. | Freeze complete wire inputs and variant-order manipulation. |
| Visualization | Attractive measured replay; can be mistaken for live language-agent cooperation. | Route/error tiles and cost-quality comparison tied to actual records; keep old animation historical. |

Accepted prior suggestions: stronger controls, new useful question, reliable native transport, honest scoped sample units, preserved budget. Revised: broader task families are synthetic engineering challenges, not independently authored real-world evidence. Deferred: replicated-database/equal-network-cost benchmark until there is a justified new architecture question. Rejected: another identical C3 run, higher packet capacities seeking a win, adding agents to inflate sample size, or treating zero observed failures as universal reliability.

The strongest competing explanation for C4 is that Qwen's two variants share the same mistakes, so agreement is a poor uncertainty signal. The same-budget random control tests whether disagreement adds information; Jev-only bounds the quality sacrificed. A useful null ends this line rather than motivating post-hoc thresholds.

Open issues: externally valid reports, independent reviewer assessment and live production cost/latency remain unestablished. None is relabeled as a pass. The concrete C4 plan is prepared for owner approval before allocation, per the requested runbook.
