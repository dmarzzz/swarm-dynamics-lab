# C7 draft: evidence-scope reliability and fresh execution stability

Status: OFFLINE PREPARATION; not approved, funded, preregistered or launched. C6 remains unchanged. This draft corrects the earlier baseline assessment: C6 is a useful finite diagnostic, but **baseline GAP** under the requirement for challenging cases and fresh-run reproducibility. No additional study allowance is created.

Useful engineering decision: on explicitly scoped multi-report evidence packets, is a single Jev classifier sufficiently reliable for accepting a claim, or does Haiku agreement identify errors worth escalating? Scope is the declared synthetic evidence grammar and exact model routes. This does not establish natural-document generalization or collective swarm benefit. The two-pass cost disadvantage is already known; this study would test reliability and failure stability, not revive a cost-saving claim by changing prices or comparators after observation.

Before implementation, define six strata: target-task distraction, metric distraction, explicitly superseded measurement, same-scope unresolved conflict, duplicate evidence and absent target measurement. Every packet explicitly names task, session, metric and provenance; the contract says irrelevant scopes are excluded, superseded evidence is withdrawn, duplicates add no evidence and unresolved opposing signs imply UNCERTAIN. SUPPORT requires positive difference; REFUTE includes zero/negative; missing or conflicting target evidence gives UNCERTAIN. No implicit meaning of “different test.” Conflict and absence strata include measured controls, not only one label. A gold constructor and an independently implemented visible-text parser must agree; same-author provenance is disclosed. Check renaming/order/duplication invariance and target-value reversal responsiveness.

Offline development:18 inspected cases, one per stratum×label; never held out. Main proposal:72 independently seeded event roots,12 per stratum, balanced4 per label. Each root samples names, values, distractor scopes and evidence order; three fresh executions per root do not create additional independent samples. Main seeds/fixtures are generated and hashed only after parser/contract freeze, then locked before qualification; grammar remains inspected. Population is this generator, not natural reports. Any claim about natural reports remains GAP; natural source collection and independent semantic adjudication would need a different corpus plan.

Comparators: same visible evidence for Haiku A/B order variants, always-Jev and deterministic parser. Retain fixed same-count random referral and analytic random expectation. No hidden evaluator metadata or conversation context. Actual route/model/provider, schema, temperature, token cap, exact requests and responses are recorded. Same models as C6, no fallback. Provider/version changes split cohorts and stop pooling.

Qualification:36 new balanced cases;12/class; each actor must score≥31/36 overall and≥9/12/class, with108/108 complete valid calls and manual review of all errors. This is competence, not efficacy. Failure stops before main; no automatic repair retry. Main:72roots×3fresh sequential sweeps×3actors=648calls, no cache reuse. Counterbalance actor call order across roots and sweeps; keep identical case/prompt bytes within each actor across sweeps. Report elapsed separation and actual hosted route identity, not assumed independent backend sampling. Provider failures remain distinct from semantic errors.

Endpoints: root-averaged classification error, false acceptance, abstention error, agreement error-detection recall, error overlap, actual API cost and per-root label-switch rate across the three fresh sweeps. Report each sweep separately, paired root differences and stratified root-bootstrap95%intervals; repeated answers stay within root clusters. With72roots, a worst-case Bernoulli standard error is about0.059 (95%half-width≈0.116); this supports only coarse reliability differences. Zero errors over72independentroots has a one-sided95%upper bound≈4.1%, not a sub-percent guarantee. Family-specific n12 is diagnostic. Predeclare that small effects or wide intervals are inconclusive; no significance-driven expansion. Agreement economics includes both passes, and parser success precludes claiming model necessity.

Missing calls receive separate missingness counts and sensitivity bounds, not fabricated labels. All main endpoints are frozen before calls; no selective root removal for surprising outcomes. If case audit finds a fatal ambiguity, stop qualification and revise prospectively rather than relabel live cases.
