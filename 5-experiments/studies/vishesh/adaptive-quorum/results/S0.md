Protocol/source revision: `c9dc5be`. Local Laya English checkpoint and installed dependency versions are in [manifest](laya-S0-manifest.json). Hardware: Apple arm64, CPU inference with two torch threads. No hosted API calls, no inference on shared servers, no new cloud resources.

Both the scripted engineering replay and local Laya qualification completed **144 arm outcomes**: six task clusters × three worlds × two deadlines × four policies. Laya made 972 physical decisions over full counterfactual tapes, taking 82.66 seconds inside episode inference (excludes model loading). Four policy outcomes reuse each team tape; 144 outcomes are not 144 independent samples. Raw episodes and model probabilities are hub artifacts, not large files in git.

Both backends had zero invalid outcomes and passed the predeclared clean-task screen. Laya's four policies each made 12/12 correct clean decisions (six tasks under two deadlines). This easy screen establishes basic instrument competence only.

Fixed and adaptive decisions were identical. All six short-deadline paired loss differences were zero; [paired values](paired-S0.json). No adaptive benefit is established. Early commitment makes majority and this first-non-abstention central baseline vulnerable by construction; a deliberative centralized baseline must be included before claiming a swarm advantage.

The fixed evidence floor did not prevent every false commitment: root availability is not proof that a ballot faithfully integrated those roots. This is a concrete reason to avoid presenting provenance counts as calibrated independence or truth. Scripted and Laya behavior differ on conflicting evidence; the complete per-cell summaries are retained rather than pooling backends.

## Failures and limitations

A wrapper import failed before assignment creation. Attempt v1 then failed during Laya initialization because the built wheel omitted `laya.backends`; no model calls occurred. The amended v2 used the same pinned source directly, not a different checkpoint. These setup failures are preserved in the protocol amendment and local records. Laya also warned about a temperature for choice sets of 11 or more being clamped; this study has four choices and treats probabilities as uncalibrated regardless.

S0 is deliberately small and synthetic. Neither threshold efficacy, biological replication nor generalization to real API selection is demonstrated. All three roots arrive by the deadline, so S0 is weakly discriminating for adaptation, as stated before execution. No S1 or S2 was automatically launched.
