# Experiments

One folder per experiment: `experiments/<id>/README.md` plus `src/` and `results/`. An experiment needs an
accepted hypothesis. Protocol and metrics are written before the first run. Keep large outputs out of git
(see .gitignore) and link them instead.

[Evidence confidence and sample sizes](EVIDENCE.md) cover the implemented exploratory studies as well as accepted experiments. See the [metadata rubric and update instructions](EVIDENCE-METADATA.md). Metadata does not promote an exploratory study through the research gates.
