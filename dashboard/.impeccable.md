# swarm-dynamics-lab dashboard: design context

## Design Context

### Users
- **Hackathon judges** (AI Village, Grove Research). They open one URL, cold, for maybe two minutes. Job: understand in ten seconds what this team built, how much, and whether the method is serious. They care about rigour and process more than volume.
- **The three researchers** (dmarz, vishesh, shadow). They return many times a day to steer dozens of agents. Job: see what is moving, what is stuck, where the gaps are, what needs a human.
- Context: laptop on a judging table, projector, or a phone in a hallway. Mixed light conditions.

### Brand Personality
- Three words: **rigorous, calm, alive**.
- Voice: a lab notebook written by a good science editor. Plain sentences, concrete numbers, no hype verbs (no "elevate", "unleash", "seamless"). Sentence case. No emoji. No em dashes.
- Emotional goal: the judge should feel "this is a working research instrument", not "this is a demo". Quiet confidence. Density earns trust.

### Aesthetic Direction
- **Editorial research lab.** Think a printed annual report from a physics institute crossed with a good newspaper data desk (FT, The Economist graphics, Quanta). Warm paper in light mode, deep ink in dark mode. Hairline rules instead of boxes. Numbers set large in a serif, labels small in a grotesk.
- Swarm motif, used with restraint and always carrying data: every library entry rendered as one particle in a field ("each dot is one source an agent read"); agents as small marks moving through a pipeline. Never decorative blobs.
- Type: **Newsreader** (variable serif) for display numerals and headings, **Geist** for UI and body, **Geist Mono** only for ids, hashes and agent handles. Tabular figures everywhere numbers align.
- Colour: tinted neutrals (warm paper / ink, OKLCH). One accent, a pigment vermilion, for "live" and the primary path. Three team colours, desaturated pigments (dmarz ochre, vishesh slate blue, shadow moss). Source kinds get a quiet 6-step categorical set derived from the same pigments. Colour always means something.
- Theme: light and dark, both first class, follow system with a toggle.
- **Anti-references:** generic AI dashboards (purple/blue gradients, glowing cards on black, glassmorphism, emoji headers, hero metric template with gradient accent, identical KPI card rows), Grafana/Datadog chrome, shadcn defaults, rounded cards with left colour stripes.

### Design Principles
1. **Human sentence first, number second.** Every panel opens with a one-line plain-English reading of the data ("Agents added 312 sources in the last hour, mostly papers on swarm detection"), then the chart, then the table.
2. **Show the method.** The prior-art gate (Scan, Survey, Hypothesis, Experiment) is the team's thesis. It should be visible from every view, not buried.
3. **Rules, not boxes.** Group with whitespace and hairlines. Use a container only where elevation means something (the entry drawer).
4. **Every mark is data.** No ornamental charts, no sparklines that say nothing. If a dot moves, it is an agent or an entry.
5. **Dense but legible.** Small type is fine when the hierarchy is clear. 13px floor for data, 15px for prose, 44px touch targets on mobile, WCAG AA contrast in both themes, reduced motion respected.
