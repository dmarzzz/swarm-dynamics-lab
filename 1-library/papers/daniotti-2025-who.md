## Summary

Trains a neural classifier to recognise AI-generated Python functions and applies it to over 30 million GitHub commits by about 170,000 developers (arXiv abstract). Estimates that AI writes 29% of Python functions in the US, a modest and shrinking lead over other countries, and that this raised quarterly code output by 3.6%; experienced programmers capture nearly all gains.

## Contribution

Population-level prevalence of machine-generated code, by country and over time, from per-function classification at scale.

## Key results

- Measured (abstract): about 29% of US Python functions AI-written.
- Estimated (abstract): +3.6% quarterly output attributable to AI; gains concentrated among experienced developers.

## Methods and models

Neural classifier for AI-generated Python functions; GitHub commit histories; geographic and seniority breakdowns. Abstract read only. The Semantic Scholar abstract gives 160,097 developers; the arXiv abstract says 170,000.

## Limitations and open questions

Classifier calibration on code is not described in the abstract. Abstract depth.

## Relevance to us

Extends population-level estimation to code, the artefact that coding-agent swarms would leave in repositories.
