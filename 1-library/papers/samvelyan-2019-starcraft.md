## Summary

SMAC is a benchmark for cooperative, partially observable MARL based on StarCraft II micromanagement, where each unit is an independent agent acting on local observations. It offers a set of challenge maps, recommended evaluation practice, and open-source code including the PyMARL framework, to replace one-off toy problems that make progress hard to measure.

## Contribution

The de facto cooperative MARL benchmark (used by [[rashid-2018-qmix]], [[yu-2022-surprising]]).
