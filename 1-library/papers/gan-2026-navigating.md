## Summary

This review studies LLM-agent security through the software lifecycle, emphasizing risks that cross tool-use, memory-management and environment-interaction boundaries. It identifies six agent features grounded in information and control flow and reviews mitigations and limitations. Four case studies examine web search, gaming, navigation and software development.
