## Summary

This systematization separates transient context manipulation from persistent memory contamination and organizes tool supply-chain risks by discovery, implementation and invocation. It describes a viral agent loop in which agents relay adversarial material during ordinary runtime activity. The proposed zero-trust architecture emphasizes provenance and privilege boundaries rather than treating plausible natural language as trusted control.
