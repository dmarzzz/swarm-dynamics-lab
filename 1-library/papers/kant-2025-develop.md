## Summary

A position paper arguing that static benchmarks miss the skills needed to build and run dynamic engineered systems (managing uncertain trade-offs, proactive adaptation), and that automation sandbox games, Factorio in particular, should be used to train and evaluate AI agents' system-engineering ability over long horizons. The author later co-authored the FLE v0.2 multi-agent release notes with the FLE team.

## Contribution
