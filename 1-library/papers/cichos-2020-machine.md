## Summary

A review of machine learning in active-matter research: deep networks for image analysis and tracking, recurrent nets and random forests for time series, and, more ambitiously, using ML to relate genetic code to emergent bacterial behaviour, find navigation strategies in complex environments (including reinforcement learning for smart microswimmers), and map physical cues to animal behaviours. It discusses how active matter and ML can benefit each other.

## Contribution

Earliest high-profile review linking RL and active matter; superseded on the RL side by [[cai-2025-reinforcement]].
