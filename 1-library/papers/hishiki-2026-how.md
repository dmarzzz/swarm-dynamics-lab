## Summary

Replaces the rule-based agents of the Social Particle Swarm model (agents move in 2D and play the Prisoner Dilemma with neighbours) with Gemini 2.0 Flash agents given Big Five scores and varying memory lengths. Memory length is a control parameter: even minimal memory sharply suppresses cooperation, and increasing memory moves the system from stable cooperative clusters through cyclic cluster formation and collapse to scattered defection. Without assigned personalities Gemini cooperative disposition dominates and cooperation largely survives; sentiment analysis shows the model reads longer memory more negatively.

## Contribution

Memory length as a measured control parameter of collective behaviour in a spatial LLM swarm.
