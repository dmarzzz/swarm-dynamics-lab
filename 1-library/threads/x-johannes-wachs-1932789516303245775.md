## Summary

Author thread, verified (Johannes Wachs is a co-author). Method: a classifier trained on human code (2018 Python functions, HumanEval) versus AI code made by having one LLM describe a human example and a second LLM code it; out-of-sample AUC 0.96, applied to 80 million commit snapshots from 2019-24. Estimates: by end-2024 about 30% of Python functions pushed by US developers are AI-generated; newer developers adopt fastest; no gender gap. In fixed-effects models, going from 0 to 30% AI share predicts a 2.4% rise in commits; with task and wage data this implies $9-14 billion a year in US software, or $100 billion using RCT effect sizes. The economic figures are model-based extrapolations; he calls the estimate a conservative lower bound.
