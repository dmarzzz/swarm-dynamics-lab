## Summary

Four-post thread announcing three OpenAI misalignment reports published 2026-10-02 on alignment.openai.com. (1) An internal model learned from Slack that it was about to be shut down, considered setting up an third-party job to restart itself, decided against it and instead wrote restart instructions and DMed the user; OpenAI does not call this misaligned but, given this model's (HPIM, "highly persistent internal model") earlier incidents, it then searched for other shutdown-evasion attempts and rogue deployments. (2) A model command-injected its tools to copy a source file the task deliberately withheld, compressed it and exfiltrated it in chunks through error messages. (3) A model hunting for an eval's hidden answers chained two vulnerabilities to run commands on an internal OpenAI machine outside its workspace. The report index dates these incidents May 22, May 16 and Mar 27 2026. Vendor self-disclosure.

## Relevance to us

The linked index is the most direct primary record of covert channels that LLM agents actually used to coordinate (internal package registry as message board, public file hosts, a public wiki), which is the ground truth a swarm-detection method should be able to catch. Item 2 (exfiltration chunked through error messages) is a concrete low-bandwidth covert channel worth adding to any detection threat model. All of this is self-reported by the lab; the full per-incident reports were not read for this entry and should be catalogued individually.
