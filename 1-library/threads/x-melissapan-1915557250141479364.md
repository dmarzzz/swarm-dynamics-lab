## Summary

Author thread by Melissa Pan, second author of the linked paper (Melissa Z. Pan in the author list). Claims: MAST is a multi-agent failure taxonomy of 14 failure modes in 3 categories, built by studying 7 multi-agent systems and more than 200 traces with grounded-theory freeform annotation and inter-annotator studies. An LLM-as-a-judge annotator labels the failure modes in a trace for scalable diagnosis. Case study: when a change in agent topology improved performance by 9%, the annotator showed which failures changed. Takeaways (the authors' view): careful system design can mitigate many failures and each failure mode needs its own fix. A reply to another user adds that metrics beyond correctness are needed to judge multi-agent systems.

## Relevance to us

[[cemri-2025-why]] gives a vocabulary and an automatic annotator for how agent collectives fail, which we can reuse to label failures in fork-and-merge experiments and to separate honest coordination failures from injected corruption. The taxonomy does not cover adversarial agents as such.
