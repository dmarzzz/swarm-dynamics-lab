## Summary

Author thread (6 tweets) by Helen Qu, a co-author of the linked paper (name matches). Claims: multi-agent search can be modelled with the theory of phase transitions; search problems are classified by evidence reusability, and communication helps when agents can build on each other's results; a critical degree of inter-agent communication is derived per task type. Measured: deterministic rule-based agents match the theory well, while LLM agents often do worse than theory and are volatile across experimental conditions. Observations on LLM agents: they do not communicate with all neighbours, especially not negative results; higher reasoning effort makes them more strategic so they all ask the same questions, which removes the value of communication; many results are model-family specific. Recommendation: design communication protocols jointly with task type and model family.
