## Relevance to us

[[austgen-2024-liquefaction]] attacks the "one key = one person" premise that personhood and identity schemes such as [[adler-2024-personhood]] and [[siddarth-2020-who]] rest on: a key held in a TEE can be shared or rented without anyone seeing it. For agent collectives this means a credential bound to one agent can be silently controlled by several, or one operator can rent many, which undercuts any Sybil defence keyed on credential ownership.
