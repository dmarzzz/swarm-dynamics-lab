## Relevance to us

[[debenedetti-2025-defeating]] separates trusted control flow from untrusted data so injected content cannot change what an agent does, a design-level defence against the prompt-injection hijack we expect on forked parts. The released code ([[gh-google-research-camel-prompt-injection]]) makes it testable; see [[x-lbeurerkellner-1913204991977828708]] for a noted weakness and [[beurer-kellner-2025-design]] for related patterns.
