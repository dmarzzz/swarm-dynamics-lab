## Relevance to us

A live, deployed instance of the most common on-chain Sybil heuristic: cluster wallets by mutual transaction edges and collapse each cluster to one identity. Relevant to swarm-detection because it is the same coordination-from-traces inference we would apply to agent swarms, and to sybil-resistance because the obvious evasion (fund wallets from independent sources, never transact between them) is exactly what a careful operator of many agents does. Useful as a "what practitioners deploy" example; no evidence of effectiveness.
