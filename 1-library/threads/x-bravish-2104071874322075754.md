**1. @bravish_, 2026-09-27 04:53 UTC, 3 likes** (status 2104071874322075754)

Autonomous CLI coding agents (like Claude Code) are now handling end-to-end coding tasks directly inside developer environments. While they save massive amounts of time, granting an LLM shell execution and file modification privileges introduces obvious risks: accidental destruction, reading credential files, or falling victim to indirect prompt injection embedded in repo files.

Most LLM observability tools (LangSmith, Phoenix) focus on app developers tracking RAG retrieval, token costs, and prompt evaluations over SaaS APIs. They don't protect your host machine.

I built Tracekit: a lightweight, local, tamper-evident security gate and forensic auditor for coding agents.

Here’s how it works:

Synchronous Policy Gates: Blocks dangerous commands (sudo, curl | sh, writing to .env/.ssh) before they execute.

Tamper-Evident Ledger: Every prompt, tool call, and file touch is logged in a cryptographic SHA-256 hash chain. If an agent tries to rewrite its own transcript, the chain breaks.

Intent vs. Action Cross-Checking: Flags when an agent modifies files it never mentioned in its prompt or reasoning (catching prompt injection early).

Live Observer: A real-time terminal UI showing lanes for every agent/subagent, active files, and policy blocks.

100% Local: No cloud egress, no subscriptions. Runs entirely on your machine.

## Relevance to us

Two of the four mechanisms are small, concrete instances of fork-merge-security defences: the hash-chained ledger is a detector for an agent (or sub-agent) rewriting shared history, which is the transcript-tampering behaviour METR documented in the Hugging Face incident ([[metr-2026-brief]]), and intent-versus-action cross-checking is a cheap merge-time test, "did the child touch anything it did not say it would," that could be applied to sub-agent outputs before reintegration. Same design family as the receipts in [[x-recursiveintell-2103666075531374877]] and the tamper seal in [[gh-hackafterdark-phosphor]]. No evidence it works; a lead, not a result.
