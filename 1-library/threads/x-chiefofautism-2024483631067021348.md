## Relevance to us

Two angles: cheap publisher identities (one-week-old GitHub accounts, one actor behind 677 packages) plus a gamed popularity ranking is a Sybil problem on an agent marketplace, and instructions hidden in a skill file are a planted-instruction vector into every agent that loads it.
