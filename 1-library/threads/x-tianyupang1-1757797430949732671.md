## Relevance to us

[[gu-2024-agent]] shows one corrupted input spreading through an agent population via memory and pairwise chats, the same mechanism as a corrupted forked part contaminating others on merge. It belongs with [[lee-2024-prompt]] and [[cohen-2024-here]] as evidence that a single compromised member can take over a collective, which sets the bar for any merge threshold we propose.
