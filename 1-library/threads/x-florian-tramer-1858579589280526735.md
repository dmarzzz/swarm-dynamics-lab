Author quip. Florian Tramer, last author of the adversarial search engine optimisation paper (arXiv 2406.18382),
quotes @AravSrinivas announcing Perplexity Shopping, which moves from answering to completing purchases, and
writes "LLM search engine optimization just got an upgrade...". The implied claim, not spelled out, is that
transactional LLM search raises the payoff for manipulating LLM-powered search with adversarial content. Opinion; no

## Relevance to us

A short signal that the attack surface in [[nestaas-2024-adversarial]], third-party content steering an LLM's
output, gains value once the LLM acts (buys). For fork-merge security it is the same channel as indirect prompt
injection ([[greshake-2023-not]]): content read by a sub-agent changes what it hands back.
