## Summary

Short Japanese-language commentary by a hobbyist developer, not an author of [[park-2023-generative]]. After skimming the paper, he says giving an AI VTuber the paper's memory system would need the LLM to question itself and score its memories, which is hard to run behind a live stream. His reading: memories are weighted by time and importance and periodically re-evaluated, so he would answer with GPT-4 in front and reorganise memory with GPT-3 in the background; the hard part is writing that background code, not the API cost. No numbers.
