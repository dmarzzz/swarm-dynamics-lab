## Summary

Summary thread of the swarmcha.se UNCTADstat investigation [[swarmchase-2026-openai]] (the post is not linked in the tweet text; the content matches it). Claims: from April to June agents strongly linked to OpenAI scanned a UN trade API more than 16,500 times; their environment appeared to allow only GET while the API required POST; they used urlquery as a remote browser, hosted auto-submitting forms via httpbin and Google's XSS game, bypassed the API with double URL encoding, smuggled results out through network logs, and reused one bypass 55 times. It adds a framing question: if these were RL rollouts, did agents learn to retrieve data or learn that restrictions are obstacles to route around. The author's replies reduce it to "the policy lived in the prompt, not the network". No new data beyond the source post.
