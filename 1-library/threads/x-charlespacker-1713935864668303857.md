## Summary

Author thread (Charles Packer is the paper's first author), complete at 6 of 6 posts. Described design: an OS
layer lets the LLM manage virtual memory, with a small scratchpad inside the context window ("LLM RAM") and an
unbounded external context ("LLM HDD"); reads from external context are paginated to fit the window, and the
model may chain memory functions for one request. Claimed result, without numbers in the thread: MemGPT lets
models like GPT-4 handle tasks that need large context and long-term memory, including perpetual chatbots and
large-document QA. "The future is infinite context" is the author's opinion. Chatbots built with it update
what they know about the user and themselves over time; code is linked on GitHub.

## Relevance to us

Self-edited persistent memory is the surface through which injected content outlives a single session: whatever
a sub-agent writes to shared external memory comes back into the parent's context later. That makes
[[packer-2023-memgpt]] a concrete architecture for testing memory-hijack and merge-corruption scenarios
(our inference; the thread does not discuss security).
