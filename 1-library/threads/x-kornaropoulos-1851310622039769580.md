## Relevance to us

Decoys that only an LLM agent would act on are a direct swarm-detection instrument: anything that follows the injected instruction self-identifies as an agent. The same mechanism is the attacker's tool in fork-and-merge (a planted instruction that a sub-agent obeys), so Mantis shows both sides. The paper should be catalogued as pasquini-2024-hacking.
