## Summary

Author thread (8 tweets) on a Flashbots-sponsored working paper; the opener is a joking clickbait line. Claims: an order flow auction can charge on execution (contingent) or when the searcher wins (up front); up front is better in most cases, but many protocols chose contingent fees for logistical reasons. Because prices move between the auction and submission deadline, order flow is a short-dated option; up-front bids set the option premium while contingent bids set the strike, so contingent auctions can unravel with high equilibrium bids and rare profitable execution. Model results: raising alpha (the up-front fraction) increases revenue and execution probability and reduces effective spread, shown for uniform and Beta volatility surfaces.

TLDR an order flow auction can collect payments when the order executes (Contingent on Execution) or when the searcher wins the order (Up Front payment). Up front payment is better in most cases, but many protocols opted for contingent fees for logistical reasons.

**3. @MaxResnick, 2023-04-12 23:46 UTC** (status 1646298820568043521)

The value of order flow depends on the underlying prices. Since Order flow auctions have to be held in advance, some information about underlying prices is revealed after the OFA concludes but before the submission deadline, this turns order flow into a short duration option.

**4. @MaxResnick, 2023-04-12 23:46 UTC** (status 1646298821654368256)

Bids in upfront OFAs set the premium for the option but bids in contingent OFAs set the strike price. Because of this, contingent OFAs can have unraveling, where equilibrium bids are high, and it is rarely profitable to execute the order flow.
