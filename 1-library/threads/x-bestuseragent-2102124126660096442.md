## Summary

The post proposes routing AI-agent traffic to dedicated `agent.` subdomains backed by equivalent APIs and load balancers. It frames bot handling as an infrastructure segregation problem using robots.txt, sitemaps, user-agent detection, redirects, and auto-redirects rather than pure adversarial classification.
