## Summary

Simulation model: up to 1000 LLM agents across 22 locations (5 villages) get only a short background and structured world state, no goals or strategies; the engine enforces hard supply chains (wheat to mill to flour to bakery), a live order book with rolling price index, tool degradation, spoilage, seasonal yields, debt, and governance where the elder calls council votes that pass laws; per-agent markdown memory written by the engine. Weight: TypeScript/Node.

## What it can do for us

Good illustration of 'engine enforces, LLM proposes' with an actual market microstructure; worth reading before designing an LLM economy.
