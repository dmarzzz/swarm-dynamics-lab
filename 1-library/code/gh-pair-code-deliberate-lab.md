## Summary

Platform: web app for designing and running online experiments on human + LLM group dynamics (staged experiments, chat rooms, agent participants), with researcher and developer docs and local/deploy guides. Deployed publicly for 12 months (88 experimenters, 9,195 participants per paper). LLM-native: agents as first-class participants. Weight: TypeScript web stack.

## What it can do for us

Use if we want human subjects interacting with our agent swarms (e.g. testing whether humans detect coordinated agents).
