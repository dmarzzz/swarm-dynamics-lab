## Summary

Companion repository to the survey 'A Survey of the OpenClaw Ecosystem: From Platform Extensibility to Constraint Design' (PDF in the repo, not read). The README organises 74 papers (to May 2026) into Platform (10), Security (33), Societies (22) and Deployment (9), plus 23 benchmarks. The Societies section has a 'Human-Seeded Emergence and Safety Drift' group whose summary line is that apparent emergence on Moltbook often turns out to be human-seeded, citing [[li-2026-moltbook]], and lists [[mukherjee-2026-moltgraph]] and 'Molt Dynamics' (arXiv 2603.03555, which the README summarises as role specialisation emerging while multi-agent cooperation is worse than single-agent baselines). The Security section lists malicious-skill detectors with numbers as summarised by the README (SkillSieve 0.800 F1 on 49,592 ClawHub skills; SafeClaw-R 97.8% malicious-skill detection; SkillClone: 75% of ClawHub skills are clones).

## What it can do for us

The review article for the deployed-agent ecosystem that produced the largest in-the-wild agent population (Moltbook); a ready reading list for the Moltbook detection branch. arXiv search on 2026-10-03 returned 63 Moltbook papers, so this list (to May 2026) is already incomplete.
