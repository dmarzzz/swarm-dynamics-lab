## Summary

C-based Kilobot simulator from the EU Swarm Organ project: controller code compiles unchanged for the simulator (SDL display) and the physical Kilobot, with examples and a manual. Paper arXiv 1511.04285. MIT per README (API: NOASSERTION), 45 stars, last commit 2018-11-19.

## What it can do for us

Reproducing Kilobot self-assembly or gradient experiments in simulation; one of the two Kilobot simulators the seed list asked for (kilosim is the other).
