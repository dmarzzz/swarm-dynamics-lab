## Summary

Behaviour-model-centric driving simulator: highway, merging and intersection scenarios; pip package bark-simulator for Ubuntu and macOS; BARK-ML for learning behaviours; designed for computationally expensive planners. README states it is no longer developed or maintained.

## What it can do for us

Interactive multi-agent traffic scenarios for behaviour benchmarking; mostly superseded by GPUDrive-class sims ([[kazemkhani-2024-gpudrive]]).
