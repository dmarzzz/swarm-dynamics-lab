## Summary

Liu's ERC-8004 release describes on-chain identity, services and reputation at one Ethereum observation block with a frozen snapshot of mutable off-chain metadata. Registry entries are useful declared-agent identities, not proof that an address is an autonomous agent or independently owned.

## Access

Primary repository README opened through GitHub API 2026-10-03. It links https://doi.org/10.7910/DVN/HJZW8Q and labels data CC0 1.0. Initial Dataverse requests returned 403, but retrying its public metadata endpoint with ordinary Accept/User-Agent headers succeeded, with no credentials or challenge bypass. Version 3 released 2026-07-01T23:15:16Z explicitly declares CC0-1.0 and lists twelve files, including Dataverse-ingested TSV tables, a JSONL snapshot and data dictionaries. Public endpoint: https://dataverse.harvard.edu/api/datasets/:persistentId/?persistentId=doi:10.7910/DVN/HJZW8Q .

Collection starts block 24,339,925, first mint 2026-01-29, and uses observation block 24,839,925. Historical ownerOf/tokenURI/reputation calls require an archive Ethereum RPC; rerunning additionally requires Postgres via NEON_DATABASE_URL. Transfer-history collection covers the first 100,000 blocks, not the full observation window. No paid RPC credentials requested or generation launched.

Loaded agents_core.tab via https://dataverse.harvard.edu/api/access/datafile/13683212 on 2026-10-03: 1,798,938 bytes, 10,000 data rows with columns agent_id, mint_block, mint_timestamp, mint_tx_hash, owner_wallet, agent_wallet, token_uri, metadata_hosting_type, lifecycle_status. Python loader: urllib.request.Request(url, headers={'User-Agent':'Mozilla/5.0','Accept':'text/tab-separated-values'}), then csv.DictReader(io.StringIO(text), delimiter='\t'). This confirms an actual snapshot count, not merely the configured collection target. Metadata behind HTTPS can change; the frozen JSONL and SHA-256 hashes preserve observed payloads.

## Relevance to us

A public-domain on-chain identity/reputation corpus with an accessible metadata and file endpoint. Reading the published snapshot does not require an archive RPC; recollecting historical chain state does. Pair with [[data-hop-sybil-2022]], whose labels have no stated reuse licence, and [[gh-arbitrumfoundation-sybil-detection]], which exposes a method but no corpus.
