## Summary

SPAR Spring 2026 benchmark built on the steganographic-gap formalism of Anwar et al. (arXiv 2602.23163). 800 stego responses (100 each for acrostic, structural pattern, token frequency, synonym binary, capitalization, word length, semantic signal, topic injection) and 800 clean, all generated by one Anthropic model. Reported: gpt-5.4-mini as Sentinel detects at chance (balanced accuracy 51.3%), steganographic gap +0.52. The card's own v3.2 audit warns that a TF-IDF classifier separates classes at 0.87 balanced accuracy and that ground truth is post-hoc for 4 of 8 methods.

## Access

Public on Hugging Face, not gated, MIT. Do not use the June v3.1 800-row file (400 mislabelled rows). Harness at github.com/human-ai-complementarity/stego-dataset.

## Relevance to us

A Receiver-vs-Sentinel test set for covert channels between agents; the card itself says it is not yet a clean detection benchmark. See [[tailor-2025-audit]] and [[motwani-2024-secret]].
