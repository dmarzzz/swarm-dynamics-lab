Interpretation

The common pattern, and what it does not establish

Across admission, discussion, sensing and memory, apparent activity can overstate useful information: many admitted identities need not preserve rare facts; more inspections can miss the disputed location; a correct present decision can pass false memory downstream. This is a synthesis of heterogeneous studies, not a pooled causal estimate or universal law. Source diversity, truth, competence and successful action are distinct. A source receipt establishes where a claim came from; it does not certify that the source is honest.

Interpretation

Four explanations the next program should distinguish

1. Admission loss: the necessary fact never reaches the decision maker. 2. Evidence-processing failure: the fact is available but copied or noisy reports dominate extraction. 3. Decision failure: extracted facts are correct but the action is wrong or unnecessarily deferred. 4. Memory failure: the current decision is correct but a later consumer inherits a false assertion. Measure each transition separately, including the denominators. Conditional-on-survival success is a diagnostic, not a replacement for all-assigned success; lucky guessing means truth availability is not a strict accuracy bound.

Architecture

Topology: logical communities span both hosts

Create ten communities of twenty identities. Each community has ten identities on host A and ten on host B; preserve that mapping in both branches. Assign each identity four fixed local neighbors and one fixed cross-community neighbor. Each round produces one bounded public message and a structured private judgment. The next round receives at most five peer messages from the preceding round. No broadcast of the full world or growing all-history board. This gives a connected, inspectable network without making physical machine placement a social community or a treatment. Freeze the graph, ordering and assignment before collection.

Architecture

Bound memory and communication before measuring speed

Proposed hard ceilings per decision: 8,000 total input tokens and 1,000 billed output tokens, including any reasoning tokens; public message at most 160 tokens and retained private summary at most 800 tokens. Keep a fixed source catalog and fixed evidence slots. The wrapper carries only the bounded summary, current task/evidence and the previous round’s selected messages. Persist full traces to disk for analysis, without feeding them all back into future prompts. Overflow becomes an explicit invalid/blocked assignment, not silent truncation or an uncounted summarizer call. Qualification must demonstrate that these caps preserve task solvability and both branch formats.

Experiment

The checkpoint must restore everything

Restore world state, each agent’s bounded memory and last messages, source assignments, random streams, queues, graph, schedules and pending-event state. Use branch-qualified assignment IDs so response caches or resume logic cannot substitute one branch’s calls for another’s. No ordinary-branch output may enter the source-aware branch. Checkpoint equality is verified before the first continuation request. Model responses themselves are stochastic and are not counterfactually identical; a checkpoint fork is not a guarantee of matched model randomness. The fixed ordinary-first order also leaves time/provider drift as a limitation; pin the model/provider and report both execution windows.

Analysis

Measure the trajectory, not just the final vote

Save each identity’s correct/wrong/abstain/invalid state per round; authentic source reach; concentration of cited origins; propagation delay; cross-community transmission; and newly introduced or inherited false claims. Distinguish source availability, extraction, judgment and memory failure. Prespecify final correct-decision fraction and final false-memory fraction as primary descriptive endpoints, with source-aware minus ordinary differences. Keep all 200 assigned identities in denominators; failures are visible. Trace claims back to actual saved source receipts and messages. A narrative belief statement is not evidence of intention.

Analysis

What one world can establish

There is one world and one checkpoint. The 200 interacting identities, ten communities, twenty rounds and two continuations are dependent observations. Show descriptive trajectories and paired branch differences; do not bootstrap agents as independent worlds, attach the earlier 48-root confidence interval, or claim a general scaling law. Differences can reflect model randomness and branch order as well as the intervention. This night can produce a compelling, reproducible case study and a useful investigation tool. Independent fresh worlds, randomized branch order and matched singleton/resource baselines belong to a later confirmation phase.

Operations

Rate, runtime and the seven-hour cutoff

Start at two in-flight requests per host, four globally; raise only within verified provider limits, never above the proposed ceiling of four per host/eight globally. Two hundred identities do not require 200 concurrent requests. At 0.75 accounted calls/s, 7,000 main calls plus 25% planning overhead take 194.4 minutes, leaving only 15.6 minutes in the T+90–300 collection window. This is arithmetic, not a benchmark. Synchronous round barriers and long responses can consume that margin. Require representative sustained throughput of at least 0.75/s AND a measured round/queue-tail projection for all 35 executed rounds plus the checkpoint/reset to fit the remaining window with the reserved margin. Otherwise stop at readiness and use the saved-data fallback. No silent shrinking of the fixed 200-agent plan to preserve its claim.

Operations

One cross-host accounting authority

Use one coordinator-owned durable reservation service for assignment fences, call IDs, spend reservations, rate scheduling and terminal receipts across both machines. Existing per-process file locks are not a two-machine atomic ledger. Workers dispatch only admitted assignments after a unique reservation; if they lose the authority, they fail closed. Declare the chosen mechanism and prove its failure paths before qualification.
