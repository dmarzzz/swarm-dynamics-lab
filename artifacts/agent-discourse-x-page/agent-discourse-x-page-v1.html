Agent discourse on X, Jan 2023 to Sep 2026

Monthly attention per topic: summed likes on that month's top posts with 50+ likes (retweets excluded), sampled through Apify. Each panel has its own y-scale, so compare shapes and timing across panels, not heights. Hover a month for the post count and the most-liked post.

  • Method: one X search per term per month (since/until, min_faves:50, Top sort), via apidojo/tweet-scraper on 2026-10-03. X's Top search caps results per query, so busy months are undersampled. The summed likes are dominated by the biggest posts, which the sample does include.
  • Most runs reached the 3,000-post sample cap (marked ◦ next to the name). Read those as lower bounds.
  • Keyword noise: "sybil" talk is mostly crypto airdrop anti-farming; "agent identity" was filtered to AI/crypto context; "Smallville" was filtered to agent context. Influencer posts dominate several project peaks.
