# 2026-10-03: academic literature scan (dmarz/swarm)

Ran 13 scan agents (`dmarz/<topic>`), each followed by an independent audit agent (`dmarz/<topic>-audit`),
over the 13 `scan-papers-*` tasks for the original topics. 26 agents, about 70 minutes, no agent failures.

## Done

- 707 papers from the scans plus 141 found by the auditors (848 at the time of the final pass). Audits
  corrected 45 entries and deleted 1 paper that could not be found.
- Every paper's DOI or arXiv id checked against Crossref and DataCite: 846 resolve with matching titles.
- 211 entries had API endpoints as `url`; replaced with doi.org or arxiv.org links.
- Each task's Coverage note has the search table, the gaps and an audit paragraph.

## Surprises

- The OpenAlex daily quota was exhausted mid-run (about 26 agents on one IP). Semantic Scholar and the arXiv
  export API rate-limited us the whole time. Crossref and DataCite were reliable.
- Paywalls (Elsevier, Springer, IEEE, Science) kept about 76% of entries at abstract depth.
- Saturation was not reached for 2023-2026 work in several topics; the seminal layers are saturated.
- One audit agent put the user's email in an OpenAlex `mailto` parameter once. It is not in the repo.
