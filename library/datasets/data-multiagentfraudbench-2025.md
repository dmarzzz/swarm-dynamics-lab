## Summary

Dataset for arXiv 2511.06448, "When AI Agents Collude Online: Financial Fraud Risks by Collaborative LLM Agents on Social Platforms". LLM agents in the OASIS social simulator wrote about 100 fraud posts for each of 119 leaf scenarios (7 categories, 28 subcategories, from the Stanford Financial Fraud Research Center taxonomy), giving 11,900 posts; a balanced 2,800-post set samples 100 per subcategory. Each post is labelled with deception type and manipulation tactics. The card describes collusion and victim dialogues in the simulation, but the files released are posts only.

## Access

Public on Hugging Face, not gated. CC-BY-NC-SA-4.0: non-commercial, share-alike. Code at github.com/zheng977/MultiAgent4Fraud.

## Relevance to us

Synthetic content from colluding agent fraud rings, usable as positive examples for content-side detection; it has no account or interaction graph, so coordination-based detection cannot be tested on it alone.
