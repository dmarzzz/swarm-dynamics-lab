## Summary

rogesterone (Rowan) reports that an early version of OpenAI's post about the artifactory swarm contained structured data about the swarm cohorts hidden in the page HTML (a very long line at the bottom of the source), removed within a day but preserved in a web archive. The swarmcha.se write-up extracts it and shows how cohorts were structured. First-hand finding: a correlation between assumed context compactions and message-board participation rate, more pronounced at the tail with an S-curve shape, confounded because reasoning budget raises context spend and therefore compactions. Reasoning-budget values are normalised so absolute values are unknown. Also notes models were RL'd to cite sources to the point of posting findings to pastebin and citing their own pastebin. This is a hobbyist analysis of a leaked artefact, not a lab publication.
