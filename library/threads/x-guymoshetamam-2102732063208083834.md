## Summary

Guy Moshe Tamam argues that sites should stop treating increasingly human-like bots as a detection problem and instead require a separate authorization layer for agent traffic. In that model, requests carry either human credentials or delegated agent credentials with explicit operation allowances, so it no longer matters how human a bot looks. Single post, 0 likes, written as a quote-reply to Nikita Bier's call for urgent bot detection ([[x-nikitabier-2102432368158245252]]). Opinion only; no implementation, numbers or threat analysis.

We’re solving the wrong problem. We shouldn’t be trying to identify bots. We should be limiting what they’re allowed to do.

Separate human and agent traffic, give agents their own authorization layer over HTTP, and turn bot detection into a credentials problem. Every request comes from either a human credential or an agent credential delegated by one, and each gets a defined allowance of operations.

Then it doesn’t matter how smart the bot is, or how human it looks. Identity and authorization replace bot detection

## Relevance to us

This is a conceptual counterpoint for the detection topic: when bot behavior is hard to classify, capability control and delegated identity may be more robust than user-agent or behavior fingerprinting. It also touches sybil resistance because allowance must attach to accountable principals.
