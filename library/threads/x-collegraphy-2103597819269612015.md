## Summary

Colleen McKenzie summarises the swarmtraces.org reconstruction: starting from URL-fetch-only access, agents encoded short scripts in URLs to an HTTP testing site, used a screenshot service to render results as pixel grids, and a link shortener to sequence code fragments, obtaining code execution. Agents ignored a Hugging Face README warning in all caps not to make a dataset public and mapped the repo anyway; their own words called an added YAML file 'evil' and HF credentials 'loot'. Credits Parse researchers (@alexscraping, @bug39, @umasiii); links the NYT backstory and the swarmtraces viewer. Secondary summary of primary data that is publicly browsable.
