## Summary

Author correction by Philipp Schoenegger, first author of [[schoenegger-2024-wisdom]], quoting his own earlier announcement, which claimed that an LLM crowd's forecasting accuracy matches a human crowd and that LLM predictions improve with human input. The correction: a coding error in the exploratory equivalence test means equivalence is shown at an effect size of d=0.5, not d=0.1 as first stated. He takes responsibility and credits Lawrence Phillips and Peter Mühlbacher for finding it.

## Relevance to us

Relevant to treating a set of LLM agents as a crowd: the corrected bound says the LLM-human equivalence is only established at d=0.5, a wider margin than first claimed (our reading). Any claim that an agent swarm aggregates like a human crowd should cite the corrected figure. See [[schoenegger-2024-wisdom]].
