## Summary

Three-tweet opinion thread summarising a longer X Article (not readable via the API, see links). The argument: once an agent persists memory across sessions, memory becomes state, and the hard problems become stale facts, provenance, deletion, poisoning and access control rather than capacity. The sharpest line is in the second tweet: a memory write is a trust transition, because untrusted input that becomes persistent memory is later treated by the agent as something it already knows. The third tweet argues forgetting is part of memory quality: a production agent needs to know when a fact is stale, what replaced it, where it came from, and whether it should still influence an action. The author says he reviewed Cognee, Graphiti, Mem0, Letta and recent memory-poisoning research, but no specific findings, numbers or citations appear in the tweets themselves. Opinion, no evidence in the thread.
