## Summary

Commentary in Arabic by a third party, not an author. The post says that, so far, no tool detects text written by ChatGPT-4, Bing or Bard with high accuracy and confidence; available tools are trained only on GPT-3.5 and have high error rates, and asking the tool itself is not accurate either. It links the 'Can AI-generated text be reliably detected' paper. The claims about specific tools are the poster's, not the paper's measured results.
