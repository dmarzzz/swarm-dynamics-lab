## Summary

Author thread by Shangbin Feng, first author of Model Swarms. Method as described: take several LLM experts (for example from Hugging Face), define a utility function scoring each model, and let each model keep a velocity in weight space driven by inertia, attraction to the global best and personal best, and repulsion from the global worst; models step, are re-scored, and the global best checkpoint is returned. Measured claim: for problems none of the initial models solved, 30-50% are solved by at least one expert after optimisation. For mixed architectures the same swarm update is applied to token probabilities for collaborative decoding.

## Relevance to us

This is literally a swarm of models repeatedly merging toward each other in weight space, so it is a natural testbed for fork-and-merge corruption: a poisoned expert that becomes the global best would pull every other model toward it. Primary source [[feng-2024-model]].
