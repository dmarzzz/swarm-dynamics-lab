Alignment alone is not enough to make autonomous AI safe.
An agent pursuing a legitimate goal can still reward hack, bypass guardrails, and compromise systems.

We've seen it with the recent OpenAI / Hugging Face and other incidents, where hundreds of agents coordinated with each other and attacked real infrastructure.
The details of those attacks are mind-blowing and show why alignment and security guardrails need to be developed together.

One difficulty in aligning a model is that rewarding the right result doesn't necessarily teach it the right behavior. It can learn to game the reward instead of doing the intended task.

We've seen versions of reward hacking in our own work at depthfirst (see blog for details).

During our research, we've seen how security guardrails can support alignment by removing shortcuts that let agents earn rewards without doing the intended task.
After deployment, they constrain unauthorized actions and contain failures.

The more autonomy we give AI, the more we need secure software and infrastructure.

Similar to how we're more comfortable letting our kids run around in an enclosed backyard.
