## Summary

Author thread by Thorsten Holz, a co-author. Claims: augmenting LLMs with retrieval and API calls enables new prompt-injection techniques; the technical report systematically studies the attacks and proof-of-concept implementations show they are practically feasible. He defines indirect prompt injection as prompts an adversary places in public sources so that the LLM later retrieves and processes them, and states that how best to defend is still unclear. No numbers in the thread.
