## Summary

Author thread, verified (Matthew Finlayson is first author). Claim: LLM outputs lie in a low-dimensional space of exactly the embedding size, so checking the dimension of the outputs reveals it; they estimate gpt-3.5-turbo's embed size at 4096. Uses: full logprob extraction in O(embed size) instead of O(vocab size) API calls, a 25x speedup for gpt-3.5-turbo (cheaper model stealing), and the output subspace as a model 'signature' that lets outsiders detect unannounced model changes or APIs serving a different model. Their position, an opinion, is that these leaks are a feature for accountability. He notes a simultaneous paper (arXiv 2403.06634) with similar findings.
