## Summary

The paper models agent cognition and shared tool infrastructure as coupled epidemic layers. It explains how agents that never directly exchange messages can still influence each other through a common tool dependency, and analyzes epidemic thresholds and allocation of a defence budget.

## Contribution

Analysis of propagation, lifecycle security, containment or trust-boundary assessment.

## Key results

The publisher-deposited abstract describes eight experiment groups over synthetic and empirical graph topologies. Shared-tool coupling amplifies spread; tool-side controls can dominate agent hardening under the model. These are modelling results, not independently measured real LLM outbreaks.

## Methods and models

Publisher-deposited abstract in Crossref; Springer page returned a client challenge. Formal SEIQ/SIS model and next-generation-matrix approximation, per abstract.

## Limitations and open questions

Full parameter estimation and simulated-versus-observed distinctions were not checked.
