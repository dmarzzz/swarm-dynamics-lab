## Summary

Paired arithmetic tests reveal poor rejection when the correct answer is absent despite strong answer-present performance. Boolean verification and a threshold tuned on separate development problems mitigate the reported failure.

## Limitations and open questions

This already answers the basic missing-option question. Test cross-model menu repair under non-arithmetic distribution shift only as an extension.
