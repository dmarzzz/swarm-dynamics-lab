## Summary

This work explores climate-action stance changes in an LLM-powered micro-society with personality and episodic memory. It tracks conviction and institutional trust alongside discussion topics, reports abrupt changes, and emphasizes that model biases and memory maintenance complicate interpreting social tipping.

## Contribution

Shows abrupt, tipping-like stance shifts in a small LLM micro-society with personalities and episodic memory, and warns that model bias and memory upkeep confound the interpretation.

## Key results

- Abrupt stance changes are reported qualitatively; the abstract contains no tipping threshold or sample size.

## Methods and models

Two-dimensional stance distances and Latent Dirichlet Allocation across repeated conversations.

## Limitations and open questions

A simple model with persistent LLM biases is not evidence that real-world climate interventions will have the same effects.

## Relevance to us

One more data point that LLM populations can flip collectively; useful only as a qualitative example for committed-minority or tipping ideas, since the abstract gives no threshold or N.
