## Summary

Replicates the Shore et al. (2018) Twitter echo-chamber framework on Moltbook, using an LLM-scored autonomy axis and a comment-based revealed-attention network. At the population level agents mainstream, as Twitter users do. Under Shore's visibility-based definition of the core, the agent core does not polarise. Polarisation appears only when coreness is defined by engagement breadth (how widely an agent comments); cores defined by incoming comments, karma or PageRank all mainstream. A second stance axis gives consistent results.

## Contribution

A human-baseline replication on an agent platform showing that the echo-chamber finding depends on the coreness definition.

## Key results

- Population mainstreams; visibility-defined core does not polarise (reported).

## Methods and models

Moltbook comment network, LLM-scored stance axes, Shore et al. core definitions. Abstract read via Crossref; SSRN full text not opened.
