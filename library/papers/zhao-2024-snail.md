## Summary

A self-reconfigurable terrestrial robot swarm for outdoor, unstructured terrain, inspired by land snails. Each
robot has a two-mode connector: a free mode using magnet-embedded tracks for freeform mobility and attachment,
and a strong mode using a vacuum sucker with directional polymer stalks for secure adhesion. Assigning functions
to each mode balances mobility and connection strength; outdoor experiments show individual and collective
capabilities.
