## Summary

shelLM is an SSH honeypot whose shell output is generated by a cloud LLM (GPT-3.5-turbo-16k per [[bridges-2025-sok]]), passing each command with the full session history. Cybersecurity researchers used it and judged whether each response matched what a real Linux shell would print; shelLM reached a true-negative rate of 0.90, i.e. it convinced humans it was a real shell.

## Contribution

The first implemented LLM-generated honeypot (per [[bridges-2025-sok]]). It is the "LLM as honeypot" branch, as opposed to the "honeypot for LLMs" branch in [[reworr-2024-llm]].

## Key results

- TNR 0.90 against human cybersecurity researchers (abstract).

## Methods and models

Prompted cloud LLM emulating a Linux shell; human evaluation. Abstract-level read. Venue and pages 430–435 confirmed via the Crossref record for the DOI.

## Limitations and open questions

Evaluated against humans, not against LLM agents; per-command API latency and cost; LLM-specific inconsistencies may be detectable by agents ([[bridges-2025-sok]]).

## Relevance to us

Cheap high-fidelity decoys are a prerequisite for sustained swarm engagement. Related: [[otal-2024-llm]], [[mckee-2023-chatbots]].
