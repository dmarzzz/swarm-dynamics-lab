## Summary

Liebchen and Levis extend the Vicsek model to circle swimmers (chiral active particles). The flocking transition occurs
at the same interaction-to-noise ratio as for straight swimmers, but rotation enhances polarization in the ordered phase
and triggers secondary instabilities: slow rotation gives macroscopic droplets (phase separation), fast rotation gives
phase-synchronized microflocks with size set by the single-particle swimming radius. Read from the abstract in the Semantic Scholar API record in `url`; details beyond the abstract are not checked.
