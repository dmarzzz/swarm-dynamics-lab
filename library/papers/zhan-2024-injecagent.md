## Summary

The first benchmark of indirect prompt injection against tool-using agents. 1,054 test cases combine 17 user tools with 62 attacker tools; the attacker's instruction sits inside a tool response (a review, an email, a note) and aims either at direct harm to the user or at exfiltrating private data. Thirty agents are evaluated, both ReAct-prompted LLMs and models fine-tuned for tool calling, in a base setting and an "enhanced" setting that prefixes a hacking prompt.

## Contribution

Turned indirect injection against agents into a measured rate across many models, establishing that tool output is a reliable control channel.

## Key results

- Measured: ReAct-prompted GPT-4 follows the injected instruction 24% of the time in the base setting.
- Measured: adding a hacking prompt roughly doubles this, to 47% for ReAct GPT-4.
- Measured: a GPT-4 model fine-tuned for function calling is more resistant, 7.1%.
- Measured: rates vary widely across open models; some small models show high success on data-stealing chains when they produce valid outputs.

## Methods and models

Simulated single-turn setting: the agent receives the user instruction and one tool response containing the injection, generated by GPT-4 and checked manually. Success means the agent calls the attacker tool (and, for data stealing, a second tool to send the data). Metrics ASR-valid and ASR-all.

## Limitations and open questions

Single tool response, no multi-step planning, no memory, no defences beyond model choice. [[debenedetti-2024-agentdojo]] argues this underestimates the planning dimension.

## Relevance to us

Q3. Quantifies the base rate of the entry step in dmarz's attack: a sub-agent reading attacker-written content and acting on it. A quarter to a half of frontier-model agents in 2024 complied with a single injected instruction. The finding that fine-tuned tool-calling models resist more suggests a parent could prefer specially trained models for exploring parts.
