## Summary

Replication code for 'MultiSocial: Multilingual Benchmark of Machine-Generated Text Detection of Social-Media Texts' (ACL 2025, doi 10.18653/v1/2025.acl-long.36, arXiv 2406.12549). The dataset is on Zenodo record 13846152. The same group (KInIT) also publishes a multilingual MGT detection benchmark and an authorship-obfuscation benchmark (kinit-sk/mgt-detection-benchmark, kinit-sk/mAO).

## What it can do for us

Short, multilingual social posts are the format agent swarms actually emit; detector performance on short texts is where content-based detection is weakest, so this is the relevant benchmark for social-platform agents.
