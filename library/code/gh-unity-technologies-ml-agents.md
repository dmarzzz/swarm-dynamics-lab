## Summary

Toolkit: Unity SDK to instrument any Unity scene as an environment plus PyTorch trainers; 17+ example environments; single-agent, cooperative multi-agent (MA-POCA) and competitive multi-agent training with self-play; imitation learning (BC, GAIL); custom trainer plugins. Surfaced only in the final saturation round despite 19.7k stars.

## What it can do for us

3D multi-agent environments with physics and rendering if we ever need embodied visual agents; self-play infrastructure.
