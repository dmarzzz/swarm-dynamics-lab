## Summary

Framework: lightweight actor model for discrete-event simulation and networked systems: Actor (state and logic), LifeCycle (start, stop, snapshot), Handler<M> for typed messages, Network trait for connections, Runtime that routes messages. Strongly typed, high performance. Repo created 2022-11 (GitHub API).

## What it can do for us

High-performance typed actor runtime if we write a rule-based or protocol sim in Rust.
