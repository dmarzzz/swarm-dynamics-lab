## Summary

The long-standing ABM environment and language, with a models library that includes Flocking (Reynolds-style), Ants, Wolf Sheep and many collective-behaviour classics, BehaviorSpace parameter sweeps, HubNet and a headless API. The GitHub repo is the source for developers; users install binaries from netlogo.org. GPL-2.0, 1.2k stars, active (2026-10-01).

## What it can do for us

Pedagogical reference implementations of Flocking and other classics; headless BehaviorSpace sweeps are easy. Not where we would build new experiments.
