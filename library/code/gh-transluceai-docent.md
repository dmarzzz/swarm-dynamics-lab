## Summary

Transluce's open platform for analysing AI agent transcripts at scale: ingest runs, search and cluster behaviours, with hosted (docent.transluce.org) and self-hosted options, a Slack community and a changelog. README is short and defers to docs.transluce.org. Transluce is the group that published the urlquery agent-activity analysis, and Docent is the tool class one would use to go through 38,000 scans or 7,200 transcripts.

## What it can do for us

If we analyse the sealed-swarm transcripts or swarmtraces payloads, Docent is purpose-built for exactly that, and self-hosting avoids sending data out.
