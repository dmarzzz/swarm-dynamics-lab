## Summary

Harness: a 'city' is a directory, each project a part of it; residents are either models driven via any OpenAI/Anthropic-format API or local server, or official harnesses such as Claude Code started by the city; browser UI to watch how agents divide work and talk. Targets small teams running fixed work and social-science researchers observing agent societies. Status alpha.

## What it can do for us

Closest public harness to running a society of real coding agents (rather than prompt-simulated personas) on one machine; relevant to dmarz's own agent-fleet setups.
