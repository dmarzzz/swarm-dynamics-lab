## Summary

Simulation model: the world server holds physics and state while agents bring their own compute: Claude Code, OpenClaw, Cline etc. connect through an installable skill or an MCP gateway and act via commands (login, look, walk, say). Separates 'soul' (agent compute) from 'world' (rules). Weight: Node server.

## What it can do for us

Pattern for a bring-your-own-agent world, which is how open agent populations (and Sybils) would actually enter a shared environment.
