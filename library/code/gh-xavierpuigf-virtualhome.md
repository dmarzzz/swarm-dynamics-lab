## Summary

Interactive platform where agents execute household activity programs with complex object interactions (picking up objects, switching appliances); v2.3 adds procedural environment generation, more environments, better physics and a synchronised day/night time system. The repo describes itself as a multi-agent household simulator; Unity executable backend.

## What it can do for us

Embodied household tasks for LLM planners; mostly useful for embodied-agent work, not swarms.
