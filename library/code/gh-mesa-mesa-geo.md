## Summary

Official GIS extension for [[gh-mesa-mesa]]: implements a GeoSpace that hosts GeoAgents, which behave like ordinary Mesa agents but carry a Shapely geometry and a coordinate reference system, so models can run on real map data and spatial queries. Installed with pip install -U mesa-geo; maintained by the Mesa project.

## What it can do for us

Real-map spatial layer for Mesa models.
