## Summary

Python platform for agent-based economic simulations in which the modeller writes only the agents' decision logic, while the framework provides standard functions for trading goods, production and consumption and handles the bookkeeping of exchanges between agents. Installed with pip install abcEconomics; documented on readthedocs.

## What it can do for us

Ready-made goods/exchange accounting for an economic ABM.
